Project overview

一个从运动学开始的控制项目

项目围绕四足机器人的单腿位置控制展开：先用几何法建立正逆运动学模型，再通过仿真验证，最后搭建可由无线手柄驱动的硬件平台。

机械腿采用髋部与膝部两个转动关节。给定末端坐标后，逆运动学把目标位置换算为关节角；正运动学再由关节角回算末端位置，组成闭环校验。

算法原型在 Python 中完成，控制硬件以 STM32F103C8Tx 为核心，驱动 8 个 MG995 舵机，并通过 PS2 无线手柄接收操作输入。机械结构由 SolidWorks 建模后使用 FDM 3D 打印制作。
