冒泡排序

O(n²) ✅ 稳定 慢
相邻交换，大数后移 — 每轮将最大元素"冒泡"到末尾，可加 flag 优化提前结束。
// 冒泡排序 —— 每轮把最大元素"冒泡"到末尾 void bubbleSort(int a[], int n) { // 外层：需要 n-1 轮冒泡（每轮确定一个最大元素的位置） for (int i = 0; i < n-1; ++i) // 内层：从 0 到 n-1-i，相邻元素两两比较 // 每轮结束后，最大的 i+1 个元素已就位，无需再比较 for (int j = 0; j < n-1-i; ++j) // 如果前一个比后一个大，则交换（升序排列） if (a[j] > a[j+1]) swap(a[j], a[j+1]); // 交换相邻元素 // 优化：可加 flag 记录本轮是否有交换，若没有则提前结束 }

选择排序

O(n²) ❌ 不稳定 慢
每轮选最小交换 — 无论数据如何都跑满 O(n²)，不稳定源于远程交换。
// 选择排序 —— 每轮从未排序区间选出最小元素，放到已排序区末尾 void selectionSort(int a[], int n) { // 外层：每次确定一个位置（从头开始） for (int i = 0; i < n-1; ++i) { int minIdx = i; // 假设当前 i 就是最小值的位置 // 内层：在[i+1, n)中查找真正的最小值下标 for (int j = i+1; j < n; ++j) if (a[j] < a[minIdx]) minIdx = j; // 更新最小元素下标 swap(a[i], a[minIdx]); // 将最小元素交换到 i 位置 } // 特点：简单直观，但无论有序与否都是 O(n²) }

插入排序

O(n²) ✅ 稳定 慢
插入到已排序区 — 数据基本有序时接近 O(n)，在线排序，稳定且适应性好。
// 插入排序 —— 把当前元素插入到左侧已排序区的正确位置 void insertionSort(int a[], int n) { // 从第 1 个元素开始，左侧 [0, i-1] 已是有序区间 for (int i = 1; i < n; ++i) { int key = a[i]; // 取出待插入的元素（保留副本） int j = i-1; // 从已排序区的最右侧开始向左扫描 // 向左移动，将所有大于 key 的元素右移一位 while (j >= 0 && a[j] > key) { a[j+1] = a[j]; // 元素右移，腾出位置 --j; // 继续向左比较下一个 } a[j+1] = key; // 将 key 插入空出的位置 } // 特点：数据基本有序时接近 O(n)，在线排序，稳定 }

希尔排序

O(n log n)~O(n²) ❌ 不稳定 中
分组插入排序 — 增量序列决定复杂度，跨越间隔的交换破坏了稳定性。
// 希尔排序 —— 改进的插入排序，跨越间隔分组进行插入排序 void shellSort(int a[], int n) { // 外层循环：不断缩小增量 gap（初始为 n/2，每轮减半） for (int gap = n/2; gap > 0; gap /= 2) // 对当前 gap 分组，每组内做插入排序（从 gap 开始到 n-1） for (int i = gap; i < n; ++i) { int tmp = a[i], j = i; // tmp: 待插入元素 // 在组内向前扫描，间隔为 gap，把大于 tmp 的元素后移 while (j >= gap && a[j-gap] > tmp) { a[j] = a[j-gap]; // 同组元素跨 gap 右移 j -= gap; // 跳转到组内前一个元素 } a[j] = tmp; // 将 tmp 插入组内正确位置 } // 特点：跨越间隔交换 → 不稳定；增量序列影响复杂度 }

归并排序

O(n log n) ✅ 稳定 快
分治 · 合并有序序列 — O(n log n) 最坏保证，需 O(n) 辅助空间，外排序首选。
// 归并排序 —— 分治：将两个有序子数组合并为一个有序数组 void merge(int a[], int l, int m, int r) { // n1、n2：左右两个子数组的长度 int n1 = m-l+1, n2 = r-m; int L[n1], R[n2]; // 创建临时数组 for (int i=0; i<n1; ++i) L[i]=a[l+i]; // 复制左半 → L for (int j=0; j<n2; ++j) R[j]=a[m+1+j]; // 复制右半 → R int i=0, j=0, k=l; // i: L指针 j: R指针 k: a指针 // 将 L 和 R 中较小的元素依次写回 a（合并两个有序序列） while (i<n1 && j<n2) a[k++] = (L[i] <= R[j]) ? L[i++] : R[j++]; // ≤ 保证稳定性 // 处理剩余元素（左右各可能还有剩余） while (i<n1) a[k++] = L[i++]; // L 有剩余 while (j<n2) a[k++] = R[j++]; // R 有剩余 } // 归并排序入口：递归分治 void mergeSort(int a[], int l, int r) { if (l >= r) return; // 递归终止：区间为空或只有一个元素 int m = l + (r-l)/2; // 取中点，避免 (l+r)/2 溢出 mergeSort(a, l, m); // 递归排序左半 [l, m] mergeSort(a, m+1, r); // 递归排序右半 [m+1, r] merge(a, l, m, r); // 合并两个有序子数组 // 特点：稳定，O(n log n) 最坏保证，需 O(n) 辅助空间 }

快速排序

O(n log n) 平均 ❌ 不稳定 快
分治 · 基准划分 — 实际最快通用排序，最坏 O(n²)，随机选 pivot 缓解。
// 快速排序 —— 分治，选取 pivot 分为小于和大于 pivot 的两部分 int partition(int a[], int lo, int hi) { int pivot = a[hi]; // 选最后一个元素作为基准 pivot int i = lo-1; // i 指向"小于区"的最后一个元素 for (int j = lo; j < hi; ++j) // 从左到右扫描 lo ~ hi-1 if (a[j] < pivot) // 发现小于 pivot 的元素 swap(a[++i], a[j]); // 交换到"小于区"右侧 swap(a[i+1], a[hi]); // 将 pivot 放到正确位置 return i+1; // 返回 pivot 下标 } void quickSort(int a[], int lo, int hi) { if (lo < hi) { // 区间至少有两个元素 int p = partition(a, lo, hi); // 划分：p 是 pivot 最终下标 quickSort(a, lo, p-1); // 递归排序左半（小于 pivot） quickSort(a, p+1, hi); // 递归排序右半（大于 pivot） } // 特点：实际最快，O(n log n) 平均；最坏 O(n²) }

堆排序

O(n log n) ❌ 不稳定 快
大根堆 + 交换 — O(n log n) 最坏保证，原地排序，适用于 Top-K 问题。
// 堆排序 —— 基于大根堆的原地排序 // 对以 i 为根的子树做堆化（下沉操作），保证父节点 ≥ 子节点 void heapify(int a[], int n, int i) { int largest = i; // 假设当前节点 i 是最大值 int l = 2*i+1; // 左子节点下标（0-indexed） int r = 2*i+2; // 右子节点下标 if (l < n && a[l] > a[largest]) largest = l; // 若左子更大，更新 if (r < n && a[r] > a[largest]) largest = r; // 若右子更大，更新 if (largest != i) { // 如果最大值不是 i swap(a[i], a[largest]); // 将最大值交换到父节点位置 heapify(a, n, largest); // 递归堆化受影响的子树 } } void heapSort(int a[], int n) { // 阶段一：建堆 —— 从最后一个非叶子节点开始向上堆化 for (int i = n/2-1; i >= 0; --i) heapify(a, n, i); // 构建大根堆 // 阶段二：排序 —— 每次将堆顶（最大值）交换到末尾 for (int i = n-1; i > 0; --i) { swap(a[0], a[i]); // 堆顶 → 数组末尾 heapify(a, i, 0); // 对剩余 i 个元素重新堆化 } // 特点：O(n log n) 最坏保证，原地排序，不稳定 }

计数排序

O(n + k) ✅ 稳定 快
非比较 · 频率统计 — k 为值域，适合值域不大的非负整数排序。
// 计数排序 —— 非比较排序，通过统计元素出现次数完成排序 void countingSort(int a[], int n, int k) { int count[k+1] = {0}; // 初始化计数数组，大小 = 值域 k+1 for (int i=0; i<n; ++i) count[a[i]]++; // 统计每个元素出现的频率 int idx = 0; // 按顺序写回原数组的下标 for (int i=0; i<=k; ++i) // 从小到大遍历值域 while (count[i]--) a[idx++] = i; // 将值 i 重复输出 count[i] 次 // 注意：此版本是"不稳定"的简单版。稳定版需前缀和 + 逆序输出 // 适用场景：值域 k 不大（如 0~10000），且元素是非负整数 }

桶排序

O(n + k) 平均 ✅ 稳定* 快
分散到桶 · 各自排序 — 数据分布均匀时 O(n)，桶内稳定则整体稳定，适合浮点数。
// 桶排序 —— 将数据均匀分散到多个桶中，各桶独立排序 void bucketSort(float a[], int n) { // 创建 n 个桶（每个桶是一个 vector） vector<vector<float>> buckets(n); // 遍历原数组，将每个元素放入对应的桶中 // 下标 = n * a[i]（要求 a[i] ∈ [0, 1)） for (int i=0; i<n; ++i) buckets[(int)(n * a[i])].push_back(a[i]); // 对每个桶内部进行排序（这里用 std::sort，通常为快速排序） for (auto& b : buckets) sort(b.begin(), b.end()); // 按桶的顺序将所有元素写回原数组 int idx = 0; for (auto& b : buckets) for (float v : b) a[idx++] = v; // 若桶内用稳定排序（如插入排序），则桶排序整体稳定 // 适用：数据均匀分布的浮点数 }

基数排序

O(d·(n+k)) ✅ 稳定 快
按位分配 · 逐位收集 — d 为位数，k 为基数（10），适合固定长度整数/字符串。
// 基数排序 —— 按位（个/十/百位）进行稳定的计数排序 void radixSort(int a[], int n) { int mx = *max_element(a, a+n); // 找到最大值，确定位数 // 按个位、十位、百位……逐位排序（exp = 1, 10, 100, ...） for (int exp = 1; mx/exp > 0; exp *= 10) { int out[n]; // 临时输出数组 int cnt[10] = {0}; // 基数 0~9 的频率 // 1. 统计当前位（exp）上每个数字（0-9）的出现次数 for (int i=0; i<n; ++i) cnt[(a[i]/exp)%10]++; // 2. 前缀和累加：cnt[i] 表示"≤ i 的数字出现次数" for (int i=1; i<10; ++i) cnt[i] += cnt[i-1]; // 3. 逆序遍历原数组，按当前位将元素放入 out 的正确位置 // 逆序保证了排序的稳定性 for (int i=n-1; i>=0; --i) { out[cnt[(a[i]/exp)%10]-1] = a[i]; cnt[(a[i]/exp)%10]--; } // 4. 将本轮排好序的结果复制回原数组 for (int i=0; i<n; ++i) a[i] = out[i]; } // 特点：稳定，O(d·(n+k))，适合固定长度整数/字符串 }

排序算法对比速览

🏆 综合推荐（通用）

原地 快速排序 — 实际最快，O(n log n) 平均，首选
非原地 归并排序 — 稳定有保障，外排序好
原地 堆排序 — 最坏保证，适合嵌入式

🎯 场景选型

• 数据基本有序 → 插入排序 O(n)
• 值域小整数 → 计数排序 O(n)
• 均匀浮点数 → 桶排序 O(n)
• 固定位数整数 → 基数排序 O(d·n)
