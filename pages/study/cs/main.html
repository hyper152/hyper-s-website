一、基本概念

  • 1. 数据结构三要素：逻辑结构、存储结构、数据运算
  • 2. 逻辑结构分类：线性结构（一对一）、树形结构（一对多）、图形结构（多对多）
  • 3. 存储结构：顺序存储、链式存储、索引存储、散列存储
  • 4. 算法复杂度
    • 时间复杂度：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)
    • 空间复杂度：算法运行所需的额外存储空间
    • 最好/最坏/平均情况复杂度

二、线性表

  • 1. 顺序表（数组实现）—— 随机访问 O(1)，插入/删除 O(n)
  • 2. 链表
    • 单链表、双向链表、循环链表
    • 头结点 vs 头指针
    • 插入/删除 O(1)（已知位置），查找 O(n)
  • 3. 顺序表与链表的对比（空间、时间、适用场景）

三、栈与队列

  • 1. 栈（Stack）—— 后进先出（LIFO）
    • 顺序栈 & 链栈
    • 入栈、出栈、栈顶操作
  • 2. 队列（Queue）—— 先进先出（FIFO）
    • 循环队列（解决假溢出问题）
    • 链队列
  • 3. 应用：表达式求值、括号匹配、层次遍历

四、树与二叉树

  • 1. 二叉树的性质
    • 第 i 层最多 2ⁱ⁻¹ 个结点，深度 h 最多 2ʰ⁻¹ 个结点
    • n₀ = n₂ + 1（叶子结点数 = 度为2的结点数 + 1）
  • 2. 遍历方式
    • 前序 / 中序 / 后序 / 层次遍历
    • 已知两种遍历序列可唯一确定二叉树
  • 3. 树与森林
    • 双亲表示法、孩子表示法、孩子兄弟表示法
    • 树、森林与二叉树的转换
  • 4. 哈夫曼树 & 哈夫曼编码
    • 带权路径长度 WPL 最小
    • 构造算法：每次合并权值最小的两棵二叉树
  • 5. 二叉搜索树（BST）
    • 左子树 < 根 < 右子树
    • 查找 / 插入 / 删除 O(h)
  • 6. 平衡二叉树（AVL）
    • 平衡因子：左右子树高度差 ≤ 1
    • 四种旋转调整：LL / RR / LR / RL

五、图

  • 1. 存储结构
    • 邻接矩阵（稠密图）、邻接表（稀疏图）
    • 十字链表、邻接多重表
  • 2. 遍历
    • 深度优先搜索（DFS）—— 栈/递归
    • 广度优先搜索（BFS）—— 队列
  • 3. 最小生成树
    • Prim 算法（顶点扩展）O(V²)
    • Kruskal 算法（边选）O(E log E)
  • 4. 最短路径
    • Dijkstra 算法（单源，非负权）
    • Floyd 算法（多源）O(V³)
  • 5. 拓扑排序 & 关键路径（AOV / AOE 网）

六、查找

  • 1. 顺序查找 O(n)
  • 2. 折半查找（二分查找）O(log n) —— 仅适用于有序顺序表
  • 3. 分块查找（索引顺序查找）
  • 4. 散列（Hash）查找
    • 常见 Hash 函数：直接定址、除留余数、数字分析
    • 冲突处理：开放定址法（线性探测/平方探测/双散列）、链地址法
    • 装填因子 α = 记录数 / 表长

七、排序 📖 排序算法详解 →

  • 1. 插入排序 O(n²)、希尔排序 O(n log n)~O(n²)
  • 2. 冒泡排序 O(n²)、快速排序 O(n log n) 重点
  • 3. 选择排序 O(n²)、堆排序 O(n log n) 重点
  • 4. 归并排序 O(n log n)
  • 5. 基数排序 O(d·n)，d 为位数
  • 6. 排序算法对比
    • 稳定性：冒泡 ✓ 插入 ✓ 归并 ✓ | 选择 ✗ 快排 ✗ 堆排 ✗ 希尔 ✗
    • 时间复杂度、空间复杂度、适用场景
