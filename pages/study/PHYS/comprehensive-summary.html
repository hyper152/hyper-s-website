📖 高中回顾 · 力学基础

📐 运动学与牛顿力学 [高中]

以下内容为高中物理已学过的力学基础，大学物理在此基础上深化扩展。

📌 质点运动学

v = v₀ + at
x = x₀ + v₀t + 12at²
v² − v₀² = 2a(x−x₀)

📌 牛顿三定律

  • 惯性定律： F = 0 ⇒ v = const
  • F = ma （牛顿第二定律，力的瞬时作用）
  • 作用与反作用： F₁₂ = −F₂₁

📌 常见的力

  • 万有引力：F = G m₁m₂/r², G = 6.67×10⁻¹¹ N·m²/kg²
  • 重力：G = mg, g ≈ 9.8 m/s²
  • 弹簧弹力（胡克定律）：F = −kx
  • 摩擦力：fₘₐₓ = μₛN, fₖ = μₖN

📌 动量与冲量

p = mv
I = ∫F dt = Δp = mv₂ − mv₁

动量守恒：∑F外 = 0 ⇒ p = const

📌 功与能

  • 动能 Eₖ = 12mv²，动能定理 W = ΔEₖ
  • 重力势能 Eₚ = mgh，弹性势能 Eₚ = 12kx²
  • 机械能守恒：只有保守力做功时，Eₖ + Eₚ = const
🌟 难点：保守力与势能的关系
保守力等于势能函数对距离 r 的负导数（一维）或负梯度（三维）：
F = −dEp/dr（一维） ⟹ F = −∇Ep（三维）
推导：保守力做功 W = ∫F·dr = −ΔEp ⇒ F·dr = −dEp ⇒ F = −dEp/dr
经典例子：
• 弹簧弹力：F = −kx = −d(½kx²)/dx ← 弹性势能 ½kx² 的负导数
• 万有引力：F = −GMm/r² = −d(−GMm/r)/dr ← 引力势能 −GMm/r 的负导数
• 重力：F = −mg = −d(mgh)/dh ← 重力势能 mgh 的负导数（一维近似）
✅ 大学新视角： 中学学的 F = ma 是 F = dpdt 在 m 为常量时的特例。 大学物理强调 F = dpdt 的微分形式，并引入 质心运动定理：∑F外 = MaC。

📐 质点运动学 · 大学深化

📐 质点运动学的矢量描述 [大学] Vector Description

💡 大学运动学与高中的核心区别： 高中主要学习一维直线运动，大学引入 矢量描述 和 微积分 方法， 以及 自然坐标系 处理曲线运动。

📌 位置矢量、位移、速度、加速度

位置矢量：r⃗ = x(t)î + y(t)ĵ + z(t)k̂
位移：Δr⃗ = r⃗(t+Δt) − r⃗(t)
瞬时速度：v⃗ = dr⃗/dt = (dx/dt)î + (dy/dt)ĵ + (dz/dt)k̂
瞬时加速度：a⃗ = dv⃗/dt = d²r⃗/dt²
⚠️ 注意区分： |Δr⃗| ≠ 路程 Δs（除直线单向运动外），|v⃗| = ds/dt（速率），而 |Δr⃗/Δt| 是平均速度大小。

📌 自然坐标系 [新概念]

以质点运动轨迹本身为坐标轴的坐标系。切向单位矢量 τ̂ 沿轨迹切线方向，法向单位矢量 n̂ 指向曲率中心。

切向加速度：aτ = dv/dt · τ̂ （描述速率变化快慢）
法向加速度：an = v²/ρ · n̂ （描述速度方向变化快慢）
总加速度：a⃗ = aττ̂ + ann̂

其中 ρ 为轨迹在该点的曲率半径。

各种运动的加速度特征

运动类型aτan总加速度
匀速直线运动00a = 0
匀变速直线运动const0a = const
匀速圆周运动0v²/Ra = v²/R, 指向圆心
一般曲线运动dv/dtv²/ρa = √(aτ² + an²)

📌 圆周运动的角量描述

角位置 θ(t)，角速度 ω = dθ/dt
角加速度 α = dω/dt = d²θ/dt²
线量与角量的关系：v = Rω，aτ = Rα，an = Rω²

📌 相对运动

v⃗AC = v⃗AB + v⃗BC （绝对 = 相对 + 牵连）
a⃗AC = a⃗AB + a⃗BC

当 B 相对于 C 做匀速直线运动时，a⃗BC = 0，则 a⃗AC = a⃗AB —— 即 加速度在不同惯性系中相同（伽利略变换不变性）。

⚡ 质点动力学 · 大学深化

⚡ 质点动力学深化 [大学] Dynamics

📌 牛顿定律的微分形式

F⃗ = dp⃗/dt = d(mv⃗)/dt

当 m 为常量时退化为 F⃗ = ma⃗。大学物理强调微分形式，便于处理变质量问题（如火箭）。

📌 惯性系与非惯性系 [新概念]

  • 惯性系：牛顿定律成立的参考系。相对惯性系做匀速直线运动的参考系也是惯性系。
  • 非惯性系：相对惯性系有加速度的参考系。在非惯性系中需引入 惯性力 才能使用牛顿定律形式。
平动非惯性系中的惯性力：F⃗惯 = −ma⃗0
转动非惯性系中的惯性力：F⃗离心 = mω²r⃗，F⃗科里奥利 = 2mv⃗′ × ω⃗

📌 动量定理与动量守恒

冲量：I⃗ = ∫t₁t₂ F⃗ dt = Δp⃗ = p⃗₂ − p⃗₁
动量守恒：∑F⃗外 = 0 ⇒ Σmᵢv⃗ᵢ = const

动量守恒是 空间平移对称性 的体现 —— 这是分析力学的深刻观点。

📌 质心与质心运动定理

质心位置：r⃗C = (Σmᵢr⃗ᵢ)/M
质心运动定理：∑F⃗外 = Ma⃗C

质心的运动只由合外力决定，内力不影响质心运动。质点系的总动量 等于总质量乘以质心速度：P⃗ = Mv⃗C。

📌 功与能 — 大学深化

变力做功：W = ∫L F⃗ · dr⃗ = ∫x₁x₂ Fx dx + ∫y₁y₂ Fy dy + ∫z₁z₂ Fz dz
动能定理：W合 = ΔEk = ½mv₂² − ½mv₁²
功能原理：W外 + W非保内 = ΔE = Δ(Ek + Ep)

📌 势能曲线与平衡 [新概念]

一维势能曲线：F(x) = −dEp/dx
  • 稳定平衡：势能曲线有极小值，F(x)=0，偏离时力指向平衡点（如弹簧振子）
  • 不稳定平衡：势能曲线有极大值，F(x)=0，偏离时力背离平衡点
  • 随遇平衡：势能曲线平坦，F(x)=0

📌 碰撞问题

类型动量动能恢复系数 e
完全弹性碰撞守恒守恒e = 1
完全非弹性碰撞守恒不守恒（损失最大）e = 0
非完全弹性碰撞守恒不守恒（部分损失）0 < e < 1
一维对心碰撞：v₂ − v₁ = e(u₁ − u₂) （碰后相对速度 = e × 碰前相对速度）

⚙️ 刚体定轴转动

⚙️ 刚体定轴转动 [大学] Rigid Body Rotation

💡 刚体定义： 在外力作用下形状和大小保持不变的理想物体 —— 任意两质点间距离恒定。 这是大学物理引入的第一个理想模型，中学未系统学习。

📌 定轴转动的运动学

ω = dθdt
α = dωdt = d²θdt²
s = Rθ
v = Rω
aτ = Rα
an = Rω²

匀角加速转动：

ω = ω₀ + αt
θ = θ₀ + ω₀t + 12αt²
ω² − ω₀² = 2α(θ−θ₀)

📌 转动惯量 [核心]

转动惯量 I 描述刚体转动惯性的大小，相当于平动中的质量。取决于 质量分布 和 转轴位置。

I = Σ mᵢ rᵢ²
⟹ I = ∫ r² dm

常见刚体的转动惯量

刚体类型转轴位置转动惯量
细圆环过中心垂直轴I = MR²
圆盘/圆柱过中心轴I = 12MR²
细棒过中心垂直轴I = 112ML²
细棒过端点垂直轴I = 13ML²
球壳直径轴I = 23MR²
球体直径轴I = 25MR²

平行轴定理

I = IC + M d²

其中 IC 为过质心轴的转动惯量，d 为两平行轴间的距离。

⚠️ 注意： 平行轴定理必须从 质心轴 出发！只能从质心轴 → 其他平行轴，不能反向。

📌 转动定律 [核心]

M = Iα = I · (dωdt)

转动定律 是牛顿第二定律在转动中的对应：合外力矩 ≠ 0 → 刚体获得角加速度。

力矩定义：M = r × F，方向由右手螺旋定则确定。

📌 刚体角动量

L = Iω
→ M = dLdt
→ ∫M dt = ΔL = Iω₂ − Iω₁

📌 角动量守恒定律 [重要]

M外 = 0 ⇒ L = Iω = const
⟹ I₁ω₁ = I₂ω₂
  • 经典例子：花样滑冰运动员收臂加速旋转；转椅上的哑铃实验
  • 猫在空中翻身、陀螺仪的定向性

📌 转动动能 & 功

Eₖ = 12Iω²
dW = M dθ
W = 12Iω₂² − 12Iω₁²

刚体 + 质点系统的机械能守恒（含重力势能 mghC）。

📌 纯滚动条件

vC = Rω
aC = Rα

纯滚动 = 无滑滚动，接触点瞬时速度为零。

📌 打击中心 (Center of Percussion)

当外力作用于刚体上的特定位置时，转轴处不受冲击力，该位置称为打击中心（COP）。

d = ICM·h + h

其中 h 为质心到转轴的距离。应用：棒球棒、门把手设计（安装在打击中心处手感最好）。

📖 高中回顾 · 静电基础

⚡ 静电学基础回顾 [高中]

📌 电荷基本性质

  • 电荷守恒定律：电荷既不能创造也不能消灭，只能转移
  • 电荷量子化：Q = ne （n 为整数，e = 1.602×10⁻¹⁹ C）
  • 同种电荷相斥，异种电荷相吸

📌 库仑定律（高中版）

F = k · q₁q₂r²
其中 k = 9.0×10⁹ N·m²/C²

适用于真空中的两个静止点电荷。

📌 电场强度 E

E = Fq₀
（场强的定义式）
E = kQr²
（点电荷的场强）

📌 电场线与电势

  • 电场线从正电荷出发，终止于负电荷
  • 沿电场线方向电势降低
  • 等势面与电场线处处垂直
✅ 大学新视角： 高中学习的是 点电荷 的简单情况；大学物理引入 连续带电体 的电场计算（积分法），以及 高斯定理 求对称性电场。
高中 F = kq₁q₂r² → 大学用 ε₀ 表示：F = q₁q₂/(4πε₀r²)，意义相同但形式更统一。

⚡ 库伦定律与电场 · 大学深化

⚡ 库仑定律 [大学] Coulomb's Law

F₁₂ = 14πε₀ · (q₁q₂r²) · r̂

ε₀ = 8.85×10⁻¹² C²/(N·m²) 为真空介电常数
静电力常量 k = 1/(4πε₀) ≈ 9.0×10⁹ N·m²/C²

📌 电场强度的深入定义

E = Fq₀
（点电荷电场：E = 14πε₀ · (q/r²) · r̂）

📌 电场叠加原理（矢量积分）

E = ΣEᵢ（离散电荷系）
E = ∫dE（连续电荷系）

常见带电体的电场（大学要求计算）

带电体场点电场强度
均匀带电直线（无限长）距离 r 处E = λ2πε₀r
均匀带电平面（无限大）任意距离E = σ2ε₀
均匀带电圆环轴线上距离 xE = qx/(4πε₀(R²+x²)^{3/2})
均匀带电圆盘轴线上距离 xE = σ2ε₀ · (1 − x/√(R²+x²))

📌 电偶极子

电偶极矩：p = ql
（方向由 −q 指向 +q）
中垂线上电场：E = −p/(4πε₀r³)

电偶极子在均匀电场中受到力矩 M = p × E，有转向电场方向的趋势。

📐 高斯定理 [大学] Gauss's Law

💡 高斯定理是大学物理静电场部分的核心方法，高中完全没有涉及。 它建立了闭合曲面的电通量与面内电荷的直接关系。

📌 电通量

ΦE = ∮S E · dS

📌 高斯定理（积分形式）

∮S E · dS = (1/ε₀) · Σq内

利用高斯定理求解电场的关键步骤：

  1. 分析电场的对称性（球对称、轴对称、面对称）
  2. 选取合适的高斯面（使 E 垂直于或平行于面的各部分）
  3. 计算电通量
  4. 计算高斯面内包围的电荷

典型应用结果

电荷分布r < R (内部)r > R (外部)
均匀带电球面E = 0E = Q/(4πε₀r²)
均匀带电球体E = Qr/(4πε₀R³)E = Q/(4πε₀r²)
无限长均匀带电直线E = λ2πε₀r
无限大均匀带电平面E = σ2ε₀

📌 静电场环路定理

∮L E · dl = 0

表明静电场是保守场（无旋场）—— 电场力做功与路径无关。

⚡ 电势与静电场能量 [大学]

📌 电势能

Ep = q₀ ∫P参考点 E · dl

📌 电势

VP = Ep/q₀ = ∫P参考点 E · dl
点电荷电势：V = q/(4πε₀r)（无穷远为零势点）

📌 电势叠加原理

V = ΣVᵢ（离散）
V = ∫dV（连续）

📌 电场与电势梯度

E = −∇V = −(∂V/∂x i + ∂V/∂y j + ∂V/∂z k)

电场指向电势下降最快的方向。

📌 静电场能量

电容器储能：We = Q²2C = 12QU = 12CU²
电场能量密度：we = 12D·E = 12εE²
静电场总能量：We = ∫ we dV
✅ 关键理解： 能量定域于场中（而非电荷上）—— 这是大学物理强调的场的观点。

🔌 静电场中的导体与电介质 [大学]

📌 静电平衡条件

  • 导体内 E = 0，表面 E ⟂ 表面
  • 导体是等势体，表面是等势面
  • 电荷分布在表面，孤立导体面电荷密度与曲率有关（尖端放电）

📌 电介质极化

极化强度：P = ε₀χeE
束缚电荷面密度：σ′ = Pn = P·en
电位移矢量：D = ε₀E + P = ε₀εrE = εE 🌟 难点

介质中的高斯定理

∮S D · dS = Σq0内（自由电荷）

📌 电容器

类型电容
平行板电容器C = εS/d = ε₀εrS/d
圆柱形电容器C = 2πεL / ln(R₂/R₁)
球形电容器C = 4πεR₁R₂ / (R₂−R₁)
串联1/C = Σ(1/Cᵢ)
并联C = ΣCᵢ
🌟 难点：断开电源后插入电介质
电容器充电后断开电源，两极板间电荷 Q 保持不变（Q 不变）。
插入电介质（εr > 1）后的变化：
• 电容 C = εrC₀ 增大（ε 增大，C ∝ ε）
• 场强 E = Q/(εS) 减小（ε 增大，E 减小）
• 电位移 D = σ = Q/S 不变（D 只由自由电荷面密度决定）
• 能量 W = Q²/(2C) 减小（C 增大，W 减小）

📌 对比：不断电源的情况（电压 U 不变）：C ↑、E ↑、D ↑、W ↑（全部增大）
💡 记忆口诀：断电 Q 不变，D 不变，E/C/W 看 ε；不断电 U 不变，全增大。

📖 高中回顾 · 磁场基础

🧲 磁场基础回顾 [高中]

📌 磁场的产生

  • 磁铁周围存在磁场
  • 电流周围产生磁场（奥斯特实验）
  • 通电螺线管相当于条形磁铁

📌 安培定则（右手螺旋定则）

  • 通电直导线：右手拇指指向电流方向，四指弯曲方向为磁场方向
  • 通电螺线管：四指顺电流方向，拇指指向 N 极

📌 安培力

F = BIL sinθ
（高中版，仅适用于匀强磁场）

📌 洛伦兹力

f = qvB sinθ
方向：左手定则
  • 带电粒子在匀强磁场中做匀速圆周运动：r = mv/(qB)，T = 2πm/(qB)
✅ 大学新视角： 高中只学习匀强磁场中的简单情况；大学物理用 毕奥-萨伐尔定律 计算任意形状电流的磁场，用 安培环路定理 求解对称性磁场。
安培力推广为矢量积分形式：F = ∫L Idl × B。

🧲 比奥-萨法尔定律 & 恒定磁场

🧲 毕奥-萨伐尔定律 [大学] Biot–Savart Law

💡 毕奥-萨伐尔定律是大学物理计算电流磁场的基本方法，高中未涉及。 它给出了任意形状载流导线在空间产生磁场的计算方法。

⏳ 狭义相对论 [大学] Special Relativity

🔥 狭义相对论完全颠覆了经典时空观 — 高中未涉及，是大学物理最具革命性的内容。 核心思想：物理规律在所有惯性系中形式相同，且真空光速不变。

x′ = x − ut，y′ = y，z′ = z，t′ = t
v′ = v − u，a′ = a

📌 狭义相对论的两条基本假设

  1. 相对性原理：物理定律在所有惯性系中具有相同的数学形式
  2. 光速不变原理：在一切惯性系中，真空中的光速都具有相同的值 c

📌 洛伦兹变换 [核心]

x′ = γ(x − ut)，y′ = y，z′ = z
t′ = γ(t − ux/c²)
其中 γ = 1/√(1 − u²/c²) （洛伦兹因子）

对比项伽利略变换洛伦兹变换

📌 狭义相对论的三个重要效应

① 同时性的相对性 [颠覆常识]

在一个惯性系中同时发生在不同地点的事件，在另一个惯性系中观察 不同时。

Δt′ = γ(Δt − uΔx/c²)

当 Δt = 0（原系同时），若 Δx ≠ 0，则 Δt′ ≠ 0（另一系不同时）。

② 时间膨胀（动钟变慢）

τ = γτ₀ = τ₀/√(1 − u²/c²) > τ₀

τ₀ 为 固有时（在相对事件静止的参考系中测得的时间间隔）。运动时钟走得更慢。

✅ 经典例子： μ 子寿命延长实验 —— 高速 μ 子在大气层中的寿命比静止时更长，从而能到达地面。

③ 长度收缩（动尺变短）

L = L₀/γ = L₀√(1 − u²/c²) < L₀

L₀ 为 固有长度（在相对物体静止的参考系中测得的长度）。运动方向上的长度收缩，垂直方向不变。

⚠️ 注意： 长度收缩只发生在 运动方向上。物体本身没有发生形变，只是不同惯性系的测量结果不同。

📌 相对论速度变换

vx′ = (vx − u)/(1 − uvx/c²)
vy′ = vy/(γ(1 − uvx/c²))

当 u, v << c 时，退化为伽利略速度变换 v′ = v − u。

⚠️ 常见易错： 绝热自由膨胀中 Q = 0, A = 0, 因此 ΔE = 0, 温度不变。 但这不是准静态过程，不能使用 pVγ = const 公式！

📌 循环过程与热机效率

热机效率：η = A/Q₁ = (Q₁ − Q₂)/Q₁ = 1 − Q₂/Q₁
致冷系数：ω = Q₂/A = Q₂/(Q₁ − Q₂)
卡诺热机效率：ηc = 1 − T₂/T₁（只与高低温热源温度有关）
🌟 卡诺定理： 所有工作在两个恒温热源之间的热机，可逆热机的效率最高。 卡诺热机的效率只取决于两个热源的温度，与工作物质无关。

📌 热力学第二定律 [核心]

两种等价表述

  • 开尔文表述：不可能从单一热源吸收热量使之完全变为有用功而不产生其他影响
  • 克劳修斯表述：热量不可能自发地从低温物体传到高温物体

两种表述等价 —— 否定其中一种必然否定另一种。

📌 熵与熵增原理 🌟 难点

熵的定义：dS = dQ可逆/T
熵变计算：ΔS = ∫ dQ可逆/T
熵增原理：对孤立系统，ΔS ≥ 0（等号在可逆过程中成立）
  • 熵是 状态函数，与路径无关
  • 孤立系统的熵永不减少 —— 给出了热力学过程进行的方向
  • 熵的微观意义：系统无序度的量度（玻耳兹曼公式 S = k ln Ω）
📌 第一定律 vs 第二定律：
第一定律：能量守恒 —— 告诉你"能不能做"（能量上是否可行）
第二定律：方向性 —— 告诉你"能不能自发进行"（熵是否增加）
两者共同构成了完整的热力学理论基础。

📌 三、计算题回顾（典型题型）

📄 典型题型 1 · 刚体转动
1. 转动惯量与角动量守恒： 一水平圆盘（质量 M，半径 R，I = 12MR²）可绕中心轴无摩擦转动。 一质量为 m 的小球以水平速度 v₀ 沿圆盘边缘切线方向撞击并粘在边缘上。求碰撞后系统的角速度。
✅ 解题思路： 角动量守恒（对转轴）
碰前：L₁ = mv₀R（小球角动量）
碰后：L₂ = (12MR² + mR²)ω（盘 + 小球）
mv₀R = (12M + m)R²ω ⇒ ω = mv₀ / [(12M + m)R]
📄 典型题型 2 · 高斯定理
2. 均匀带电球体电场： 一半径为 R、总电量为 Q 的均匀带电球体。 求 (1) 球体外 r > R 处的电场强度； (2) 球体内 r < R 处的电场强度。
✅ 解：
(1) r > R：∮E·dS = Q/ε₀ ⇒ E·4πr² = Q/ε₀ ⇒ E = Q/(4πε₀r²)
(2) r < R：∮E·dS = ρ·(4/3πr³)/ε₀，其中 ρ = 3Q/(4πR³)
E·4πr² = Qr³/(ε₀R³) ⇒ E = Qr/(4πε₀R³)
📄 典型题型 3 · 安培环路定理
3. 无限长载流圆柱体： 一半径为 R 的无限长圆柱导体，通有均匀分布的电流 I。 求 (1) 圆柱外 r > R 的 B； (2) 圆柱内 r < R 的 B。
✅ 解：
(1) r > R：∮B·dl = μ₀I ⇒ B·2πr = μ₀I ⇒ B = μ₀I/(2πr)
(2) r < R：Ienc = I·πr²/πR² = Ir²/R²
B·2πr = μ₀Ir²/R² ⇒ B = μ₀Ir/(2πR²)
📄 典型题型 4 · 动生电动势
4. 导体棒在磁场中切割磁力线： 一长度为 L 的导体棒在垂直于均匀磁场 B 的平面内 以角速度 ω 绕其一端匀速转动。求棒两端的感应电动势。
✅ 解： 在距转轴 r 处取 dr，线速度 v = ωr
dℰ = (v × B)·dr = vBdr = Bωr dr
ℰ = ∫₀ᴸ Bωr dr = 12BωL²
📄 典型题型 5 · 电磁感应综合
5. 矩形线圈在磁场中运动： 一矩形线圈（宽 a，长 b，电阻 R）以速度 v 匀速进入均匀磁场 B 区域（磁场垂直于线圈平面）。求线圈进入过程中感应电流的大小和方向。
✅ 解： 进入时磁通量变化率：dΦdt = Bav
ℰ = Bav，I = Bav/R
方向：由楞次定律，线圈进入时磁通量增加，感应电流产生的磁场阻碍增加 → 逆时针方向。
📄 典型题型 6 · 磁矩与磁力矩
6. 载流线圈在磁场中： 一圆形线圈（半径 r = 0.1 m，I = 5 A）置于匀强磁场 B = 0.2 T 中，线圈平面与磁场方向夹角为 30°。求线圈所受磁力矩的大小。
✅ 解： 线圈磁矩 m = I·πr² = 5 × π × 0.01 ≈ 0.157 A·m²
线圈法线与 B 夹角 θ = 60°（线圈平面与 B 呈 30°）
M = mB sinθ = 0.157 × 0.2 × sin60° ≈ 0.0272 N·m
📄 典型题型 7 · 自感与磁场能量
7. 螺线管自感与储能： 一长直螺线管（长度 l = 0.5 m，截面积 S = 10 cm²， 总匝数 N = 1000）通有电流 I = 2 A。求 (1) 自感系数 L； (2) 磁场储能 Wm。
✅ 解： n = N/l = 2000 匝/m
L = μ₀n²V = 4π×10⁻⁷ × (2000)² × (0.5 × 10×10⁻⁴)
L ≈ 2.51×10⁻³ H = 2.51 mH
Wm = 12LI² = 12 × 2.51×10⁻³ × 4 ≈ 5.02×10⁻³ J
📄 典型题型 8 · 比奥-萨伐尔定律
8. 圆环电流轴线磁场： 一半径为 R 的圆形载流线圈通有电流 I。 求圆环轴线上距离中心 x 处的磁感应强度。
✅ 解： 由对称性，dB 的垂直分量抵消，只有沿轴线分量
dB∥ = (μ₀/4π)(Idl/r²)sinα，其中 sinα = R/√(R²+x²)，r² = R²+x²
B = ∫dB∥ = (μ₀/4π)·IR/(R²+x²)^{3/2} · ∫dl
= (μ₀/4π)·IR/(R²+x²)^{3/2} · 2πR
= μ₀IR²/[2(R²+x²)^{3/2}]
当 x = 0（圆心）：B = μ₀I/(2R)
