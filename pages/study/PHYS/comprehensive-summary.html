📖 高中回顾 · 力学基础

📐 运动学与牛顿力学 [高中]

以下内容为高中物理已学过的力学基础，大学物理在此基础上深化扩展。

📌 质点运动学

v = v₀ + at
x = x₀ + v₀t + 12at²
v² − v₀² = 2a(x−x₀)

📌 牛顿三定律

  • 惯性定律： F = 0 ⇒ v = const
  • F = ma （牛顿第二定律，力的瞬时作用）
  • 作用与反作用： F₁₂ = −F₂₁

📌 常见的力

  • 万有引力：F = G m₁m₂/r², G = 6.67×10⁻¹¹ N·m²/kg²
  • 重力：G = mg, g ≈ 9.8 m/s²
  • 弹簧弹力（胡克定律）：F = −kx
  • 摩擦力：fₘₐₓ = μₛN, fₖ = μₖN

📌 动量与冲量

p = mv
I = ∫F dt = Δp = mv₂ − mv₁

动量守恒：∑F外 = 0 ⇒ p = const

📌 功与能

  • 动能 Eₖ = 12mv²，动能定理 W = ΔEₖ
  • 重力势能 Eₚ = mgh，弹性势能 Eₚ = 12kx²
  • 机械能守恒：只有保守力做功时，Eₖ + Eₚ = const
🌟 难点：保守力与势能的关系
保守力等于势能函数对距离 r 的负导数（一维）或负梯度（三维）：
F = −dEp/dr（一维） ⟹ F = −∇Ep（三维）
推导：保守力做功 W = ∫F·dr = −ΔEp ⇒ F·dr = −dEp ⇒ F = −dEp/dr
经典例子：
• 弹簧弹力：F = −kx = −d(½kx²)/dx ← 弹性势能 ½kx² 的负导数
• 万有引力：F = −GMm/r² = −d(−GMm/r)/dr ← 引力势能 −GMm/r 的负导数
• 重力：F = −mg = −d(mgh)/dh ← 重力势能 mgh 的负导数（一维近似）
✅ 大学新视角： 中学学的 F = ma 是 F = dpdt 在 m 为常量时的特例。 大学物理强调 F = dpdt 的微分形式，并引入 质心运动定理：∑F外 = MaC。

⚙️ 刚体定轴转动

⚙️ 刚体定轴转动 [大学] Rigid Body Rotation

💡 刚体定义： 在外力作用下形状和大小保持不变的理想物体 —— 任意两质点间距离恒定。 这是大学物理引入的第一个理想模型，中学未系统学习。

📌 定轴转动的运动学

ω = dθdt
α = dωdt = d²θdt²
s = Rθ
v = Rω
aτ = Rα
an = Rω²

匀角加速转动：

ω = ω₀ + αt
θ = θ₀ + ω₀t + 12αt²
ω² − ω₀² = 2α(θ−θ₀)

📌 转动惯量 [核心]

转动惯量 I 描述刚体转动惯性的大小，相当于平动中的质量。取决于 质量分布 和 转轴位置。

I = Σ mᵢ rᵢ²
⟹ I = ∫ r² dm

常见刚体的转动惯量

刚体类型转轴位置转动惯量
细圆环过中心垂直轴I = MR²
圆盘/圆柱过中心轴I = 12MR²
细棒过中心垂直轴I = 112ML²
细棒过端点垂直轴I = 13ML²
球壳直径轴I = 23MR²
球体直径轴I = 25MR²

平行轴定理

I = IC + M d²

其中 IC 为过质心轴的转动惯量，d 为两平行轴间的距离。

⚠️ 注意： 平行轴定理必须从 质心轴 出发！只能从质心轴 → 其他平行轴，不能反向。

📌 转动定律 [核心]

M = Iα = I · (dωdt)

转动定律 是牛顿第二定律在转动中的对应：合外力矩 ≠ 0 → 刚体获得角加速度。

力矩定义：M = r × F，方向由右手螺旋定则确定。

📌 刚体角动量

L = Iω
→ M = dLdt
→ ∫M dt = ΔL = Iω₂ − Iω₁

📌 角动量守恒定律 [重要]

M外 = 0 ⇒ L = Iω = const
⟹ I₁ω₁ = I₂ω₂
  • 经典例子：花样滑冰运动员收臂加速旋转；转椅上的哑铃实验
  • 猫在空中翻身、陀螺仪的定向性

📌 转动动能 & 功

Eₖ = 12Iω²
dW = M dθ
W = 12Iω₂² − 12Iω₁²

刚体 + 质点系统的机械能守恒（含重力势能 mghC）。

📌 纯滚动条件

vC = Rω
aC = Rα

纯滚动 = 无滑滚动，接触点瞬时速度为零。

📌 打击中心 (Center of Percussion)

当外力作用于刚体上的特定位置时，转轴处不受冲击力，该位置称为打击中心（COP）。

d = ICM·h + h

其中 h 为质心到转轴的距离。应用：棒球棒、门把手设计（安装在打击中心处手感最好）。

📖 高中回顾 · 静电基础

⚡ 静电学基础回顾 [高中]

📌 电荷基本性质

  • 电荷守恒定律：电荷既不能创造也不能消灭，只能转移
  • 电荷量子化：Q = ne （n 为整数，e = 1.602×10⁻¹⁹ C）
  • 同种电荷相斥，异种电荷相吸

📌 库仑定律（高中版）

F = k · q₁q₂r²
其中 k = 9.0×10⁹ N·m²/C²

适用于真空中的两个静止点电荷。

📌 电场强度 E

E = Fq₀
（场强的定义式）
E = kQr²
（点电荷的场强）

📌 电场线与电势

  • 电场线从正电荷出发，终止于负电荷
  • 沿电场线方向电势降低
  • 等势面与电场线处处垂直
✅ 大学新视角： 高中学习的是 点电荷 的简单情况；大学物理引入 连续带电体 的电场计算（积分法），以及 高斯定理 求对称性电场。
高中 F = kq₁q₂r² → 大学用 ε₀ 表示：F = q₁q₂/(4πε₀r²)，意义相同但形式更统一。

⚡ 库伦定律与电场 · 大学深化

⚡ 库仑定律 [大学] Coulomb's Law

F₁₂ = 14πε₀ · (q₁q₂r²) · r̂

ε₀ = 8.85×10⁻¹² C²/(N·m²) 为真空介电常数
静电力常量 k = 1/(4πε₀) ≈ 9.0×10⁹ N·m²/C²

📌 电场强度的深入定义

E = Fq₀
（点电荷电场：E = 14πε₀ · (q/r²) · r̂）

📌 电场叠加原理（矢量积分）

E = ΣEᵢ（离散电荷系）
E = ∫dE（连续电荷系）

常见带电体的电场（大学要求计算）

带电体场点电场强度
均匀带电直线（无限长）距离 r 处E = λ2πε₀r
均匀带电平面（无限大）任意距离E = σ2ε₀
均匀带电圆环轴线上距离 xE = qx/(4πε₀(R²+x²)^{3/2})
均匀带电圆盘轴线上距离 xE = σ2ε₀ · (1 − x/√(R²+x²))

📌 电偶极子

电偶极矩：p = ql
（方向由 −q 指向 +q）
中垂线上电场：E = −p/(4πε₀r³)

电偶极子在均匀电场中受到力矩 M = p × E，有转向电场方向的趋势。

📐 高斯定理 [大学] Gauss's Law

💡 高斯定理是大学物理静电场部分的核心方法，高中完全没有涉及。 它建立了闭合曲面的电通量与面内电荷的直接关系。

📌 电通量

ΦE = ∮S E · dS

📌 高斯定理（积分形式）

∮S E · dS = (1/ε₀) · Σq内

利用高斯定理求解电场的关键步骤：

  1. 分析电场的对称性（球对称、轴对称、面对称）
  2. 选取合适的高斯面（使 E 垂直于或平行于面的各部分）
  3. 计算电通量
  4. 计算高斯面内包围的电荷

典型应用结果

电荷分布r < R (内部)r > R (外部)
均匀带电球面E = 0E = Q/(4πε₀r²)
均匀带电球体E = Qr/(4πε₀R³)E = Q/(4πε₀r²)
无限长均匀带电直线E = λ2πε₀r
无限大均匀带电平面E = σ2ε₀

📌 静电场环路定理

∮L E · dl = 0

表明静电场是保守场（无旋场）—— 电场力做功与路径无关。

⚡ 电势与静电场能量 [大学]

📌 电势能

Ep = q₀ ∫P参考点 E · dl

📌 电势

VP = Ep/q₀ = ∫P参考点 E · dl
点电荷电势：V = q/(4πε₀r)（无穷远为零势点）

📌 电势叠加原理

V = ΣVᵢ（离散）
V = ∫dV（连续）

📌 电场与电势梯度

E = −∇V = −(∂V/∂x i + ∂V/∂y j + ∂V/∂z k)

电场指向电势下降最快的方向。

📌 静电场能量

电容器储能：We = Q²2C = 12QU = 12CU²
电场能量密度：we = 12D·E = 12εE²
静电场总能量：We = ∫ we dV
✅ 关键理解： 能量定域于场中（而非电荷上）—— 这是大学物理强调的场的观点。

🔌 静电场中的导体与电介质 [大学]

📌 静电平衡条件

  • 导体内 E = 0，表面 E ⟂ 表面
  • 导体是等势体，表面是等势面
  • 电荷分布在表面，孤立导体面电荷密度与曲率有关（尖端放电）

📌 电介质极化

极化强度：P = ε₀χeE
束缚电荷面密度：σ′ = Pn = P·en
电位移矢量：D = ε₀E + P = ε₀εrE = εE 🌟 难点

介质中的高斯定理

∮S D · dS = Σq0内（自由电荷）

📌 电容器

类型电容
平行板电容器C = εS/d = ε₀εrS/d
圆柱形电容器C = 2πεL / ln(R₂/R₁)
球形电容器C = 4πεR₁R₂ / (R₂−R₁)
串联1/C = Σ(1/Cᵢ)
并联C = ΣCᵢ
🌟 难点：断开电源后插入电介质
电容器充电后断开电源，两极板间电荷 Q 保持不变（Q 不变）。
插入电介质（εr > 1）后的变化：
• 电容 C = εrC₀ 增大（ε 增大，C ∝ ε）
• 场强 E = Q/(εS) 减小（ε 增大，E 减小）
• 电位移 D = σ = Q/S 不变（D 只由自由电荷面密度决定）
• 能量 W = Q²/(2C) 减小（C 增大，W 减小）

📌 对比：不断电源的情况（电压 U 不变）：C ↑、E ↑、D ↑、W ↑（全部增大）
💡 记忆口诀：断电 Q 不变，D 不变，E/C/W 看 ε；不断电 U 不变，全增大。

📖 高中回顾 · 磁场基础

🧲 磁场基础回顾 [高中]

📌 磁场的产生

  • 磁铁周围存在磁场
  • 电流周围产生磁场（奥斯特实验）
  • 通电螺线管相当于条形磁铁

📌 安培定则（右手螺旋定则）

  • 通电直导线：右手拇指指向电流方向，四指弯曲方向为磁场方向
  • 通电螺线管：四指顺电流方向，拇指指向 N 极

📌 安培力

F = BIL sinθ
（高中版，仅适用于匀强磁场）

📌 洛伦兹力

f = qvB sinθ
方向：左手定则
  • 带电粒子在匀强磁场中做匀速圆周运动：r = mv/(qB)，T = 2πm/(qB)
✅ 大学新视角： 高中只学习匀强磁场中的简单情况；大学物理用 毕奥-萨伐尔定律 计算任意形状电流的磁场，用 安培环路定理 求解对称性磁场。
安培力推广为矢量积分形式：F = ∫L Idl × B。

🧲 比奥-萨法尔定律 & 恒定磁场

🧲 毕奥-萨伐尔定律 [大学] Biot–Savart Law

💡 毕奥-萨伐尔定律是大学物理计算电流磁场的基本方法，高中未涉及。 它给出了任意形状载流导线在空间产生磁场的计算方法。

📌 基本定律

dB = (μ₀/4π) · (I dl × r̂) / r²

μ₀ = 4π×10⁻⁷ T·m/A 为真空磁导率，方向由右手螺旋定则判断。

📌 常见电流构型的磁场

电流构型磁感应强度 B
无限长直导线B = μ₀I/(2πr)
半无限长直导线端点B = μ₀I/(4πr)
有限长直导线B = (μ₀I)/(4πd)·(sinθ₂−sinθ₁)
圆形电流圆心B = μ₀I/(2R)
圆环轴线（距离 x）B = μ₀IR²/[2(R²+x²)^{3/2}]
长直螺线管内部B = μ₀nI（n 为单位长度匝数）

📌 磁场的高斯定理

∮S B · dS = 0

表明 磁场是无源场，不存在磁单极子，磁感线总是闭合的。

📌 磁通量

ΦB = ∫S B · dS

🔄 安培环路定理 [大学] Ampère's Circuital Law

∮L B · dl = μ₀ ΣI内
（真空中的安培环路定理）

磁场 B 沿任意闭合回路的环量 = μ₀ × 穿过回路所围曲面的电流代数和。

📌 与高斯定理的对比

定理积分形式含义适用对称性
电场高斯定理∮ E·dS = Q/ε₀电荷是电场的源球、轴、面对称
磁场高斯定理∮ B·dS = 0无磁单极—
静电场环路∮ E·dl = 0静电场保守—
安培环路定理∮ B·dl = μ₀I电流是磁场的源轴、面对称

典型应用

  • 无限长直导线：B·2πr = μ₀I ⇒ B = μ₀I/(2πr)
  • 长直螺线管：B = μ₀nI
  • 环形螺线管：B = μ₀NI/(2πr)
⚠️ 使用安培环路定理的关键： 必须选择适当的安培环路，使 B 在回路上为常数或方向已知。 与高斯定理类似，只能处理对称性较高的问题。

🧲 磁场对电流的作用 [大学]

📌 安培力（矢量积分形式）

dF = I dl × B
F = ∫L I dl × B

📌 平行载流导线间的作用力

F/l = μ₀ I₁I₂/(2πd)

同向电流相互吸引，反向电流相互排斥。

📌 洛伦兹力

F = q(E + v × B)

这是完整的洛伦兹力公式，包含电场力和磁场力两部分，高中只学过磁场部分。

带电粒子在匀强磁场中的运动

速度方向运动形式
v ∥ B匀速直线运动
v ⟂ B匀速圆周运动：r = mv/(qB)，T = 2πm/(qB)
v 与 B 成 θ 角螺旋线运动（回旋半径 r = mvsinθ/(qB)，螺距 h = vcosθ·T）

🧲 磁矩

🧲 磁矩 [大学] Magnetic Moment

💡 磁矩是大学物理引入的重要概念，高中未涉及。 载流线圈的磁性强弱由磁矩描述，这是理解磁介质和原子磁性的基础。

📌 载流线圈的磁矩

m = I · S · n̂
→ |m| = I · S（面积）

方向：右手定则 — 四指顺电流方向，拇指指向磁矩方向（与线圈法向一致）。

📌 磁力矩 🌟 难点

M = m × B
→ τ = mB sinθ

θ 为 m 与 B 的夹角。磁矩有转向外磁场方向的趋势：θ = 0 时稳定平衡，θ = π 时不稳定平衡。

📌 磁势能

Um = −m · B = −mB cosθ

磁矩与外磁场同向时势能最小（θ=0, U=−mB），反向时最大。

📌 磁矩的三种来源

来源描述公式
载流线圈通电回路的宏观磁性m = IS
运动电荷（圆周）电荷做圆周运动产生m = qvr/2 = qωr²/2
均匀磁化体磁化强度 = 单位体积磁矩M = dmdV

📌 磁矩与角动量的关系

m = (q/2m) · L
（对做圆周运动的带电粒子）

回磁比 γ = q/(2m)，这是原子物理的重要基础。

🔄 H 安环 & 磁介质

🔄 磁介质 & H 的安培环路定理 [大学] Magnetic Media & H-field

💡 磁介质是大学物理的全新内容，高中完全未涉及。 引入辅助场量 H 来简化磁介质中的磁场计算。

📌 磁化强度 M

M = dmdV
（单位体积的磁矩）
M = χmH
（各向同性线性介质）

📌 磁场强度 H

H = B/μ₀ − M
→ B = μ₀(H + M) = μH

μ = μ₀μr 为磁导率，μr = 1 + χm 为相对磁导率。

📌 H 的安培环路定理 [核心] 🌟 难点

∮L H · dl = ΣIf  （仅计自由电流）
⚠️ 关键区别：环流定义 & 两类电流
• 环流（Circulation）： 矢量场沿闭合回路的线积分 ∮A·dl，描述场的有旋性
• H 的环流 = 自由电流 If；B 的环流 = μ₀(If + Im)（含磁化电流）
• 传导电流 Ic： 自由电荷在导体中的定向运动，产生焦耳热
• 磁化电流 Im： 介质磁化产生的等效束缚电流，不产生焦耳热
• 使用 H 安环的优势：只需知道自由电流，磁化电流已隐含在 B = μH 中

B 安环 vs H 安环

对比项B 的安培环路定理H 的安培环路定理
表达式∮B·dl = μ₀(If + Im)∮H·dl = If
包含的电流自由电流 + 磁化电流仅自由电流

适用场景真空中磁介质中（更实用）

📌 铁磁质的特点

  • μr 远大于 1，非线性关系
  • 存在磁滞回线（Hysteresis Loop）：剩磁 Br、矫顽力 Hc
  • 软磁材料（磁滞回线窄）：易磁化也易退磁 → 电磁铁、变压器
  • 硬磁材料（磁滞回线宽）：剩磁大 → 永磁体

📌 应用场景

  • 无限长直导线在介质中：H = I/(2πr)，B = μ₀μrI/(2πr)
  • 螺绕环：H = NI/(2πr)，B = μH
  • 电磁铁：软铁芯中 H ≈ NI/l，B = μH 远大于空心螺线管
⚠️ 注意： H 环路上的 If 只计自由电流，介质磁化产生的磁化电流不计入。 求 B 时需知道 μr 或介质的磁化状态。

📌 位移电流 [核心贡献] 🌟 难点

📌 积分形式

📌 每个方程的物理意义

🌟 难点：四个基本矢量场的性质（有源/无源 & 有旋/无旋）
从麦克斯韦方程组理解四个场的"源"与"旋"特性：

① 电场 E：有源无旋场
∮S E·dS = Q/ε₀（有源：电荷是源） ∮L E·dl = 0（无旋：静电场保守）

② 磁场 B：无源有旋场
∮S B·dS = 0（无源：无磁单极） ∮L B·dl = μ₀I（有旋：电流是涡旋源）

③ 电位移 D：有源无旋场
∮S D·dS = Q₀（有源：自由电荷是源） 在静场中 ∮L D·dl = 0（无旋）

④ 磁场强度 H：无源有旋场
∮S H·dS = 0（无源） ∮L H·dl = If（有旋：自由电流是涡旋源）

📌 注意：变化情况下（电磁感应），E 变得有旋（涡旋电场），D 的变化产生位移电流。
  • ① 电场高斯定理： 电荷是电场的源 — 电场线始于正电荷终于负电荷（有源场）
  • ② 磁场高斯定理： 磁单极不存在 — 磁感线总是闭合的（无源场）
  • ③ 法拉第定律： 变化的磁场激发涡旋电场（磁生电）
  • ④ 安培-麦克斯韦定律： 传导电流 或 变化的电场激发磁场（电生磁 + 位移电流修正）

📌 方程组的对称性

加上位移电流后，方程组在数学上完美对称：

  • 变化的磁场 → 电场（③）
  • 变化的电场 → 磁场（④）
  • 电磁交替激发 → 电磁波在空间传播
💡 麦克斯韦的伟大贡献： 在安培环路定理中引入位移电流，使方程组自洽，并预言了电磁波的存在。 电磁波在真空中的速度 c = 1/√(ε₀μ₀) ≈ 3×10⁸ m/s，与光速相等 ⇒ 光就是电磁波。

📌 三、计算题回顾（典型题型）

📄 典型题型 1 · 刚体转动
1. 转动惯量与角动量守恒： 一水平圆盘（质量 M，半径 R，I = 12MR²）可绕中心轴无摩擦转动。 一质量为 m 的小球以水平速度 v₀ 沿圆盘边缘切线方向撞击并粘在边缘上。求碰撞后系统的角速度。
✅ 解题思路： 角动量守恒（对转轴）
碰前：L₁ = mv₀R（小球角动量）
碰后：L₂ = (12MR² + mR²)ω（盘 + 小球）
mv₀R = (12M + m)R²ω ⇒ ω = mv₀ / [(12M + m)R]
📄 典型题型 2 · 高斯定理
2. 均匀带电球体电场： 一半径为 R、总电量为 Q 的均匀带电球体。 求 (1) 球体外 r > R 处的电场强度； (2) 球体内 r < R 处的电场强度。
✅ 解：
(1) r > R：∮E·dS = Q/ε₀ ⇒ E·4πr² = Q/ε₀ ⇒ E = Q/(4πε₀r²)
(2) r < R：∮E·dS = ρ·(4/3πr³)/ε₀，其中 ρ = 3Q/(4πR³)
E·4πr² = Qr³/(ε₀R³) ⇒ E = Qr/(4πε₀R³)
📄 典型题型 3 · 安培环路定理
3. 无限长载流圆柱体： 一半径为 R 的无限长圆柱导体，通有均匀分布的电流 I。 求 (1) 圆柱外 r > R 的 B； (2) 圆柱内 r < R 的 B。
✅ 解：
(1) r > R：∮B·dl = μ₀I ⇒ B·2πr = μ₀I ⇒ B = μ₀I/(2πr)
(2) r < R：Ienc = I·πr²/πR² = Ir²/R²
B·2πr = μ₀Ir²/R² ⇒ B = μ₀Ir/(2πR²)
📄 典型题型 4 · 动生电动势
4. 导体棒在磁场中切割磁力线： 一长度为 L 的导体棒在垂直于均匀磁场 B 的平面内 以角速度 ω 绕其一端匀速转动。求棒两端的感应电动势。
✅ 解： 在距转轴 r 处取 dr，线速度 v = ωr
dℰ = (v × B)·dr = vBdr = Bωr dr
ℰ = ∫₀ᴸ Bωr dr = 12BωL²
📄 典型题型 5 · 电磁感应综合
5. 矩形线圈在磁场中运动： 一矩形线圈（宽 a，长 b，电阻 R）以速度 v 匀速进入均匀磁场 B 区域（磁场垂直于线圈平面）。求线圈进入过程中感应电流的大小和方向。
✅ 解： 进入时磁通量变化率：dΦdt = Bav
ℰ = Bav，I = Bav/R
方向：由楞次定律，线圈进入时磁通量增加，感应电流产生的磁场阻碍增加 → 逆时针方向。
📄 典型题型 6 · 磁矩与磁力矩
6. 载流线圈在磁场中： 一圆形线圈（半径 r = 0.1 m，I = 5 A）置于匀强磁场 B = 0.2 T 中，线圈平面与磁场方向夹角为 30°。求线圈所受磁力矩的大小。
✅ 解： 线圈磁矩 m = I·πr² = 5 × π × 0.01 ≈ 0.157 A·m²
线圈法线与 B 夹角 θ = 60°（线圈平面与 B 呈 30°）
M = mB sinθ = 0.157 × 0.2 × sin60° ≈ 0.0272 N·m
📄 典型题型 7 · 自感与磁场能量
7. 螺线管自感与储能： 一长直螺线管（长度 l = 0.5 m，截面积 S = 10 cm²， 总匝数 N = 1000）通有电流 I = 2 A。求 (1) 自感系数 L； (2) 磁场储能 Wm。
✅ 解： n = N/l = 2000 匝/m
L = μ₀n²V = 4π×10⁻⁷ × (2000)² × (0.5 × 10×10⁻⁴)
L ≈ 2.51×10⁻³ H = 2.51 mH
Wm = 12LI² = 12 × 2.51×10⁻³ × 4 ≈ 5.02×10⁻³ J
📄 典型题型 8 · 比奥-萨伐尔定律
8. 圆环电流轴线磁场： 一半径为 R 的圆形载流线圈通有电流 I。 求圆环轴线上距离中心 x 处的磁感应强度。
✅ 解： 由对称性，dB 的垂直分量抵消，只有沿轴线分量
dB∥ = (μ₀/4π)(Idl/r²)sinα，其中 sinα = R/√(R²+x²)，r² = R²+x²
B = ∫dB∥ = (μ₀/4π)·IR/(R²+x²)^{3/2} · ∫dl
= (μ₀/4π)·IR/(R²+x²)^{3/2} · 2πR
= μ₀IR²/[2(R²+x²)^{3/2}]
当 x = 0（圆心）：B = μ₀I/(2R)
