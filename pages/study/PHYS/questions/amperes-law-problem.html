H 形式的安培环路定理 · 磁介质中的磁场
综合题 · 14分
📘 来源：重庆大学 · 大学物理III (PHYS10016) · 2025春 A卷 改编 📌 考点：H 安培环路定理 · 磁介质 · 磁通量 ⏱ 建议用时：15 分钟
📝 题目

如图所示，一个密绕螺线环（环形螺线管）内充满磁导率为 μ 的均匀磁介质。 螺线环上绕有 N 匝线圈，通有恒定电流 I。 环的截面为圆形，半径为 a（a 远小于环的平均半径 R，即 R ≫ a）。

取环内与环共轴的半径为 r 的圆形闭合回路 L（a < r < R - a），绕行方向为逆时针（如图）。

图：螺线环剖面及安培环路 L（左） / 立体示意（右）

(1) 写出 H 的安培环路定理 的表达式，并说明式中各物理量的含义。

(2) 利用 H 的安培环路定理，求环内磁介质中的磁场强度 H 的分布（大小与方向）。

(3) 求环内磁介质中的磁感应强度 B 的分布（大小与方向）。

(4) 求穿过螺线环圆形截面的磁通量 Φm。

已知 真空磁导率 μ0，磁介质相对磁导率 μr = μ / μ0。
📐 解题过程
(1) H 的安培环路定理

在稳恒磁场中，磁场强度 H 沿任意闭合路径 L 的线积分，等于该闭合路径所包围的 传导电流 的代数和：

∮L H · dl = Σ I传
  • H：磁场强度 (A/m)，由传导电流和磁化电流共同决定，但环流只与传导电流有关；
  • dl：闭合路径 L 上的线元矢量，方向与路径绕行方向一致；
  • Σ I传：闭合路径 L 所包围的 传导电流 的代数和（按右手螺旋定则确定正负）。
💡 说明： H 的安培环路定理与 B 的安培环路定理 (∮L B · dl = μ0 Σ I) 本质等价，但 H 形式将磁介质的贡献吸收到 μ 中，使表达式更简洁。
(2) 求磁场强度 H 分布

取环内半径为 r 的圆形闭合路径 L，绕行方向为逆时针（与电流方向一致）。 由于螺线环的对称性，环内 H 的大小在半径为 r 的圆周上处处相等，方向沿圆周切线方向（逆时针）。

路径 L 包围的传导电流为 N I（所有匝线圈的电流均穿过该路径所围面积）。 由 H 的安培环路定理：

∮L H · dl = H · 2π r = N I

因此，环内磁介质中的磁场强度大小为：

H = N I2π r （方向：沿圆周逆时针切线方向）

⚠️ H 与 r 成反比，在环内不同半径处 H 的大小不同（但 R ≫ a 时近似均匀）。

(3) 求磁感应强度 B 分布

在各向同性均匀磁介质中，B = μ H，其中 μ = μ0 μr。 因此环内磁介质中的磁感应强度大小为：

B = μ H = μ N I2π r （方向：沿圆周逆时针切线方向）

🔄 若环内为真空（μr = 1），则 B0 = μ0 N I / (2π r)。

(4) 求穿过截面的磁通量 Φm

由于 R ≫ a，可近似认为环内 B 在截面上均匀，取 r ≈ R（平均半径处）。 穿过截面的磁通量：

Φm = B · S = μ N I2π R · (π a2) = μ N I a22 R

📌 若考虑 B 随 r 的变化，严格积分：Φm = ∫S B · dS = ∫R-aR+a μ N I2π r · (2√(a2 - (r-R)2)) dr，在 a ≪ R 时近似为上式。

✅ 答案

(1) H 的安培环路定理： ∮L H · dl = Σ I传

(2) H 分布： H = N I / (2π r)，方向沿逆时针切线方向。

(3) B 分布： B = μ N I / (2π r)，方向沿逆时针切线方向。

(4) 磁通量： Φm = μ N I a2 / (2 R)（近似）

核心考点 H 安培环路定理 磁介质 磁通量

📖 拓展思考： ① 若螺线环内为 铁磁质（μr 非常大且非线性），则 B 与 H 的关系为 B = μ(H) H，需使用磁化曲线（B-H 曲线）求解。 ② 本题中 H 的环流 仅与传导电流 N I 有关，与磁介质无关，这正是 H 安培环路定理的优越性。
