曲面法向量的核心求解方法

重积分与线面积分

📥 下载 PDF 原文

一、曲面法向量概述

曲面的法向量是垂直于曲面切平面的向量，在曲面积分中有着至关重要的地位。无论是第一型曲面积分（对面积的曲面积分）还是第二型曲面积分（对坐标的曲面积分），都需要明确曲面的法向量方向。

根据曲面的表达方式不同，法向量的计算方法也分为三类：

曲面表达形式示例法向量求法
显式方程 z = f(x,y)z = x² + y²梯度法：(−fx, −fy, 1)
隐式方程 F(x,y,z) = 0x² + y² + z² = R²梯度法：∇F = (Fx, Fy, Fz)
参数方程 r(u,v)r = (u,v,u²+v²)叉积法：ru × rv

二、隐式方程 F(x,y,z) = 0 的法向量

1. 方法原理

对于由隐式方程 F(x,y,z) = 0 定义的曲面，法向量由梯度给出：

n = ∇F = (∂F/∂x, ∂F/∂y, ∂F/∂z)

2. 单位法向量

n° = ∇F / |∇F| = (Fx, Fy, Fz) / √(Fx² + Fy² + Fz²)

3. 常用曲面的法向量

曲面方程法向量 n
x² + y² + z² = R²（球面）(2x, 2y, 2z) ∥ (x, y, z)
x²/a² + y²/b² + z²/c² = 1（椭球面）(2x/a², 2y/b², 2z/c²)
z − f(x,y) = 0（显式曲面的隐式形式）(−fx, −fy, 1)
Ax + By + Cz + D = 0（平面）(A, B, C)（常向量）
注意方向： ∇F 指向 F 值增加的方向（即函数值增大最快的方向）。对于闭合曲面（如球面 x²+y²+z²=R²），取 F = x²+y²+z²−R²，∇F 指向外侧；若取 F = R²−x²−y²−z²，则指向内侧。

三、显式方程 z = f(x,y) 的法向量

1. 方法推导

将显式方程改写为隐式形式 F(x,y,z) = z − f(x,y) = 0，则：

n = (−∂f/∂x, −∂f/∂y, 1) = (−fx, −fy, 1)

2. 指向判定

  • 上侧法向量：n上 = (−fx, −fy, 1)（竖直分量 > 0，指向 z 轴正向）
  • 下侧法向量：n下 = (fx, fy, −1)（竖直分量 < 0，指向 z 轴负向）

3. 面积微元与方向余弦

dS = √(1 + fx² + fy²) dxdy

单位法向量的方向余弦：

cos α = −fx / √(1 + fx² + fy²)
cos β = −fy / √(1 + fx² + fy²)
cos γ = 1 / √(1 + fx² + fy²)

(cos α, cos β, cos γ) 即为上侧单位法向量。

4. 推广到其他显式形式

  • x = g(y,z)：法向量 (1, −gy, −gz)
  • y = h(x,z)：法向量 (−hx, 1, −hz)

四、参数方程 r(u,v) 的法向量

1. 方法原理

若曲面由参数方程 r(u,v) = (x(u,v), y(u,v), z(u,v)) 给出，则两个切向量分别为：

ru = (∂x/∂u, ∂y/∂u, ∂z/∂u)
rv = (∂x/∂v, ∂y/∂v, ∂z/∂v)

法向量由这两个切向量的叉积给出：

n = ru × rv

2. 叉积展开式

ru × rv = ∣ i    j    k ∣
∣ xu yu zu ∣
∣ xv yv zv ∣

= (yu zv − zu yv, zu xv − xu zv, xu yv − yu xv)

3. 参数曲面的面积微元

dS = |ru × rv| du dv

4. 常用曲面的参数化

曲面参数化ru × rv
球面 x²+y²+z²=R² r(θ,φ) = (R sin φ cos θ, R sin φ sin θ, R cos φ)
0≤θ<2π, 0≤φ≤π		 (R² sin² φ cos θ, R² sin² φ sin θ, R² sin φ cos φ)
|rθ × rφ| = R² sin φ
柱面 x²+y²=R² r(θ,z) = (R cos θ, R sin θ, z)
0≤θ<2π		 (R cos θ, R sin θ, 0)
|rθ × rz| = R
圆锥面 z = √(x²+y²) r(r,θ) = (r cos θ, r sin θ, r)
r≥0, 0≤θ<2π		 (−r cos θ, −r sin θ, r)
|rr × rθ| = r√2

五、法向量在曲面积分中的应用

1. 第一型曲面积分（对面积的曲面积分）

∬Σ f(x,y,z) dS = ∬D f(x,y,z(x,y)) √(1 + zx² + zy²) dxdy

其中 dS = √(1 + fx² + fy²) dxdy 即为法向量模长的几何意义。

2. 第二型曲面积分（对坐标的曲面积分）

∬Σ P dy∧dz + Q dz∧dx + R dx∧dy = ∬Σ (F · n) dS

其中 n 为指定侧的单位法向量。转换为投影计算：

∬Σ R dx∧dy = ∬Dxy R(x,y,z(x,y)) · (±1) dxdy

符号选择： 取上侧时为正，下侧时为负。

3. 高斯公式（散度定理）

高斯公式建立了第二型曲面积分和三重积分之间的桥梁：

∯∂Ω F · dS = ∭Ω (∇ · F) dV

其中 ∂Ω 取外侧法向量，∇ · F = ∂P/∂x + ∂Q/∂y + ∂R/∂z 为向量场 F 的散度。

关键技巧： 在处理第二型曲面积分时，一定要明确曲面的侧（外侧/内侧、上侧/下侧、前侧/后侧），这决定了法向量的方向和积分结果的符号。

六、典型例题

例 1（球面法向量）： 求球面 x² + y² + z² = 4 在点 (1,1,√2) 处的上侧单位法向量。

解： 令 F(x,y,z) = x² + y² + z² − 4
∇F = (2x, 2y, 2z)，在 (1,1,√2) 处为 (2, 2, 2√2)
|∇F| = √(4 + 4 + 8) = 4
单位法向量 n° = (2/4, 2/4, 2√2/4) = (1/2, 1/2, √2/2)
由于该点处 z > 0 且第三个分量为正，即为上侧外法向。
例 2（参数曲面法向量）： 求参数曲面 r(u,v) = (u cos v, u sin v, v)（螺旋面）在点 (u=1, v=0) 处的法向量。

解： ru = (cos v, sin v, 0)
rv = (−u sin v, u cos v, 1)
在 (1,0) 处：ru = (1,0,0)，rv = (0,1,1)
n = ru × rv = (0, −1, 1)
例 3（曲面积分中的应用）： 计算第二型曲面积分 ∬Σ x dy∧dz + y dz∧dx + z dx∧dy，Σ 为球面 x²+y²+z²=R² 的外侧。

解法一（高斯公式）：
P = x, Q = y, R = z
∇ · F = ∂P/∂x + ∂Q/∂y + ∂R/∂z = 1 + 1 + 1 = 3
∯Σ F · dS = ∭Ω 3 dV = 3 · (4/3)πR³ = 4πR³

解法二（投影法）：
球面外侧的单位法向量 n = (x/R, y/R, z/R)
F · n = x·(x/R) + y·(y/R) + z·(z/R) = (x²+y²+z²)/R = R²/R = R
∬Σ F · n dS = R · ∬Σ dS = R · 4πR² = 4πR³
两种解法结果一致。
例 4（方向余弦法）： 计算 ∬Σ z² dx∧dy，Σ 为锥面 z = √(x²+y²) 被 z=1 和 z=2 截下的外侧。

解： 将曲面投影到 xoy 平面，Dxy 为环形域 1 ≤ x²+y² ≤ 4。
锥面上侧的法向量为 (−zx, −zy, 1) = (−x/√(x²+y²), −y/√(x²+y²), 1)
第三分量为正（上侧），但题目要求外侧，对锥面外侧指向斜上方，第三分量仍为正。
∬Σ z² dxdy = ∬Dxy (x²+y²) · (+1) dxdy
换极坐标：∫02π dθ ∫12 r² · r dr = 2π · [r⁴/4]12 = 2π · (4 − 1/4) = 2π · 15/4 = 15π/2

七、常见误区与解题总结

常见误区

  • 混淆隐式与显式法向量：显式 z = f(x,y) 的法向量是 (−fx, −fy, 1)，不是 (fx, fy, −1)
  • 忘记单位化：在第二型曲面积分的向量点积形式中，需要的是单位法向量
  • 方向选取错误：高斯公式要求外侧法向量，投影法需要明确曲面侧对应的符号
  • 参数法向量的顺序：ru × rv 的方向依赖于参数顺序，交换 u,v 顺序会使法向量反向

解题步骤总结

  1. 识别曲面类型：隐式、显式还是参数形式？
  2. 确定法向量方向：题目指定了哪一侧？
  3. 计算法向量：
    • 隐式：∇F
    • 显式：(±fx, ±fy, ±1)
    • 参数：ru × rv
  4. 单位化（如需）：n° = n / |n|
  5. 代入积分：根据积分类型使用对应公式
