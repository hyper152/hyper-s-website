二元函数极值计算方法

多元函数微分学 — 无条件极值 & 条件极值（拉格朗日乘数法）

📥 下载 PDF 原文

一、概述

二元函数极值是多元函数微分学的核心应用之一，广泛出现在最优化问题、物理建模、经济决策等领域。与一元函数不同，二元函数的极值问题分为两大类：无条件极值（函数在整个定义域内求极值）和条件极值（在附加约束条件下求极值）。前者通过分析偏导数和 Hesse 矩阵判定，后者则依赖拉格朗日乘数法将条件极值转化为无条件极值处理。

二、无条件极值

1. 极值的定义

设函数 z = f(x, y) 在点 P0(x0, y0) 的某邻域内有定义。若对该邻域内任意点 (x, y) 均有：

f(x, y) ≤ f(x0, y0) （极大值）  或   f(x, y) ≥ f(x0, y0) （极小值）

则称 f(x0, y0) 为函数的一个极值，(x0, y0) 称为极值点。

2. 极值的必要条件

若 f(x, y) 在点 (x0, y0) 处可微且取得极值，则在该点处一阶偏导数必为零：

fx(x0, y0) = 0，  fy(x0, y0) = 0

满足上述方程组的点称为函数的驻点（临界点）。注意：驻点不一定是极值点（如鞍点），但极值点必为驻点或不可微点。

📝 注：不可微点也可能是极值点（例如 z = |x| + |y| 在 (0,0) 处不可微但取得极小值），因此找极值点时需同时考察驻点和偏导不存在的点。

3. 极值的充分条件（Hesse 矩阵判别法）

设 (x0, y0) 是 f(x, y) 的驻点，且 f 在 (x0, y0) 的某邻域内具有二阶连续偏导数。记：

A = fxx(x0, y0)，   B = fxy(x0, y0)，   C = fyy(x0, y0)

定义判别量（Hesse 行列式）：

△ = AC − B2 = fxx · fyy − (fxy)2

判别规则如下表：

△ 符号 A 符号 结论
△ > 0 A > 0 (x0, y0) 是极小值点
△ > 0 A < 0 (x0, y0) 是极大值点
△ < 0 — (x0, y0) 是鞍点（非极值点）
△ = 0 — 无法判定，需用更高阶方法

4. 无条件极值的求解步骤

  1. 求驻点：解方程组 fx(x, y) = 0，fy(x, y) = 0，得到所有驻点。
  2. 求二阶偏导：计算 fxx、fxy、fyy。
  3. 逐点判别：对每个驻点，计算 △ = AC − B2，按上表判定。
  4. 检查不可微点：考虑偏导不存在的点是否为极值点（按定义判断）。

5. 经典例题

例 1：求函数 f(x, y) = x3 − y3 + 3x2 + 3y2 − 9x 的极值。

解：
(1) 求驻点：
fx = 3x2 + 6x − 9 = 0 ⇒ x2 + 2x − 3 = 0 ⇒ x = 1 或 x = −3
fy = −3y2 + 6y = 0 ⇒ y = 0 或 y = 2
驻点：(1, 0)、(1, 2)、(−3, 0)、(−3, 2)

(2) 求二阶偏导：
fxx = 6x + 6，fxy = 0，fyy = −6y + 6

(3) 逐点判别：
• (1, 0)：A = 12，B = 0，C = 6，△ = 72 > 0，A > 0 ⇒ 极小值，f(1,0) = −5
• (1, 2)：A = 12，B = 0，C = −6，△ = −72 < 0 ⇒ 鞍点
• (−3, 0)：A = −12，B = 0，C = 6，△ = −72 < 0 ⇒ 鞍点
• (−3, 2)：A = −12，B = 0，C = −6，△ = 72 > 0，A < 0 ⇒ 极大值，f(−3, 2) = 31

6. 全局极值（最值）

若函数在有界闭区域 D 上连续，则必能取到最大值和最小值。求法如下：

  1. 求出 D 内所有驻点及不可微点，计算函数值。
  2. 求出 D 的边界上的可能极值点（通常化为条件极值问题或参数化边界）。
  3. 比较所有候选点的函数值，最大者为最大值，最小者为最小值。
⚠ 注意：有界闭区域上的连续函数一定存在最值，但开区域上的连续函数未必有最值，需结合函数在边界上的趋势分析。

三、条件极值与拉格朗日乘数法

1. 问题的提法

求函数 z = f(x, y) 在约束条件 φ(x, y) = 0 下的极值。从几何角度看，即在曲线 φ(x, y) = 0 上寻找使 z 取极值的点。

2. 拉格朗日乘数法基本原理

在极值点处，目标函数的梯度向量与约束条件的梯度向量平行（正交条件），即存在常数 λ（称为拉格朗日乘数）使得：

∇f(x0, y0) = λ ∇φ(x0, y0)

等价于：

fx(x0, y0) = λ φx(x0, y0)
fy(x0, y0) = λ φy(x0, y0)
φ(x0, y0) = 0

3. 标准求解步骤

  1. 构造拉格朗日函数：引入辅助函数
    L(x, y, λ) = f(x, y) + λ · φ(x, y)
  2. 求偏导并令为零：解方程组
    Lx = fx + λφx = 0
    Ly = fy + λφy = 0
    Lλ = φ(x, y) = 0
  3. 解出候选点：从方程中解出 (x, y, λ)，(x, y) 即为可能的极值点。
  4. 判定：根据实际问题的物理/几何意义或二阶条件判定极大值或极小值。

4. 经典例题

例 2（几何应用）：求原点到曲面 (x − y)2 − z2 = 1 的最短距离。

解：即求 d2 = x2 + y2 + z2 在约束 (x − y)2 − z2 = 1 下的最小值。
构造 L = x2 + y2 + z2 + λ[(x − y)2 − z2 − 1]

令偏导为零：
Lx = 2x + 2λ(x − y) = 0   (1)
Ly = 2y − 2λ(x − y) = 0   (2)
Lz = 2z − 2λz = 0   (3)
Lλ = (x − y)2 − z2 − 1 = 0   (4)

由 (3)：2z(1 − λ) = 0 ⇒ z = 0 或 λ = 1
若 z = 0，由 (4) 得 (x − y)2 = 1，由 (1)(2) 得 x + y = 0，解得两组解：(1/2, −1/2, 0) 和 (−1/2, 1/2, 0)，对应距离 d = 1/√2
若 λ = 1，由 (1)(2) 得 x = y = 0，代入 (4) 得 −z2 − 1 = 0 无解。

因此最短距离为 d = 1/√2。

5. 多约束条件的推广

对于多个约束条件的情形，引入多个拉格朗日乘数。例如求 f(x, y, z) 在约束 φ(x, y, z) = 0 和 ψ(x, y, z) = 0 下的极值：

L(x, y, z, λ, μ) = f(x, y, z) + λφ(x, y, z) + μψ(x, y, z)

然后令所有变量的偏导为零（共 5 个方程），解出候选点。

6. 条件极值的二阶判别

在条件极值中，不能直接使用无条件极值的 △ 判别公式。需要构造二阶微分来判定。设 (x0, y0) 为条件极值的候选点，考虑约束条件 dφ = 0 下的二阶微分：

d2L = Lxx dx2 + 2Lxy dx dy + Lyy dy2

若 d2L > 0（在满足 dφ = 0 的非零方向），则为极小值；若 d2L < 0，则为极大值。

四、无条件极值与条件极值的对比总结

对比项 无条件极值 条件极值
自变量范围 整个定义域（或开区域） 约束曲面/曲线上的点
核心条件 fx = fy = 0 ∇f ‖ ∇φ
判别方法 Hesse 矩阵正/负定 Lagrange 函数二阶微分
典型应用 函数极值点、曲面最值 几何距离、经济优化、物理约束
解法复杂度 解 2 个方程 解 n + m 个方程（m 个约束）

五、常见错误与注意事项

  • 混淆驻点与极值点：驻点只是必要条件，须用 △ 判别或更高阶方法确认。
  • 忽略不可微点：不可微点也可能是极值点，这在考试中经常被遗漏。
  • 条件极值直接代入消元：当约束可显式解出 y = y(x) 时，可直接代入化为无条件极值，但要留意定义域变化和计算复杂度；拉格朗日乘数法更通用。
  • △ = 0 时的处理：判别法失效，需沿各方向增量分析函数的性态，或利用极值的定义直接判断。
  • 最值与极值的混淆：最值（全局）需要在所有极值点候选和边界点中比较得出，不能仅凭极值点就断言为最值。
