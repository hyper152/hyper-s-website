级数收敛与收敛半径知识点总结

无穷级数

📥 下载 PDF 原文

一、级数的基本概念

无穷级数是由无穷多个数按一定次序相加而成的表达式：

∑n=1∞ an = a1 + a2 + a3 + … + an + …

记部分和 Sn = ∑k=1n ak。若极限 limn→∞ Sn = S 存在且有限，则称级数收敛于 S；否则称级数发散。

收敛级数的基本性质

  1. 若 ∑ an 收敛，则 limn→∞ an = 0（收敛的必要条件）
  2. 若 ∑ an 和 ∑ bn 都收敛，则 ∑ (an ± bn) 也收敛
  3. 若 ∑ an 收敛，c 为常数，则 ∑ can 也收敛
  4. 级数收敛则加括号后仍收敛（但逆命题不成立）
  5. 去掉、添加或改变级数的有限项不影响其敛散性

二、正项级数的审敛法

若级数的每一项 an ≥ 0，则称为正项级数。以下是正项级数常用的审敛法：

1. 比较审敛法

设 0 ≤ an ≤ bn（对充分大的 n），则：
• 若 ∑ bn 收敛，则 ∑ an 收敛
• 若 ∑ an 发散，则 ∑ bn 发散

2. 比较审敛法的极限形式

设 an, bn > 0，且 limn→∞ an/bn = l (0 ≤ l ≤ +∞)，则：
• 若 0 < l < +∞，则 ∑ an 与 ∑ bn 同敛散
• 若 l = 0 且 ∑ bn 收敛，则 ∑ an 收敛
• 若 l = +∞ 且 ∑ bn 发散，则 ∑ an 发散

3. 比值审敛法（达朗贝尔判别法，d'Alembert）

设 an > 0，且 limn→∞ an+1/an = ρ，则：
• ρ < 1 ⇒ 级数收敛
• ρ > 1 ⇒ 级数发散
• ρ = 1 ⇒ 此法失效，需换用其他方法

适用条件：通项含 n!、an 等因子时最为有效。

4. 根值审敛法（柯西判别法，Cauchy）

设 an ≥ 0，且 limn→∞ √(an) = ρ，则：
• ρ < 1 ⇒ 级数收敛
• ρ > 1 ⇒ 级数发散
• ρ = 1 ⇒ 此法失效

适用条件：通项含 n 次幂（如 an = (bn)n）时最为有效。

5. 积分审敛法

设 f(x) 在 [1, +∞) 上连续、非负且单调递减，an = f(n)，则：
∑n=1∞ an 收敛 ⇔ ∫1+∞ f(x) dx 收敛

三、交错级数审敛法

形如 ∑ (-1)n-1 un（un > 0）的级数称为交错级数。

莱布尼茨审敛法（Leibniz）

若交错级数 ∑ (-1)n-1 un 满足：
(1) un ≥ un+1 > 0（单调递减趋于零）
(2) limn→∞ un = 0
则级数收敛（称为条件收敛）。

绝对收敛与条件收敛

对于任意项级数 ∑ an：

  • 若 ∑ |an| 收敛，则称 ∑ an 绝对收敛
  • 若 ∑ an 收敛但 ∑ |an| 发散，则称 ∑ an 条件收敛
  • 定理：绝对收敛的级数必收敛

四、幂级数与收敛半径

形如 ∑n=0∞ an(x - x0)n 的级数称为幂级数。研究幂级数的关键是确定其收敛半径和收敛域。

阿贝尔定理（Abel）

若幂级数 ∑ anxn 在 x = x0 (≠ 0) 处收敛，
则对任意 |x| < |x0|，幂级数绝对收敛；
若在 x = x0 处发散，则对任意 |x| > |x0|，幂级数发散。

收敛半径的求法

方法一：比值法（系数模比值法）

设 limn→∞ |an+1/an| = ρ（或为 +∞），则收敛半径为：
R = 1/ρ  （当 ρ ≠ 0 且有限）
R = +∞  （当 ρ = 0）
R = 0  （当 ρ = +∞）

方法二：根值法（系数模 n 次根法）

设 limn→∞ √(|an|) = ρ，则：
R = 1/ρ

方法三：缺项幂级数的处理

若幂级数存在缺项（如只含偶数次项 ∑ anx2n），不能直接使用系数公式，而应使用比值法直接对项处理：

令 un(x) = an · x2n，则：
limn→∞ |un+1(x)/un(x)| = limn→∞ |an+1/an| · |x|²
令极限 < 1 解出 |x| < R

五、收敛域的确定步骤

Step 1：用比值法或根值法求出收敛半径 R，确定开区间 (-R, R) 内绝对收敛。
Step 2：分别讨论端点 x = ±R（或 x = x0 ± R）处的敛散性。
Step 3：综合上述结果，写出收敛域（可能为开区间、闭区间或半开半闭区间）。
💡 端点判断要点：将 x = ±R 代入原级数，化为常数项级数，再利用正项级数审敛法或交错级数审敛法判断。

收敛域的常见形式

收敛半径收敛域可能情形
R = +∞(-∞, +∞)
R = 0仅在 x = 0（或 x = x0）处收敛
R > 0 有限(-R, R)、[-R, R)、(-R, R]、[-R, R]

六、典型例题

例 1：判断级数 ∑n=1∞ n/(2n + 1)n 的敛散性。

解：使用根值审敛法。
limn→∞ √(an) = limn→∞ √(n)/(2n + 1) = 0 < 1
结论：级数收敛。
例 2：判断级数 ∑n=1∞ (2n)!/(n!)² · (1/4)n 的敛散性。

解：使用比值审敛法。
limn→∞ an+1/an = limn→∞ (2n+2)(2n+1)/(n+1)² · 1/4 = limn→∞ (4n²+6n+2)/(4n²+8n+4) = 1
ρ = 1，审敛法失效。改用拉贝审敛法或斯特林公式判断。
实际上由 (2n)!/(n!)² ∼ 4n/√(πn) 得通项 ∼ 1/√(πn)，发散。
结论：级数发散。
例 3：求幂级数 ∑n=1∞ (-1)n-1 xn/n 的收敛半径与收敛域。

解：系数 an = (-1)n-1/n。
ρ = limn→∞ |an+1/an| = limn→∞ n/(n+1) = 1
收敛半径 R = 1。
在 x = 1 处：∑ (-1)n-1/n，由莱布尼茨判别法知条件收敛。
在 x = -1 处：∑ (-1)n-1 · (-1)n/n = ∑ -1/n，发散（负的调和级数）。
结论：收敛半径 R = 1，收敛域为 (-1, 1]。
例 4：求幂级数 ∑n=1∞ (x - 1)n/(2n · n) 的收敛域。

解：令 t = x - 1，原级数化为 ∑ tn/(2n n)。
an = 1/(2n n)，ρ = lim |an+1/an| = lim 2nn/(2n+1(n+1)) = 1/2。
收敛半径 Rt = 2。
当 t = 2（即 x = 3）：∑ 2n/(2n n) = ∑ 1/n，发散。
当 t = -2（即 x = -1）：∑ (-2)n/(2n n) = ∑ (-1)n/n，条件收敛。
结论：原级数收敛域为 [-1, 3)。

七、审敛法选择策略

通项特征优先选用的审敛法
含 n!、an、(2n)!/(n!)²比值审敛法
含 nn、(f(n))n根值审敛法
分式有理函数 P(n)/Q(n)比较审敛法（与 1/np 比）
含 ln n 因子积分审敛法 或 比较法
交错符号 (-1)n莱布尼茨判别法（先证 un → 0）
比值/根值极限 = 1换用拉贝判别法或比较法
💡 审敛步骤：
  1. 先看 lim an 是否为零（必要条件）—— 不为零则直接发散
  2. 正项级数优先尝试比值法和根值法（通常最便捷）
  3. 若极限为 1，改用比较法或积分法
  4. 交错级数先判断是否绝对收敛；若不是，再用莱布尼茨判别法
  5. 含参数的级数注意分类讨论

八、幂级数的运算与性质

幂级数的四则运算

设 ∑ anxn 和 ∑ bnxn 的收敛半径分别为 R1 和 R2：

  • 加减法：∑ anxn ± ∑ bnxn = ∑ (an ± bn)xn，收敛半径 R ≥ min{R1, R2}
  • 乘法（柯西乘积）：(∑ anxn) · (∑ bnxn) = ∑ cnxn，其中 cn = ∑k=0n akbn-k

幂级数的分析性质

设幂级数 ∑ anxn 的收敛半径为 R > 0，和函数为 S(x)：

  • 内闭一致收敛：对任意 0 < r < R，在 [-r, r] 上一致收敛
  • 逐项可微：S'(x) = ∑ nanxn-1，且收敛半径仍为 R
  • 逐项可积：∫0x S(t) dt = ∑ anxn+1/(n+1)，且收敛半径仍为 R

九、常见易错点提醒

⚠ 常见错误：
  1. 必要条件误用：an → 0 是收敛的必要条件而非充分条件（如调和级数）
  2. 比值法条件适用：比值法要求 an > 0（正项级数），对任意项级数需加绝对值
  3. 交错级数审敛忘记验证单调性：莱布尼茨判别法要求 un 单调递减
  4. 缺项幂级数误用系数公式：缺项时用 lim |an/an+1| 会出错，应用比值法处理 un(x)
  5. 端点忘记单独验证：收敛半径只给出开区间内的收敛性，端点必须单独代入判断
  6. 绝对收敛与条件收敛混淆："收敛"不等于"绝对收敛"，交错 p-级数在 0 < p ≤ 1 时为条件收敛
  7. 幂级数逐项求导/积分后端点敛散性可能改变
