格林公式知识点总结

重积分与线面积分 — 格林公式及其应用、曲线积分与二重积分的联系

一、格林公式概述

格林公式（Green's Theorem）是向量分析与积分理论中的重要定理，它建立了平面闭区域上的二重积分与其边界曲线上的曲线积分之间的联系。格林公式是斯托克斯定理（Stokes' Theorem）在二维情形下的特例，同时也是牛顿-莱布尼茨公式从一维到二维的推广。

格林公式（基本形式）：
∮C P(x, y) dx + Q(x, y) dy = ∬D (∂Q/∂x − ∂P/∂y) dx dy

其中 C 为区域 D 的正向边界曲线（逆时针方向），P(x, y) 和 Q(x, y) 在 D 上具有一阶连续偏导数。

记忆口诀："Q 对 x 求偏导，减去 P 对 y 求偏导。" 即被积函数为 ∂Q/∂x − ∂P/∂y，顺序不可颠倒。

二、格林公式的适用条件

格林公式的使用需要满足以下三个基本条件：

条件 说明 常见反例
1. 区域连通性 D 为平面有界闭区域，其边界 C 由有限条光滑或逐段光滑曲线组成 带有"洞"的区域需考虑多连通情形
2. 函数光滑性 P(x, y) 和 Q(x, y) 在 D 上具有一阶连续偏导数 在区域内存在奇点（如 (0,0) 处不连续）
3. 边界方向 边界取正向（逆时针方向），即区域始终在左侧 顺时针方向时需加负号
注意：如果区域内有"空洞"或函数在区域内不连续，不能直接应用格林公式！此时需要将区域分割为多个单连通区域，或挖掉奇点处理。

三、格林公式的几种等价形式

3.1 向量点积形式

∮C F · dr = ∬D (∇ × F) · k dA

其中 F = (P, Q)，dr = (dx, dy)，k 为垂直于 xy 平面的单位向量。该形式揭示了格林公式是斯托克斯定理的二维版本。

3.2 面积计算公式（格林公式的推论）

利用格林公式可推导出平面图形的面积计算公式：

A = ∬D dx dy = (1/2) ∮C x dy − y dx

或者写成：

A = ∮C x dy = −∮C y dx
示例：利用格林公式求椭圆 x2/a2 + y2/b2 = 1 的面积。
解：椭圆参数方程为 x = a cos t, y = b sin t, t ∈ [0, 2π]。
A = (1/2) ∮C x dy − y dx = (1/2) ∫02π [a cos t · b cos t − b sin t · (−a sin t)] dt
= (1/2) ∫02π (ab cos2t + ab sin2t) dt = (1/2) · ab · 2π = πab。

四、格林公式的应用

4.1 应用一：曲线积分化为二重积分

当直接计算曲线积分比较困难时，可利用格林公式将其转化为二重积分进行计算。这是格林公式最直接的应用。

示例：计算 I = ∮C (x2 + y) dx + (y2 − x) dy，其中 C 是以 (0,0), (1,0), (0,1) 为顶点的三角形正向边界。
解：P = x2 + y, Q = y2 − x，∂Q/∂x = −1, ∂P/∂y = 1。
由格林公式：I = ∬D (−1 − 1) dx dy = −2 ∬D dx dy = −2 × (1/2) = −1。

4.2 应用二：二重积分化为曲线积分

反向使用格林公式可将二重积分转化为曲线积分，在边界曲线简单时尤为方便。

示例：利用曲线积分计算 ∬D x2 y dx dy，其中 D 为由 y = x 和 y = x2 围成的区域。
思路：选择适当的 P, Q 使 ∂Q/∂x − ∂P/∂y = x2 y。取 P = 0，Q = (1/3)x3y，则 ∂Q/∂x = x2y。
于是 ∬D x2 y dx dy = ∮C (1/3)x3y dy，沿边界分段计算即可。

4.3 应用三：计算平面区域的面积

如前述，利用格林公式的推论公式可计算任意闭曲线所围图形的面积：

A = (1/2) ∮C x dy − y dx
示例：求星形线 x = a cos3t, y = a sin3t 所围图形的面积。
解：dx = −3a cos2t sin t dt, dy = 3a sin2t cos t dt。
A = (1/2) ∫02π [a cos3t · 3a sin2t cos t − a sin3t · (−3a cos2t sin t)] dt
= (3a2/2) ∫02π (cos4t sin2t + sin4t cos2t) dt = (3a2/8) ∫02π sin22t dt = 3πa2/8。

4.4 应用四：判断曲线积分与路径无关

设 P, Q 在单连通区域 D 上具有一阶连续偏导数，则曲线积分 ∫C P dx + Q dy 在 D 内与路径无关的充要条件是：

∂P/∂y = ∂Q/∂x   （在 D 内每一点成立）

该条件等价于格林公式右端被积函数为零，即 ∂Q/∂x − ∂P/∂y = 0。

推论：若 ∂P/∂y = ∂Q/∂x 在单连通区域 D 内恒成立，则：
① 曲线积分与路径无关；
② 沿 D 内任意闭曲线的积分为零；
③ 存在可微函数 u(x, y) 使得 du = P dx + Q dy（原函数存在）。

五、多连通区域上的格林公式

当区域 D 为多连通区域（即区域内有"空洞"）时，格林公式需要修正。设 D 为复连通区域，其边界由外边界 C0 和多个内边界 C1, C2, ..., Ck 组成，则：

∬D (∂Q/∂x − ∂P/∂y) dx dy = ∮C0 P dx + Q dy + ∑i=1k ∮Ci− P dx + Q dy

其中 C0 取逆时针方向（正向），各内边界 Ci 取顺时针方向（相对于区域 D 仍为正向，即区域始终在左侧）。

等价地，若所有边界均取逆时针方向，则：

∬D (∂Q/∂x − ∂P/∂y) dx dy = ∮C0 P dx + Q dy − ∑i=1k ∮Ci P dx + Q dy
示例：计算 I = ∮C [−y/(x2 + y2)] dx + [x/(x2 + y2)] dy，其中 C 为包含原点的任意正向闭曲线。
分析：函数在 (0,0) 处不连续，不能直接应用格林公式。需挖去原点，构造复连通区域。
解：作以原点为圆心、半径 ε > 0 的小圆 Cε（顺时针），由多连通格林公式可得：
∮C = ∮Cε−（因 ∂Q/∂x − ∂P/∂y = 0 在挖去原点后成立）。
在 Cε 上，参数化 x = ε cos θ, y = ε sin θ, θ: 0 → 2π：
I = ∫02π [(−ε sin θ)(−ε sin θ) + (ε cos θ)(ε cos θ)] / ε2 dθ = ∫02π dθ = 2π。

六、格林公式与曲线积分计算策略

计算曲线积分时，应根据具体情况选择最合适的方法。以下为策略对比表：

情况 推荐方法 理由
边界曲线复杂，被积函数简单 格林公式 → 二重积分 将复杂的线积分转化为较简单的面积分
边界曲线简单（如矩形、圆） 直接参数化计算 参数化代入计算更直接
∂P/∂y = ∂Q/∂x 成立 与路径无关 → 选择简单路径 可沿坐标轴折线积分
被积函数在某点不连续 挖奇点法（多连通格林公式） 避开奇点，利用复连通修正
求区域面积 A = (1/2) ∮ x dy − y dx 格林公式的经典应用

七、格林公式与其它积分定理的联系

格林公式是三大积分定理的二维基础，下表展示了它们之间的关系：

定理 适用范围 核心关系
格林公式 二维平面 ∮C Pdx + Qdy = ∬D (∂Q/∂x − ∂P/∂y) dA
高斯公式 三维空间 ∬S F · dS = ∭V ∇ · F dV（格林公式在三维的推广之一）
斯托克斯公式 三维空间中的曲面 ∮C F · dr = ∬S ∇ × F · dS（格林公式在三维的推广之二）
牛顿-莱布尼茨公式 一维区间 ∫ab f'(x) dx = f(b) − f(a)（格林公式在一维的类比）
统一观点：这四个定理都可以统一表述为"区域上的积分等于边界上的积分"——这正是广义斯托克斯定理（Generalized Stokes' Theorem）的核心思想。

八、经典例题精讲

例题 1：直接应用格林公式

计算 I = ∮C (y − ex) dx + (2x + sin y) dy，其中 C 为圆 (x − 1)2 + (y − 1)2 = 4 的正向边界。
解：P = y − ex, Q = 2x + sin y，则 ∂P/∂y = 1，∂Q/∂x = 2。
由格林公式：I = ∬D (2 − 1) dx dy = ∬D dx dy = π × 22 = 4π。

例题 2：利用格林公式证明曲线积分与路径无关

证明曲线积分 ∫C (3x2y + y3) dx + (x3 + 3xy2) dy 在 xy 平面上与路径无关，并求原函数。
证明：∂P/∂y = 3x2 + 3y2，∂Q/∂x = 3x2 + 3y2，故 ∂P/∂y = ∂Q/∂x 在全平面成立。
求原函数：取 (0,0) → (x,0) → (x,y) 的折线路径：
u(x, y) = ∫0x 3t2 · 0 dt + ∫0y (x3 + 3xs2) ds = x3y + xy3 + C。

例题 3：挖奇点法

计算 I = ∮C [x dy − y dx] / (x2 + y2)，其中 C 为任意不经过原点的正向闭曲线。
分析：计算 ∂P/∂y 和 ∂Q/∂x：
P = −y/(x2+y2), Q = x/(x2+y2)
∂P/∂y = (y2 − x2)/(x2+y2)2, ∂Q/∂x = (y2 − x2)/(x2+y2)2
所以 ∂Q/∂x − ∂P/∂y = 0 在除原点外处处成立。
① 若原点不在 C 内部，则 I = 0（由格林公式直接得到）。
② 若原点在 C 内部，则挖去原点作小圆，计算结果为 I = 2π。
综合可得：I = 0（原点在外）或 I = 2π（原点在内）。

九、常见误区与易错点

  • 方向错误：未注意曲线的正向取法。格林公式要求边界取正向（逆时针），若为顺时针需在结果前加负号。
  • 偏导顺序混淆：被积函数是 ∂Q/∂x − ∂P/∂y，而非 ∂P/∂y − ∂Q/∂x。
  • 忽视奇点：区域内存在偏导数不连续的点时直接套用格林公式，导致结果错误。
  • 多连通区域处理不当：未正确处理内外边界的方向关系，或遗漏了内边界上的积分。
  • 条件遗漏：格林公式要求函数具有一阶连续偏导数，若仅存在偏导数但不连续，公式不一定成立。
  • 混淆充要条件：曲线积分与路径无关等价于 ∂P/∂y = ∂Q/∂x，这个结论只在单连通区域上成立。

十、总结与解题模板

应用格林公式解题的一般步骤：

  1. Step 1 — 确认条件：检查区域 D 是否为有界闭区域，边界是否光滑或逐段光滑，P, Q 是否具有一阶连续偏导数。
  2. Step 2 — 检查奇点：若 D 内有奇点（偏导数不连续的点），则需作辅助曲线挖去奇点。
  3. Step 3 — 检查连通性：若为多连通区域，需分割为单连通区域，或使用复连通格林公式。
  4. Step 4 — 确定边界方向：确保所有边界取正向（区域始终在左侧）。
  5. Step 5 — 计算偏导差：计算 ∂Q/∂x − ∂P/∂y，代入格林公式。
  6. Step 6 — 计算二重积分：将曲线积分转化为二重积分进行计算。
  7. Step 7 — 处理辅助曲线：若作了辅助曲线挖洞，需要单独计算辅助曲线上的积分并作为修正值。
核心要诀："看条件、判奇点、定方向、算偏导、化重积"——五步法熟练掌握格林公式的各类应用。
