重积分与线面积分 — 斯托克斯公式、旋度与曲线积分的关系

一、斯托克斯公式概述

斯托克斯公式（Stokes' Theorem）是矢量分析中三大基本积分定理之一， 它将空间曲面上的曲面积分与 该曲面边界上的曲线积分联系起来。 斯托克斯公式可以看作格林公式从二维平面到三维曲面的推广。

斯托克斯公式揭示了向量场的旋度在曲面上的积分等于该向量场沿曲面边界的环量， 是连接"局部旋转"与"整体环流"的桥梁。

核心思想： 曲面上的旋度积分 ↔ 边界曲线上的环量。 斯托克斯公式将空间曲线积分转化为曲面积分（或反之），大大简化了计算。

二、斯托克斯公式定理

1. 定理内容

设 Σ 为分片光滑的有向曲面， L 是其边界曲线（分段光滑），方向与 Σ 的侧符合右手法则。 若函数 P(x,y,z)、Q(x,y,z)、R(x,y,z) 在 Σ（包括边界）上具有一阶连续偏导数，则：

∮L P dx + Q dy + R dz = &iint;Σ (∂R/∂y - ∂Q/∂z) dy dz + (∂P/∂z - ∂R/∂x) dz dx + (∂Q/∂x - ∂P/∂y) dx dy

向量形式：

∮L A ⋅ dr = &iint;Σ rot A ⋅ n dS = &iint;Σ (∇ × A) ⋅ dS

其中 A = (P, Q, R)，rot A = ∇ × A 为旋度。

2. 方向判定（右手定则）

曲面 Σ 的侧与边界曲线 L 的方向需满足右手法则：
右手拇指指向曲面法向量方向，四指弯曲的方向即为曲线 L 的正向。

三、旋度的概念与计算

1. 旋度的定义

向量场 A = (P, Q, R) 的旋度定义为：

rot A = ∇ × A = i(∂R/∂y - ∂Q/∂z) + j(∂P/∂z - ∂R/∂x) + k(∂Q/∂x - ∂P/∂y)

也可写作行列式形式：

rot A = det [ [i, j, k], [∂/∂x, ∂/∂y, ∂/∂z], [P, Q, R] ]

2. 旋度的物理意义

旋度描述向量场在某点处的旋转强度和旋转方向：

  • 大小： 旋度向量的大小表示该点处最大环量面密度
  • 方向： 旋度向量的方向为最大环量面密度的方向（右手法则确定的旋转轴方向）
  • 物理量纲： 角速度的 2 倍（对于刚体旋转速度场 v = ω × r， rot v = 2ω）

3. 旋度的运算法则

  • rot (cA) = c rot A（c 为常数）
  • rot (A + B) = rot A + rot B
  • rot (uA) = u rot A + ∇u × A（u 为标量函数）
  • div (rot A) = 0（旋度的散度恒为零）
  • rot (∇u) = 0（梯度场的旋度恒为零）

四、斯托克斯公式的应用方法

1. 用曲面积分计算空间曲线积分

将复杂的空间曲线积分转化为曲面积分，是斯托克斯公式最重要的应用。 当曲面积分更容易计算时（如曲面为平面区域），这种方法特别有效。

例 1： 计算曲线积分 ∮L (y2 - z2) dx + (z2 - x2) dy + (x2 - y2) dz， 其中 L 是平面 x + y + z = 1 被三个坐标平面所截三角形的边界（从 z 轴正向看为逆时针方向）。

解：
P = y2 - z2， Q = z2 - x2， R = x2 - y2
计算旋度各分量：
∂R/∂y - ∂Q/∂z = -2y - 2z = -2(y + z)
∂P/∂z - ∂R/∂x = -2z - 2x = -2(z + x)
∂Q/∂x - ∂P/∂y = -2x - 2y = -2(x + y)
由斯托克斯公式：
原式 = &iint;Σ -2(y+z) dy dz - 2(z+x) dz dx - 2(x+y) dx dy
取 Σ 为平面 x + y + z = 1 上被三角形区域 D。 曲面法向量 n = (1, 1, 1)/√3，方向符合右手法则。
将曲面积分投影到 xOy 平面：z = 1 - x - y， dS = √(1 + zx2 + zy2) dxdy = √3 dxdy
rot A ⋅ n = -2[(y+z)+(z+x)+(x+y)]/√3 = -4(x+y+z)/√3 = -4/√3
因此原式 = &iint;D (-4/√3) √3 dxdy = -4 × (面积) = -4 × (1/2) = -2

2. 用曲线积分计算曲面积分

反向使用斯托克斯公式：将曲面积分转化为边界上的曲线积分， 当边界曲线简单时非常有用。

例 2： 计算曲面积分 &iint;Σ rot A ⋅ dS， 其中 A = (y - z, z - x, x - y)， Σ 是上半球面 z = √(1 - x2 - y2) 的上侧。

解：
由斯托克斯公式：&iint;Σ rot A ⋅ dS = ∮L A ⋅ dr
边界 L 是平面 z = 0 上的单位圆 x2 + y2 = 1， 方向与曲面侧对应（从上往下看为逆时针）。
在 z = 0 上：A = (y, -x, x - y)
参数化：x = cos t, y = sin t, t: 0 → 2π
dx = -sin t dt, dy = cos t dt
∮L A ⋅ dr = ∫02π [sin t ⋅ (-sin t) + (-cos t) ⋅ cos t] dt
= ∫02π (-sin2t - cos2t) dt = -∫02π dt = -2π

五、旋度与环量的物理意义

1. 环量的概念

向量场 A 沿封闭曲线 L 的环量定义为：

Γ = ∮L A ⋅ dr = ∮L P dx + Q dy + R dz
  • 对流速场 v，环量表示绕曲线的环流强度
  • 对电场 E，环量表示电动势

2. 环量面密度

斯托克斯公式揭示了环量面密度的概念： 旋度在法方向上的投影等于该方向上的环量面密度：

(rot A)n = limS → 0 (1/S) ∮L A ⋅ dr

这表示旋度的物理意义：旋度在 n 方向的分量 等于单位面积上的环量（环量面密度）。

六、三大积分公式对比

对比项 格林公式 高斯公式 斯托克斯公式
适用维度 二维平面 三维空间区域 三维曲面
左侧积分 封闭曲线积分 封闭曲面积分 封闭曲线积分
右侧积分 二重积分 三重积分 曲面积分
微分算子 旋度（二维） 散度 旋度（三维）
连通关系 平面区域 ↔ 边界曲线 空间区域 ↔ 边界曲面 曲面 ↔ 边界曲线
物理意义 环量 = 旋度面积分 通量 = 散度体积分 环量 = 旋度面积分

七、格林公式与斯托克斯公式的关系

当斯托克斯公式中的曲面 Σ 退化为平面区域时， 斯托克斯公式退化为格林公式。

设 Σ 在 xOy 平面内， 则 z = 0，dz = 0，n = (0, 0, 1)：

∮L P dx + Q dy = &iint;Σ (∂Q/∂x - ∂P/∂y) dx dy

这正是平面上的格林公式。因此，格林公式是斯托克斯公式的特例。

八、斯托克斯公式的适用条件与注意事项

条件/注意事项 说明
曲面方向一致 曲面侧与边界方向须满足右手法则
偏导数连续 P,Q,R 在 Σ 上有一阶连续偏导
曲面分片光滑 允许由多片光滑曲面拼接，边界分段光滑
曲面选取灵活 以同一曲线为边界的任意曲面均可使用，选择计算简单的曲面
方向一致性检验 如果曲线方向与曲面侧不匹配，结果差一个负号
与格林公式区别 注意斯托克斯公式是空间中的公式， 格林公式是平面上的特例
常见陷阱： (1) 最容易出错的是曲面方向与曲线方向的对应关系， 务必用右手法则确认。(2) 当曲线为平面曲线时， 选取曲线所在的平面区域作为积分曲面通常最方便。 (3) 如果曲线非封闭，需补线使其封闭再应用公式。

九、典型综合例题

例 3： 综合应用：计算曲线积分
计算 ∮L (y2 + z2) dx + (z2 + x2) dy + (x2 + y2) dz， 其中 L 是曲线 { x2 + y2 + z2 = 2Rz, x2 + y2 = R2 (z > 0) } 的方向从 z 轴正向看为逆时针。

解： 注意第一个方程可化为 x2 + y2 + (z - R)2 = R2， 即球心在 (0,0,R)、半径为 R 的球面。 第二个方程是圆柱面。两曲面交线 L 在平面 z = R 上。
取 Σ 为平面 z = R 上的圆盘 x2 + y2 ≤ R2， 取上侧（法向量 n = (0,0,1)）。
计算旋度：
P = y2 + z2， Q = z2 + x2， R = x2 + y2
∂R/∂y - ∂Q/∂z = 2y - 2z
∂P/∂z - ∂R/∂x = 2z - 2x
∂Q/∂x - ∂P/∂y = 2x - 2y
在平面 z = R 上， rot A ⋅ n = ∂Q/∂x - ∂P/∂y = 2x - 2y
由斯托克斯公式：
原式 = &iint;Σ (2x - 2y) dS
利用对称性：&iint;Σ x dS = 0， &iint;Σ y dS = 0
因此原式 = 0
例 4： 曲线积分与路径无关性（旋度为零的场）
判断曲线积分 ∫L yz dx + zx dy + xy dz 是否与路径无关，并计算 ∮L yz dx + zx dy + xy dz 沿单位圆 x2 + y2 = 1, z = 0 的积分。

解：
计算旋度：
P = yz, Q = zx, R = xy
∂R/∂y - ∂Q/∂z = x - x = 0
∂P/∂z - ∂R/∂x = y - y = 0
∂Q/∂x - ∂P/∂y = z - z = 0
旋度处处为零，因此积分与路径无关。
由于是保守场，沿任何封闭曲线的积分均为零：
∮L yz dx + zx dy + xy dz = 0

事实上，存在势函数 u(x,y,z) = xyz，使得 du = yz dx + zx dy + xy dz。

十、斯托克斯公式应用总结

应用场景 方法 典型条件
空间曲线积分计算 转化为曲面积分（正向使用公式） 曲面好找且曲面积分易算
旋度的曲面积分计算 转化为曲线积分（反向使用公式） 边界曲线简单易参数化
判断保守场 检查旋度是否为零 旋度处处为零 → 保守场
求势函数 积分与路径无关，选择特殊路径 保守场中成立
非封闭曲线处理 补线法：加辅助路径形成封闭曲线 辅助路径积分易算
平面曲线退化 退化为格林公式 曲面选为曲线所在平面
