复合函数偏导数的链式法则核心知识点

多元函数微分学

📥 下载 PDF 原文

一、概述

链式法则（Chain Rule）是多元函数微分学中最重要的计算工具之一。在一元函数中，链式法则的形式简洁明了：若 y = f(u)，u = g(x)，则 dy/dx = f'(u) • g'(x)。在多元函数中，链式法则需要根据复合的结构（中间变量的个数、自变量的个数）灵活应用，形式更加多样。

正确理解和掌握多元复合函数的链式法则，是处理偏微分方程、优化问题、物理建模等更深层次问题的基础。

二、链式法则的基本形式

情形1：一元函数与多元函数复合（单变量中间变量）

设 z = f(x, y)，而 x = x(t)，y = y(t) 均为 t 的一元函数。则 z = f(x(t), y(t)) 是 t 的一元复合函数，其全导数为：

dz/dt = (∂f/∂x) • (dx/dt) + (∂f/∂y) • (dy/dt)

这是最基础的形式，其中 ∂f/∂x 和 ∂f/∂y 来自外层函数对中间变量的偏导，dx/dt 和 dy/dt 来自内层函数。

x     y

（z 通过 x, y 最终依赖 t，共两条路径）

情形2：多元函数与多元函数复合（多变量中间变量）

设 z = f(u, v)，而 u = u(x, y)，v = v(x, y)。则 z = f(u(x,y), v(x,y)) 是 x, y 的二元复合函数，其偏导数为：

∂z/∂x = (∂f/∂u) • (∂u/∂x) + (∂f/∂v) • (∂v/∂x)
∂z/∂y = (∂f/∂u) • (∂u/∂y) + (∂f/∂v) • (∂v/∂y)

x y  x y
（z → x：经过 u 和 v 两条路径；z → y 同理）

情形3：多种变量混合复合

设 z = f(u, v, w)，其中 u = u(x, y)，v = v(x, y)，w = w(x, y)，则

∂z/∂x = (∂f/∂u)(∂u/∂x) + (∂f/∂v)(∂v/∂x) + (∂f/∂w)(∂w/∂x)
∂z/∂y = (∂f/∂u)(∂u/∂y) + (∂f/∂v)(∂v/∂y) + (∂f/∂w)(∂w/∂y)

三、链式法则的通式规则

对于一般的多元复合函数，链式法则遵循一个统一的模式：

∂z/∂xi = ∑j (∂f/∂uj) • (∂uj/∂xi)

其中 uj 是所有中间变量，xi 是最终自变量。求和是对所有从 z 到 xi 的路径进行的，每条路径贡献一个"偏导乘积"项。

"路径和"规则（记忆口诀）

"连线相乘，分线相加"

  • 连线相乘：从因变量到自变量的一条路径上，依次对每个中间变量求偏导，将各偏导相乘。
  • 分线相加：把所有不同路径的乘积项相加，得到最终的偏导数。

四、特殊情形的链式法则

1. 函数依赖路径存在"重合"

设 z = f(x, y) 且 y = y(x)，则 z = f(x, y(x)) 是仅关于 x 的一元函数（但 f 显式依赖于 x 和 y）：

dz/dx = ∂f/∂x + (∂f/∂y) • (dy/dx)

注意：dz/dx（全导数）与 ∂f/∂x（偏导数）是不同的——前者包括了通过 y 的间接路径。

2. 隐函数的偏导数（链式法则的逆向应用）

若方程 F(x, y, z) = 0 确定了隐函数 z = z(x, y)，两边对 x 求偏导得：

∂F/∂x + (∂F/∂z) • (∂z/∂x) = 0
⇒ ∂z/∂x = − Fx / Fz   (Fz ≠ 0)

完全类似可得 ∂z/∂y = − Fy / Fz。这是链式法则应用于隐函数求导的重要结论。

五、高阶偏导的链式法则

对复合函数求高阶偏导时，需要多次应用链式法则，且注意偏导函数本身仍然是复合函数。

举例：求二阶偏导

设 z = f(u, v)，u = u(x, y)，v = v(x, y)。已求得：

∂z/∂x = (∂f/∂u)(∂u/∂x) + (∂f/∂v)(∂v/∂x)

若要继续对 x 求偏导：

∂2z/∂x2 = (∂/∂x)[(∂f/∂u)(∂u/∂x) + (∂f/∂v)(∂v/∂x)]

其中 ∂f/∂u 和 ∂f/∂v 仍然是 (u, v) 的函数（即需对它们再应用链式法则），而 ∂u/∂x 和 ∂v/∂x 可能是 (x, y) 的函数。因此最终表达式会涉及 f 的二阶偏导。

简记形式：若记 fu = ∂f/∂u，fv = ∂f/∂v，则

∂2z/∂x2 = [fuu(∂u/∂x)2 + 2fuv(∂u/∂x)(∂v/∂x) + fvv(∂v/∂x)2] + fu(∂2u/∂x2) + fv(∂2v/∂x2)

六、典型例题

例题1：基础链式法则

题目：设 z = u2 + uv，其中 u = x + y，v = x − y。求 ∂z/∂x 和 ∂z/∂y。

解：由链式法则：

∂z/∂x = (∂z/∂u)(∂u/∂x) + (∂z/∂v)(∂v/∂x)

∂z/∂u = 2u + v，∂z/∂v = u

∂u/∂x = 1，∂v/∂x = 1

⇒ ∂z/∂x = (2u + v) • 1 + u • 1 = 3u + v = 3(x + y) + (x − y) = 4x + 2y

同理 ∂z/∂y = (2u + v) • 1 + u • (−1) = u + v = (x + y) + (x − y) = 2x

验算：直接代入 z = (x+y)2 + (x+y)(x−y) = 2x2 + 2xy，验证结果正确。

例题2：二阶偏导的链式法则

题目：设 z = f(xy, x/y)，f 具有二阶连续偏导。求 ∂z/∂x，∂z/∂y 和 ∂2z/∂x∂y。

解：令 u = xy，v = x/y，则 z = f(u, v)。

∂z/∂x = fu • (∂u/∂x) + fv • (∂v/∂x) = fu • y + fv • (1/y)

∂z/∂y = fu • (∂u/∂y) + fv • (∂v/∂y) = fu • x + fv • (−x/y2)

然后求混合偏导：

∂2z/∂x∂y = ∂/∂y [fu • y + fv • (1/y)]

= [fuu•x + fuv•(−x/y2)]•y + fu•1 + [fvu•x + fvv•(−x/y2)]•(1/y) + fv•(−1/y2)

利用 fuv = fvu（二阶连续偏导下混合偏导相等），整理得：

= xyfuu − (x/y)fuv + fu + (x/y)fvu − (x/y3)fvv − (1/y2)fv

= xyfuu + fu − (x/y3)fvv − (1/y2)fv

例题3：隐函数与链式法则

题目：设 F(x + y + z, x2 + y2 + z2) = 0 确定了隐函数 z = z(x, y)，求 ∂z/∂x。

解：令 u = x + y + z，v = x2 + y2 + z2，则 F(u, v) = 0。

两边对 x 求偏导（注意 u 和 v 均依赖于 x 和 z，而 z 又是 x, y 的函数）：

Fu • (1 + ∂z/∂x) + Fv • (2x + 2z • ∂z/∂x) = 0

整理出 ∂z/∂x：

⇒ (Fu + 2zFv) • (∂z/∂x) = − Fu − 2xFv

⇒ ∂z/∂x = − (Fu + 2xFv) / (Fu + 2zFv)

七、链式法则表格速查

一元⇒一元 y = f(u) u = g(x) x dy/dx = f'(u) g'(x)

八、链式法则的标准解题步骤

  1. 画依赖关系图：确定因变量、中间变量和自变量，用树状图表示依赖路径。
  2. 确定需要求的偏导：明确是对哪个自变量求偏导。
  3. 找出所有路径：从因变量到目标自变量之间的每一条依赖路径。
  4. 每条路径上的偏导相乘：路径上每"跳"一次乘上对应的偏导因子。
  5. 所有路径求和：将所有路径的乘积项加起来。
  6. 化简代入：必要时将中间变量代回为自变量的表达式。

关键提醒：

  • 求偏导时分清层次——外层偏导 ∂f/∂u 是对中间变量而言，中间变量仍是 (u, v) 的函数。
  • 求全导数时 dz/dt 要考虑所有依赖路径；而偏导 ∂z/∂x 则固定其他自变量。
  • 高阶求导时，fu、fv 与 f 具有相同的复合结构，再次应用链式法则时不能忘记这一点。
  • 记法：用下标表示偏导，如 fu、fuv 可使表达式简洁清晰。

九、偏导数记号中的链式法则含义

链式法则可以帮助理解偏导数的不同记号的含义差异。考虑 z = f(x, y)，其中 y = y(x)：

记号 含义 与链式法则的关系
∂f/∂x 固定 y，只看 f 对 x 的显式依赖 仅考虑直接路径
dz/dx z 对 x 的全导数 同时考虑直接和间接路径
∂F/∂x（在 F(x, y, z)=0 中） 固定 y, z，只看 F 对 x 的显式依赖 隐函数求导时两边同时应用链式法则

链式法则使得这些不同的"变化率"概念可以相互转化和精确计算。

十、常见错误与注意事项

  • 错误一：遗漏路径。该有两条路径时只写了一条，或反之多写了不存在的路径。
  • 错误二：混淆全导与偏导。在混合复合中，∂z/∂x 与 ∂f/∂x 含义不同，不能等同。
  • 错误三：高阶求导时，对 fu 再次求偏导时忘记应用链式法则——fu 仍是 (u, v) 的函数，而 (u, v) 又依赖于 (x, y)。
  • 错误四：符号混淆——注意 fu 也可以记为 ∂f/∂u，求值时是在 (u(x,y), v(x,y)) 处取值。
  • 注意事项：画依赖关系图是避免出错最有效的方法。先画图、再列式、后计算。
  • 注意事项：题中若说"f 具有二阶连续偏导数"，意味着 fuv = fvu，可合并同类项简化结果。
