一、概述

二元函数的极限与泰勒公式是多元函数微分学的两大基石。极限理论刻画了函数在趋近某点时的行为，而泰勒公式则提供了用多项式逼近复杂函数的工具。相较于一元函数，二元函数的极限复杂得多——趋近路径有无穷多种，极限存在要求"沿所有路径趋近同一值"。泰勒公式从一元推广到二元，引入了偏导数的组合和多变量展开的系数规律，是近似计算和极值判别的理论基础。

二、二元函数的极限

1. 极限的定义（ε-δ 语言）

设函数 z = f(x, y) 在点 P0(x0, y0) 的去心邻域内有定义。若对任意给定的正数 ε > 0，总存在 δ > 0，使得当 0 < √[(x − x0)2 + (y − y0)2] < δ 时（即 (x, y) 在以 P0 为圆心、δ 为半径的去心圆盘内），恒有：

|f(x, y) − A| < ε

则称 A 为 f(x, y) 当 (x, y) → (x0, y0) 时的极限，记作：

lim(x,y)→(x0,y0) f(x, y) = A
⚠ 与一元极限的关键区别：一元函数中 x → x0 只有左、右两个方向；而二元函数中 (x, y) → (x0, y0) 有无穷多种路径（直线、曲线、螺旋等）。极限存在必须要求所有路径的极限值相同且等于 A。

2. 极限的判定方法

方法一：定义法（ε-δ 直接证明）

利用放缩技巧，将 |f(x, y) − A| 放大为关于 ρ = √[(x − x0)2 + (y − y0)2] 的表达式，然后取 δ。

例 1：证明 lim(x,y)→(0,0) (x2 + y2) sin[1/(x2 + y2)] = 0

证明：注意到 |sin(1/(x2 + y2))| ≤ 1
∴ |(x2 + y2) sin(1/(x2 + y2))| ≤ x2 + y2 = ρ2
对任意 ε > 0，取 δ = √ε，则当 0 < ρ < δ 时，|f − 0| < ε，证毕。

方法二：路径法（证明极限不存在）

若找到两条不同路径，使极限值不相等，则极限不存在。常用路径：

路径形式参数化适用场景
直线路径y = kx最常用，若结果依赖于 k 则极限不存在
抛物线路径y = kx2当分母含 x2、y 混合项时
曲线路径y = xm、x = yn高次项主导时
极坐标路径x = r cos θ，y = r sin θ结果与 θ 有关则极限不存在
例 2（极限不存在）：证明 lim(x,y)→(0,0) (xy) / (x2 + y2) 不存在。

证明：沿直线 y = kx 趋近：
lim(x,y)→(0,0) (x · kx) / (x2 + k2x2) = limx→0 kx2 / [(1 + k2)x2] = k / (1 + k2)
结果依赖于 k，例如取 k = 0 得极限 0，取 k = 1 得极限 1/2。因此极限不存在。

方法三：极坐标代换法

令 x = x0 + r cos θ，y = y0 + r sin θ，将二元极限转化为 r → 0 时关于 r 和 θ 的极限。

lim(x,y)→(x0,y0) f(x, y) = limr→0 f(x0 + r cos θ, y0 + r sin θ)

关键：若化简后表达式为 rα · g(θ)，且 g(θ) 有界，则极限为 0；若 g(θ) 无界或结果依赖于 θ，则极限不存在。

例 3：求 lim(x,y)→(0,0) (x3 + y3) / (x2 + y2)

解：令 x = r cos θ，y = r sin θ
原式 = limr→0 (r3 cos3θ + r3 sin3θ) / r2
= limr→0 r (cos3θ + sin3θ) = 0
（因为 |cos3θ + sin3θ| ≤ 2 有界）
因此极限为 0。

方法四：夹逼准则

若在 (x0, y0) 的某去心邻域内有 h(x, y) ≤ f(x, y) ≤ g(x, y)，且：

lim(x,y)→(x0,y0) h(x, y) = lim(x,y)→(x0,y0) g(x, y) = A

则 lim f(x, y) = A。常用放缩技巧：|xy| ≤ (x2 + y2)/2、|x| ≤ √(x2 + y2) 等。

3. 常用极限技巧速查

技巧适用情形示例
分子有理化含根式差(√(xy + 1) − 1) / (xy)
等价无穷小代换乘除因子的无穷小量sin(xy) ~ xy（当 xy → 0）

📝 重要结论：如果在多条路径上的极限值不相等，则极限肯定不存在。但如果所有直线路径上的极限值都相等，不能保证极限存在（仍可能有曲线路径导致不同结果）。

三、二元函数的连续性

若 f(x, y) 满足：

lim(x,y)→(x0,y0) f(x, y) = f(x0, y0)

则称 f 在 (x0, y0) 处连续。具体来说，需满足三个条件：

  1. f(x0, y0) 有定义
  2. 极限 lim f(x, y) 存在
  3. 极限值等于函数值

连续函数的和、差、积、商（分母不为零）、复合仍连续。连续函数在有界闭区域上可取到最大值和最小值（有界性定理）并一致连续。

四、二元函数的泰勒公式

1. 从一元到二元的推广思路

一元函数的泰勒公式：

f(x) = ∑k=0n f(k)(x0) / k! · (x − x0)k + Rn

推广到二元时，将 (x − x0)k 展开为 (Δx + Δy)k 的二项式展开，其中系数变为各阶偏导数的组合。

2. 二元函数泰勒公式的一般形式

设 f(x, y) 在点 (x0, y0) 的某邻域内有直到 n + 1 阶连续偏导数，则：

f(x0 + h, y0 + k) = f(x0, y0) + (h∂x + k∂y)f + 1/2! (h∂x + k∂y)2f + ... + 1/n! (h∂x + k∂y)nf + Rn

其中 h = x − x0，k = y − y0，(h∂x + k∂y)f 表示对 f 分别求偏导后乘以 h、k 再求和。

3. 展开至二阶的具体形式（最重要）

f(x0 + h, y0 + k) = f(x0, y0) + fx(x0, y0) · h + fy(x0, y0) · k
+ 1/2 [fxx(x0, y0) · h2 + 2 fxy(x0, y0) · hk + fyy(x0, y0) · k2]
+ R2

4. 余项形式

余项类型表达式说明
Peano 余项 Rn = o(ρn)（ρ = √(h2 + k2)） 仅要求 f 在 (x0, y0) 处 n 阶可微，不能具体估计误差
Lagrange 余项 Rn = 1/(n+1)! (h∂x + k∂y)n+1 f(x0 + θh, y0 + θk)（0 < θ < 1） 可进行误差估计，要求更高阶可微

5. 常用二元函数的泰勒展开（在 (0, 0) 处，即麦克劳林公式）

函数展开（至二阶）
ex+y 1 + (x + y) + 1/2 (x2 + 2xy + y2) + o(ρ2)
sin(x + y) (x + y) − 1/6 (x + y)3 + o(ρ3)
cos(xy) 1 − 1/2 x2y2 + o(ρ4)
ln(1 + x + y) (x + y) − 1/2 (x + y)2 + o(ρ2)

💡 速记口诀："沿着方向 (h, k)，用偏导组合代替单变量导数，二项式展开系数就是泰勒系数"
具体说：一元中的 f'(x0)(x − x0) 变为 fxh + fyk；
一元中的 1/2 f''(x0)(x − x0)2 变为 1/2 (fxxh2 + 2fxyhk + fyyk2)

6. 泰勒公式的应用

  • 近似计算：用低阶多项式逼近函数值，估计误差。
  • 极值判别：二阶展开用于无条件极值的充分条件判定（△ = AC − B2 的来源）。
  • 求极限：将复杂函数展开为多项式，化简极限计算。
  • 误差分析：用 Lagrange 余项估计数值计算的精度。
例 4（近似计算）：用二阶泰勒展开求 f(x, y) = ex cos y 在 (0.1, 0.2) 处的近似值。

解：在 (0, 0) 处展开：
f(0,0) = 1，fx = ex cos y ⇒ fx(0,0) = 1
fy = −ex sin y ⇒ fy(0,0) = 0
fxx = ex cos y ⇒ fxx(0,0) = 1
fxy = −ex sin y ⇒ fxy(0,0) = 0
fyy = −ex cos y ⇒ fyy(0,0) = −1

∴ f(h, k) ≈ 1 + h + 1/2 (h2 − k2)
代入 h = 0.1，k = 0.2：
f(0.1, 0.2) ≈ 1 + 0.1 + 1/2 (0.01 − 0.04) = 1.1 − 0.015 = 1.085
实际值 e0.1 cos(0.2) ≈ 1.083，近似效果良好。

五、极限与泰勒公式的联系

泰勒公式为极限计算提供了强大工具：若需要计算 lim f(x, y) 且函数可微，可将其展开为多项式形式，分子分母分别展开到适当阶数后化简。常见思路：

  1. 将分子分母分别展开到 最低阶非零项
  2. 注意展开的同阶对应：分子分母展开到同一阶次
  3. 处理 0/0 型的极限时，展开式的首项对比给出极限值
例 5（用泰勒求极限）：求 lim(x,y)→(0,0) (1 − cos(xy)) / (x2 + y2)

解：由一元展开 cos u = 1 − u2/2 + o(u2)
1 − cos(xy) = 1/2 (xy)2 + o(x2y2)

原式 = lim(x,y)→(0,0) [1/2 x2y2 + o(x2y2)] / (x2 + y2)

用极坐标 x = r cos θ，y = r sin θ：
原式 = limr→0 [1/2 r4 cos2θ sin2θ + o(r4)] / r2
= limr→0 [1/2 r2 cos2θ sin2θ + o(r2)] = 0
因此极限为 0。

六、常见错误与注意事项

  • 路径法滥用：只验证了有限条路径不足以证明极限存在——极限存在需要对所有路径都成立。
  • 极坐标误区：极坐标下若化简结果依赖于 θ，极限不存在；若结果不依赖 θ 但包含 r 的负幂次，极限可能不存在。
  • 等价无穷小滥用：等价无穷小代换只能用于乘除因子，不能用于加减项的内部代换。
  • 泰勒展开阶数不够：展开阶数不足会导致分子分母抵消后误判极限值。
  • 忽略余项：用泰勒近似时必须记住余项的存在——等式必须包含 o(ρn) 或写为近似符号。
  • 连续性验证：函数在一点连续必须先验证极限存在，不能想当然地认为初等函数在其定义域内一定连续（分段函数需单独验证）。
