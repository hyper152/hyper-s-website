平面点集基本定义

空间解析几何 — 邻域、聚点、开集、闭集、区域等基本概念

📥 下载 PDF 原文

一、平面点集的基本概念

平面点集是 R2 中点的集合，即坐标平面 xOy 上满足某种条件的点的全体。一般记为：

E = { (x, y) | (x, y) 满足某种条件 }

例如：E = { (x, y) | x2 + y2 < 1 } 表示单位圆内部（不含边界）的所有点。

空间 R2 中任意两点 P1(x1, y1) 和 P2(x2, y2) 之间的距离定义为：

d(P1, P2) = √[(x1 - x2)2 + (y1 - y2)2]

这是欧几里得距离（Euclidean distance）。

二、邻域

1. δ 邻域（圆形邻域）

设 P0(x0, y0) 是 xOy 平面上的一个点，δ 为某一正数。称点集：

U(P0, δ) = { P | d(P, P0) < δ }

为点 P0 的 δ 邻域。它表示以 P0 为圆心、δ 为半径的圆盘内部（不含边界）。

2. 去心邻域

从 δ 邻域中除去中心点 P0 本身，称为 去心 δ 邻域：

Ů(P0, δ) = { P | 0 < d(P, P0) < δ }

3. 方形邻域

有时也使用方形邻域：

U□(P0, δ) = { (x, y) | |x - x0| < δ, |y - y0| < δ }

即以 P0 为中心、边长为 2δ 的开正方形区域。

注：圆形邻域和方形邻域在拓扑上是等价的——对于任意一个圆形邻域，总可以找到一个包含在其中的方形邻域，反之亦然。因此在实际论证中，两者可以互换使用。

三、点与点集的关系

设 E 是 R2 中的一个点集，P0 为平面上的一个点。根据 P0 与 E 的关系，可作如下分类：

类型 定义 符号 说明
内点 存在 δ > 0 使得 U(P0, δ) ⊂ E P0 是 E 的内点 周围所有点都属于 E
外点 存在 δ > 0 使得 U(P0, δ) ∩ E = ∅ P0 是 E 的外点 周围所有点都不属于 E
边界点 对任意 δ > 0，U(P0, δ) 既含有 E 的点又含有非 E 的点 P0 是 E 的边界点 任意邻域中都混有 E 内外的点
聚点 对任意 δ > 0，去心邻域 Ů(P0, δ) 中至少含有 E 的一个点 P0 是 E 的聚点 附近有无限多 E 的点（可以是 E 的内点或边界点）
孤立点 P0 ∈ E，但存在 δ > 0 使得 U(P0, δ) ∩ E = {P0} P0 是 E 的孤立点 属于 E 但不是聚点
例题 1：设 E = { (x, y) | x2 + y2 ≤ 1 }（单位闭圆盘），请判断：

(1) 点 (0, 0) 是内点还是边界点？
(2) 点 (1, 0) 呢？
(3) 点 (2, 0) 呢？

解：
(1) (0, 0) 是内点。因为取 δ = 0.5，所有到 (0,0) 距离 < 0.5 的点都满足 x2+y2 < 0.25 < 1，故完全包含在 E 内。
(2) (1, 0) 是边界点。因为无论 δ 多小，邻域内既有圆内点（如 (1-δ/2, 0)），也有圆外点（如 (1+δ/2, 0)）。
(3) (2, 0) 是外点。取 δ = 0.5，所有到 (2,0) 距离 < 0.5 的点都离圆心 > 1，故与 E 无交集。

此外，E 的边界为 { (x, y) | x2 + y2 = 1 }，整个 E 的聚点集为 { (x, y) | x2 + y2 ≤ 1 }（所有内点和边界点都是聚点）。

四、聚点定理（Bolzano-Weierstrass 定理）

Bolzano-Weierstrass 定理（聚点定理）：
R2 中的任意有界无限点集至少有一个聚点。

等价表述：有界无限点列必有收敛子列。

这是数学分析中极为重要的定理，它建立了"无限"与"聚集"之间的联系，是后续学习紧致性概念的基础。

说明：此定理是 R1 中 Bolzano-Weierstrass 定理（有界数列必有收敛子列）在 R2 中的推广，更一般地，该定理在 Rn 中均成立。

五、开集与闭集

1. 开集

如果点集 E 中的每个点都是 E 的内点，则称 E 为开集。

E 是开集 ⇔ 对任意 P ∈ E，存在 δ > 0 使 U(P, δ) ⊂ E

直观理解：开集不包含它的任何边界点。

例子：

  • { (x, y) | x2 + y2 < 1 }（开圆盘）—— 是开集
  • R2 本身 —— 是开集
  • 空集 ∅ —— 是开集（规定）
  • { (x, y) | 0 < x < 1, 0 < y < 1 }（开正方形）—— 是开集

2. 闭集

如果点集 E 的所有聚点都属于 E（即 E 包含其全部极限点），则称 E 为闭集。

等价定义：如果 E 的补集 Ec = R2 \ E 是开集，则 E 是闭集。

例子：

  • { (x, y) | x2 + y2 ≤ 1 }（闭圆盘）—— 是闭集
  • { (x, y) | 0 ≤ x ≤ 1, 0 ≤ y ≤ 1 }（闭正方形）—— 是闭集
  • R2 本身 —— 既是开集又是闭集
  • 空集 ∅ —— 既是开集又是闭集
重要区分：开集和闭集并非"非此即彼"的关系。一个点集可以既是开集也是闭集（如 R2 和 ∅），也可以既不是开集也不是闭集（如半开半闭区间 { (x, y) | 0 < x ≤ 1 }）。

3. 开集与闭集的性质

开集 闭集
任意并 任意个开集的并集仍是开集 有限个闭集的并集仍是闭集
有限交 有限个开集的交集仍是开集 任意个闭集的交集仍是闭集
补集 开集的补集是闭集 闭集的补集是开集

（注意：无限个开集的交集未必是开集，无限个闭集的并集也未必是闭集。）

六、区域

1. 连通性

设 E 是一个点集。如果 E 中任意两点都能用完全属于 E 的折线连接起来，则称 E 是连通的。

例题 2：判断以下集合是否连通：

(a) E1 = { (x, y) | x2 + y2 < 1 }
(b) E2 = { (x, y) | x < 0 } ∪ { (x, y) | x > 0 }
(c) E3 = { (x, y) | 1 < x2 + y2 < 4 }

解：
(a) 连通。单位圆内任意两点都可以用直线段连接，且线段完全在圆内。
(b) 不连通。左右半平面被 x = 0 隔开，无法用折线连接。
(c) 连通。圆环区域中任意两点可以用绕行的折线连接。

2. 开区域（简称区域）

如果 E 既是开集又是连通的，则称 E 为开区域（简称区域）。

例子：

  • { (x, y) | x2 + y2 < 1 }（开圆盘）—— 是区域
  • { (x, y) | x > 0 }（右半平面）—— 是区域
  • { (x, y) | 1 < x2 + y2 < 4 }（开圆环）—— 是区域
  • { (x, y) | x2 + y2 ≤ 1 }（闭圆盘）—— 不是开集，不是区域

3. 闭区域

开区域连同其边界所组成的集合称为闭区域。

更准确地说：如果 D 是一个开区域，则 D ∪ ∂D 称为闭区域（其中 ∂D 表示 D 的边界）。

例子：

  • { (x, y) | x2 + y2 ≤ 1 }（闭圆盘）—— 是闭区域
  • { (x, y) | 0 ≤ x ≤ 1, 0 ≤ y ≤ 1 }（闭正方形）—— 是闭区域

4. 有界集与无界集

如果存在一个以原点为中心的圆盘 U(0, R) 使得 E ⊂ U(0, R)，则称 E 是有界集；否则称为无界集。

概念 定义要点 常见例子
开区域 开集 + 连通 开圆盘、开矩形、开圆环
闭区域 开区域 + 边界 闭圆盘、闭矩形
有界闭区域 闭区域 + 有界 闭圆盘、闭三角形
有界开区域 开区域 + 有界 开圆盘、开矩形
无界区域 区域 + 无界 上半平面、右半平面

七、点集拓扑概念一览表

概念 英文 简短定义
邻域 Neighborhood 以某点为中心、δ 为半径的开圆盘

外点 Exterior point 存在邻域完全不含集合的点

八、常见题型与方法总结

题型 解题思路
判断某个点是否为内点、边界点、聚点 取一般 δ 邻域，检查邻域中点的坐标是否满足条件。
内点：要证明存在某个 δ 使邻域完全在集合内。
边界点/聚点：要证明对任意 δ 邻域都含有特定性质的点。
判断点集是开集还是闭集 检查边界是否包含在集合中：
— 不含任何边界点 → 开集
— 包含所有边界点（即所有聚点）→ 闭集
判断是否为区域 两步法：① 检查是否为开集；② 检查是否连通
求点集的聚点集 聚点 = 内点集 ∪ 边界点集（但不是所有边界点都是聚点）。
注意孤立点不是聚点。
例题 3：判断以下点集是开集、闭集还是都不是，并求其聚点集和边界。

(a) E1 = { (x, y) | 0 < x < 1, 0 < y < 1 }
(b) E2 = { (1/n, 0) | n = 1, 2, 3, ... }
(c) E3 = { (x, y) | x2 + y2 = 1 }

解：
(a) E1 是开集（不含任何边界），是区域（连通的开集）。
 聚点集：{ (x, y) | 0 ≤ x ≤ 1, 0 ≤ y ≤ 1 }（闭正方形）
 边界：正方形的四条边（但不含内部）

(b) E2 既不是开集也不是闭集。每个点都是孤立点。
 聚点集：{ (0, 0) }（仅原点，因为它不在集合中但任何邻域都含有某个 (1/n, 0)）
 边界：E2 ∪ { (0, 0) }

(c) E3 是闭集（单位圆周，不含内点，所有点都是边界点）。
 聚点集：{ (x, y) | x2 + y2 = 1 }（自身）
 边界：自身

九、在多元函数中的重要性

平面点集的基本概念是学习多元函数微分学的几何基础。以下是这些概念在后续章节中的应用：

概念 在多元函数中的应用
邻域 定义多元函数的极限、连续性的基础
聚点 多元函数极限存在的必要条件（自变量趋近的方向分析）
开区域 多元函数的定义域通常是开区域（例如 z = ln(1 - x2 - y2) 定义域是开圆盘）
闭区域 在有界闭区域上，连续函数必有最大值和最小值（最值定理）
边界 函数的最值可能出现在边界上（条件极值）
连通性 与路径无关的曲线积分需要积分区域是连通的开区域
学习建议：这些点集拓扑的基本概念是多元函数微积分学的逻辑基石。建议通过绘制图形来辅助理解——在坐标系中画出点集，标出内点、边界点和外点，直观感受开集、闭集和区域的区别。
