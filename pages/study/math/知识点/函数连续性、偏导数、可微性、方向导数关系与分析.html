函数连续性、偏导数、可微性、方向导数关系与分析

多元函数微分学

📥 下载 PDF 原文

一、概述

在多元函数微分学中，连续性（Continuity）、偏导数（Partial Derivatives）、可微性（Differentiability）和方向导数（Directional Derivatives）是四个核心概念。它们之间既有紧密的联系，又存在本质的区别。理清这一组概念的逻辑关系，是掌握多元函数微分学的关键，也是各类考试中的高频考点。

核心结论：在多元函数中，可微是最强的条件，它蕴含了连续性、偏导数的存在性以及任意方向的方向导数存在性。然而，连续的函数未必可微，且偏导数存在也未必连续。

二、各概念精确定义

1. 连续性

设 z = f(x, y) 在点 P0(x0, y0) 的某邻域内有定义。若

lim(x,y)→(x0,y0) f(x, y) = f(x0, y0)

则称 f(x, y) 在 P0 处连续。直观上，自变量发生微小变化时，函数值也仅发生微小变化，即没有"跳跃"或"断裂"。

2. 偏导数

设 z = f(x, y) 在 (x0, y0) 的某邻域内有定义。固定 y = y0，若

fx(x0, y0) = ∂f/∂x(x0,y0) = limΔx→0 [f(x0+Δx, y0) − f(x0, y0)] / Δx

存在，则称该极限值为 f 在 (x0, y0) 处对 x 的偏导数。类似定义 fy(x0, y0)。

偏导数的本质是"将多元函数视为单元函数"来求导——即沿坐标轴方向的瞬时变化率。

3. 可微性

设 z = f(x, y) 在 (x0, y0) 的某邻域内有定义。若函数值的增量可以表示为

Δz = f(x0+Δx, y0+Δy) − f(x0, y0) = AΔx + BΔy + o(ρ)
（其中 ρ = √[(Δx)2 + (Δy)2]，o(ρ) 为 ρ → 0 时的高阶无穷小）

则称 f 在 (x0, y0) 处可微，且 A = fx(x0, y0)，B = fy(x0, y0)，全微分为

df = fx(x0, y0) dx + fy(x0, y0) dy

可微的直观含义：函数在一点附近可以用平面（切平面）很好地近似，误差是比距离高阶的无穷小。

4. 方向导数

设 z = f(x, y) 在 (x0, y0) 的某邻域内有定义。l 为从 (x0, y0) 出发的射线，方向向量为 (cosα, cosβ)。若

∂f / ∂l = limt→0+ [f(x0+t cosα, y0+t cosβ) − f(x0, y0)] / t

存在，则称该极限为 f 在 (x0, y0) 沿方向 l 的方向导数。方向导数刻画了函数沿任意方向（不限于坐标轴方向）的变化率。

三、核心逻辑关系总图

多元函数在一点处的概念层次（f(x, y) 在 (x0, y0)）

✔ 可微 ⇒ 连续

✔ 可微 ⇒ 偏导数存在

✔ 可微 ⇒ 任意方向的方向导数存在

✔ 偏导数存在且偏导函数连续 ⇒ 可微

✖ 偏导数存在 ⇔ 连续（不一定！）

✖ 连续 ⇔ 偏导数存在（不一定！）

✖ 方向导数存在（每个方向） ⇒ 可微（不一定！）

重要解读

  • 可微 ⇒ 连续：若 f 可微，则 Δz → 0 当 ρ → 0，故连续成立。
  • 可微 ⇒ 偏导数存在：可微时，取 Δy = 0 便得偏导数存在且为系数。
  • 可微 ⇒ 方向导数存在：可微时，沿任意方向 l 的方向导数为 ∇f • (cosα, cosβ)。
  • 偏导连续 ⇒ 可微：这是可微的充分条件（而非必要条件）。

四、典型反例分析

反例1：偏导存在但不连续

函数：

f(x, y) =

(xy) / (x2 + y2)(x, y) ≠ (0, 0)
0(x, y) = (0, 0)

分析：在 (0, 0) 处，沿 y = kx 路径：f(x, kx) = k / (1 + k2)，极限依赖于 k，故极限不存在，函数不连续。

但偏导数：fx(0, 0) = limΔx→0 [f(Δx, 0) − 0] / Δx = 0；同理 fy(0, 0) = 0。偏导数存在，函数却不连续。

结论：偏导存在 ⇒ 连续。

反例2：连续但偏导不存在

函数：f(x, y) = |x| + |y|

分析：此函数在 (0, 0) 处显然连续。但沿 x 轴方向：f(x, 0) = |x| 在 x = 0 处不可导，故 fx(0, 0) 不存在。

结论：连续 ⇒ 偏导存在。

反例3：可微的偏导不连续

函数：

f(x, y) =

(x2 + y2) sin[1 / (x2 + y2)](x, y) ≠ (0, 0)
0(x, y) = (0, 0)

分析：在 (0, 0) 处，f 可微（利用有界震荡函数乘以高阶无穷小）。但偏导函数 fx(x, y) 在 (0, 0) 附近震荡，不连续。

结论："偏导函数连续"是充分而非必要条件。

反例4：所有方向导数存在但不可微

函数：

f(x, y) =

x3 / (x2 + y2)(x, y) ≠ (0, 0)
0(x, y) = (0, 0)

分析：在 (0, 0) 处沿任意方向的方向导数均存在（且为0）。但函数不连续（沿路径 y = x 无极限），故不可微。

结论：方向导数（全部方向）存在 ⇒ 可微。

五、可微的充分条件与必要条件总结

条件类型 条件内容 说明
必要条件 可微 ⇒ 连续 函数值增量是 o(ρ) 量级，必然连续
必要条件 可微 ⇒ 偏导存在 沿坐标轴增量分解即得
充分条件 偏导存在且连续 ⇒ 可微 经典充分条件，非必要
充要条件（n=2） 偏导存在且 Δz − (fxΔx + fyΔy) = o(ρ) 直接按定义验证

六、方向导数与梯度

若 f(x, y) 在 (x0, y0) 处可微，则沿任一方向 l（方向余弦 (cosα, cosβ)）的方向导数可通过梯度计算：

∂f / ∂l = ∇f(x0, y0) • (cosα, cosβ)
= fx(x0, y0) cosα + fy(x0, y0) cosβ

梯度 ∇f = (fx, fy) 的方向是函数值增长最快的方向，其模长即为方向导数的最大值：

max |∂f / ∂l| = ||∇f|| = √(fx2 + fy2)

梯度方向与等值线的法方向一致，是函数变化最剧烈的方向。

七、关系速查表

条件 连续 偏导存在 方向导数存在 可微
连续 ✔ 不一定 不一定 不一定
偏导存在 不一定 ✔ 沿坐标轴存在 不一定
方向导数存在（所有方向） 不一定 不一定 ✔ 不一定
可微 ✔ ✔ ✔ ✔
偏导连续 ✔ ✔ ✔ ✔

八、解题方法与常见题型

题型1：判断可微性

步骤：

  1. 检查函数是否连续（若不连续则直接判定不可微）。
  2. 计算偏导数 fx(x0, y0) 和 fy(x0, y0) 是否都存在（若某个不存在则不可微）。
  3. 利用定义验证 Δz − (fxΔx + fyΔy) = o(ρ)，关键计算极限
lim(Δx, Δy)→(0,0) |f(x0+Δx, y0+Δy) − f(x0, y0) − fxΔx − fyΔy| / √[(Δx)2 + (Δy)2] = 0

若极限为0则可微，否则不可微。

题型2：判断偏导数连续性

先求出 fx(x, y) 和 fy(x, y) 的表达式（在非零点用求导公式，在分界点用定义），再检验偏导函数在分界点处是否连续——即

lim(x,y)→(x0,y0) fx(x, y) = fx(x0, y0)

题型3：计算方向导数与梯度

步骤：

  1. 判断函数在目标点是否可微（只有可微才能用梯度公式）。
  2. 若可微，计算梯度 ∇f。
  3. 写出方向余弦 (cosα, cosβ)，代入点乘得到方向导数。
  4. 若要找最大增长方向——即梯度方向；最大增长率为梯度模长。

九、常见错误与注意事项

  • 误区一：误以为"偏导存在则连续"。实际上偏导存在仅保证沿坐标轴方向的变化率存在，并非所有路径。
  • 误区二：误以为"连续则偏导存在"。连续仅保证用"直线逼近"时无跳跃，但沿坐标轴可能有尖点。
  • 误区三：方向导数全存在不保证可微。反例见上面例4。
  • 误区四：混淆"偏导函数连续"与"偏导存在"。前者是更强的条件。
  • 注意事项：判断可微性时，优先检查——若不连续或偏导不全存在，直接否定。否则用定义严格验证。
  • 注意事项：方向导数的方向余弦必须满足 cos2α + cos2β = 1。

十、关系层次图（逻辑阶梯）

最强 → 偏导函数连续（C1类）

⇓

可微（全微分存在，切平面良好逼近）

⇓ ⇒

连续      偏导数存在

⇓ ⇒

（底层是沿每条路径的一致逼近性质）
