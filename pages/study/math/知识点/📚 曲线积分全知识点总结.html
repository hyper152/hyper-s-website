重积分与线面积分

一、曲线积分概述

曲线积分是多元函数积分学的重要组成部分，它研究的是函数沿曲线的积分。根据被积函数的类型和积分路径的方向性，曲线积分分为两大类：

类型 名称 被积对象 物理意义
第一型 对弧长的曲线积分 标量函数 f(x,y,z) 曲线质量、弧长等
第二型 对坐标的曲线积分 向量场 F = (P,Q,R) 变力沿曲线做功、环流量
关键区别： 第一型曲线积分与方向无关（无向），第二型曲线积分与方向有关（有向），反转路径方向会使第二型曲线积分变号。

二、第一型曲线积分（对弧长的曲线积分）

1. 定义

设 L 为空间中一条可求长的光滑曲线，f(x,y,z) 在 L 上有定义，将 L 任意分割为 n 个小弧段，在每个弧段上任取一点，作黎曼和的极限：

∫L f(x,y,z) ds = limλ→0 ∑i=1n f(ξi, ηi, ζi) Δsi

其中 ds 称为弧长微元。

2. 计算方法（参数方程法）

若曲线 L 由参数方程 x = x(t), y = y(t), z = z(t)（α ≤ t ≤ β）给出，则：

∫L f(x,y,z) ds = ∫αβ f(x(t), y(t), z(t)) √(x'(t)² + y'(t)² + z'(t)²) dt

其中 ds = √(x'(t)² + y'(t)² + z'(t)²) dt 为弧长微分公式。

3. 几种特殊情形

  • 平面曲线 y = y(x)（a ≤ x ≤ b）：
    ∫L f(x,y) ds = ∫ab f(x, y(x)) √(1 + (y'(x))²) dx
  • 极坐标曲线 r = r(θ)（α ≤ θ ≤ β）：
    ∫L f(r,θ) ds = ∫αβ f(r(θ),θ) √(r(θ)² + (r'(θ))²) dθ

4. 性质

性质表达式
线性性∫ (αf + βg) ds = α∫f ds + β∫g ds
路径可加性∫L1+L2 f ds = ∫L1 f ds + ∫L2 f ds
无方向性∫L− f ds = ∫L f ds（与方向无关）
比较定理若 f ≤ g 在 L 上，则 ∫L f ds ≤ ∫L g ds

三、第二型曲线积分（对坐标的曲线积分）

1. 定义

设向量值函数 F(x,y,z) = (P(x,y,z), Q(x,y,z), R(x,y,z)) 在有向光滑曲线 L 上连续，则：

∫L P dx + Q dy + R dz = ∫L F · dr

其中 dr = (dx, dy, dz) 为有向弧微元。

2. 计算方法（参数方程法）

若 L 由参数方程 x = x(t), y = y(t), z = z(t)（t: α → β，α 为起点，β 为终点）给出：

∫L P dx + Q dy + R dz = ∫αβ [P·x'(t) + Q·y'(t) + R·z'(t)] dt

3. 两种曲线积分之间的联系

同一曲线上，两类曲线积分通过切向量方向余弦相互转换：

∫L P dx + Q dy + R dz = ∫L (P cos α + Q cos β + R cos γ) ds

其中 (cos α, cos β, cos γ) 为曲线 L 在指定方向上的单位切向量的方向余弦。

四、格林公式（Green 公式）

1. 定理表述

设闭区域 D 由分段光滑的闭曲线 L 围成，函数 P(x,y) 和 Q(x,y) 在 D 上具有一阶连续偏导数，则：

∮L P dx + Q dy = ∬D (∂Q/∂x − ∂P/∂y) dxdy

其中 L 取正向（即区域 D 始终在左侧的行走方向，对应逆时针方向）。

2. 格林公式的应用

  • 计算封闭曲线上的第二型曲线积分：转化为二重积分计算
  • 计算平面区域面积：取 P = −y, Q = x，得：
    A = ∬D dxdy = ½ ∮L x dy − y dx
  • 判断曲线积分与路径无关：当 ∂Q/∂x − ∂P/∂y = 0 且 D 为单连通区域时，积分与路径无关
注意： 如果函数 P,Q 在 D 内部有奇点（不连续点），不能直接使用格林公式，需要通过挖洞法（取绕奇点的小圆或闭合回路）处理。

五、曲线积分与路径无关

1. 等价条件

设 D 是单连通区域，P,Q 在 D 上连续可微，则以下命题等价：

  1. 曲线积分 ∫L P dx + Q dy 在 D 内与路径无关
  2. 对 D 内任意闭曲线 C，有 ∮C P dx + Q dy = 0
  3. 在 D 内恒有 ∂Q/∂x = ∂P/∂y
  4. 存在可微函数 u(x,y) 使 du = P dx + Q dy（即 P = ∂u/∂x，Q = ∂u/∂y）

2. 原函数的求法

当积分与路径无关时，可选特殊路径（如折线）计算原函数：

u(x,y) = ∫(x₀,y₀)(x,y) P dx + Q dy

通常取 (x₀,y₀) 为原点或方便的起始点，路径由平行于坐标轴的折线构成。

六、典型例题

例 1： 计算第一型曲线积分 ∫L (x² + y²) ds，其中 L 为圆周 x = a cos t, y = a sin t（0 ≤ t ≤ 2π）。

解： ds = √(x'(t)² + y'(t)²) dt = √((−a sin t)² + (a cos t)²) dt = a dt
∫L (x² + y²) ds = ∫02π (a² cos² t + a² sin² t) · a dt = ∫02π a³ dt = 2π a³
例 2： 计算第二型曲线积分 ∫L y dx + x dy，其中 L 为从 (1,0) 到 (0,1) 的上半圆弧 x² + y² = 1。

解： 参数化 x = cos t, y = sin t（t: 0 → π/2）
∫L y dx + x dy = ∫0π/2 [sin t · (−sin t) + cos t · cos t] dt
= ∫0π/2 (−sin² t + cos² t) dt = ∫0π/2 cos(2t) dt = 0
例 3（格林公式应用）： 计算 ∮L (2xy − x²) dx + (x + y²) dy，L 为正向圆周 x² + y² = 4。

解： P = 2xy − x², Q = x + y²
∂Q/∂x = 1, ∂P/∂y = 2x
∮L P dx + Q dy = ∬D (1 − 2x) dxdy = ∬D 1 dxdy − 2 ∬D x dxdy
由对称性 ∬D x dxdy = 0，∬D dxdy = 4π，故结果为 4π。
例 4（与路径无关）： 验证积分 ∫L (2xy + 1) dx + (x² + 2y) dy 与路径无关，并求从 (0,0) 到 (1,2) 的积分值。

验证： P = 2xy + 1, Q = x² + 2y
∂P/∂y = 2x, ∂Q/∂x = 2x，满足 ∂Q/∂x = ∂P/∂y，故与路径无关。

计算： 取折线路径 (0,0) → (1,0) → (1,2)
第一段（y=0, dy=0, x: 0→1）：∫01 (2x·0 + 1) dx = ∫01 dx = 1
第二段（x=1, dx=0, y: 0→2）：∫02 (1² + 2y) dy = [y + y²]02 = 2 + 4 = 6
总积分 = 7

七、常见误区与解题技巧

常见误区

  • 混淆两类曲线积分：第一型对弧长（标量），第二型对坐标（向量）
  • 忘记弧长微元：第一型积分中 ds 不是 dt，而是 √(x'² + y'²) dt
  • 忽略方向：第二型曲线积分换向时记得加负号
  • 格林公式方向：闭曲线方向必须是正向（逆时针），否则差一个负号
  • 奇点问题：被积函数在围成区域内有奇点时不能直接使用格林公式

解题技巧

  • 对称性：利用积分曲线的对称性简化被积函数
  • 代入曲线方程：第一型曲线积分中，可将曲线方程代入被积函数化简
  • 补线法：对非闭曲线的第二型积分，可补一条简单曲线使之闭合后使用格林公式
  • 凑微分法：寻找原函数直接计算积分值
  • 参数化技巧：选择合适的参数化形式可大幅简化计算
