一、高斯公式概述

高斯公式（Gauss's Theorem，又称散度定理）是矢量分析中的核心定理之一。 它建立了封闭曲面上的曲面积分与该曲面所围区域上的三重积分之间的联系。 本质上，高斯公式描述了向量场通过一个封闭曲面的通量等于该向量场的散度在曲面所围区域上的积分。

高斯公式与格林公式、斯托克斯公式共同构成了三大积分公式体系， 是将区域内部的性质与边界上的性质相互转化的桥梁。

核心思想： 边界上的积分 ↔ 内部的积分。高斯公式将封闭曲面的通量转化为体积分，大大简化了计算。

二、高斯公式定理

1. 定理内容

设空间区域 Ω 由分片光滑的封闭曲面 S 所围成。 若函数 P(x,y,z)、Q(x,y,z)、R(x,y,z) 在 Ω 上具有一阶连续偏导数，则：

&iint;S P dy dz + Q dz dx + R dx dy = ∭Ω (∂P/∂x + ∂Q/∂y + ∂R/∂z) dv

其中 S 取外侧为正向。上式也可写作向量形式：

&iint;S A ⋅ dS = ∭Ω div A dv

其中 A = (P, Q, R) 为向量场，div A = ∇ ⋅ A 为散度。

2. 三种常用形式

形式 表达式 说明
坐标形式 &iint;S P dy dz + Q dz dx + R dx dy 分别投影到坐标平面
向量形式 &iint;S A ⋅ n dS = ∭Ω ∇ ⋅ A dv n 为单位外法向量
分量展开 &iint;S P dydz + Q dzdx + R dxdy = ∭Ω (Px + Qy + Rz) dv 偏导求和形式

三、散度的概念与计算

1. 散度定义

向量场 A = (P(x,y,z), Q(x,y,z), R(x,y,z)) 在点 (x,y,z) 处的散度定义为：

div A = ∇ ⋅ A = ∂P/∂x + ∂Q/∂y + ∂R/∂z

散度的物理意义：散度表示向量场在某点处"发散"或"汇聚"的强度。

  • div A > 0：该点处有"源"（向外发散），如正电荷
  • div A < 0：该点处有"汇"（向内汇聚），如负电荷
  • div A = 0：该点处无源无汇，称为无散场（管形场）

2. 散度的运算法则

  • div (cA) = c div A（c 为常数）
  • div (A + B) = div A + div B
  • div (uA) = u div A + A ⋅ ∇ u（u 为标量函数）

四、高斯公式的应用方法

1. 计算封闭曲面的曲面积分

高斯公式最直接的应用：将曲面积分转化为三重积分，避免直接处理曲面投影的复杂性。

例 1： 计算 &iint;S x3 dydz + y3 dzdx + z3 dxdy， 其中 S 是球面 x2 + y2 + z2 = a2 的外侧。

解：
由高斯公式：
&iint;S ... = ∭Ω (3x2 + 3y2 + 3z2) dv
= 3 ∭Ω (x2 + y2 + z2) dv
采用球坐标：x2 + y2 + z2 = r2， dv = r2 sin φ dr dφ dθ
= 3 ∫02π dθ ∫0π sin φ dφ ∫0a r4 dr
= 3 × 2π × 2 × a5/5 = 12πa5/5

2. 计算非封闭曲面（补面法）

当曲面不封闭时，可添加辅助曲面（如平面盖）使其封闭，再用高斯公式计算， 最后减去辅助曲面上的积分。

例 2： 计算曲面积分 &iint;Σ x dydz + y dzdx + z dxdy， 其中 Σ 是锥面 z = √(x2 + y2) 被平面 z = 1 所截部分的下侧。

解： 补上平面 Σ1: z = 1（上侧）， 使 Σ ∪ Σ1 构成封闭曲面，取外侧。
由高斯公式：&iint;Σ+Σ1 ... = ∭Ω 3 dv = 3 × V
锥体体积 V = π/3，故原积分 = π - (补面上的积分)， 补面 z=1 上 dz = 0， x dydz + y dzdx = 0，z dxdy = 1 × dxdy
&iint;Σ1 dxdy = π（半径为 1 的圆面积）
因此原积分 = 3 × π/3 - π = 0

3. 计算三重积分

在某些情形下，也可反向使用高斯公式，将复杂的体积分转化为曲面积分来简化计算。

五、通量与散度的物理意义

1. 通量的概念

向量场 A 通过曲面 S 的通量定义为：

Φ = &iint;S A ⋅ dS = &iint;S A ⋅ n dS

通量表示向量场穿过曲面的"总量"：

  • 对流速场 v，通量 = 单位时间流过曲面的流体体积
  • 对电场 E，通量 = 通过曲面的电通量

2. 散度的物理意义

散度的物理意义可通过高斯公式理解：

div A(x0, y0, z0) = limV → 0 (1/V) &iint;S A ⋅ n dS

即散度是单位体积的通量，描述向量场在某点的"源密度"。 高斯公式本质上是将散度的体积分加起来等于总通量。

六、高斯公式的适用条件与注意事项

条件/注意事项 说明
曲面必须封闭 高斯公式要求 S 是封闭曲面；若不封闭，需补面处理
取外侧方向 标准高斯公式中外法线方向为正；若取内侧需加负号
偏导数连续 P,Q,R 需在 Ω 内有一阶连续偏导
奇点处理 若有奇点（偏导不连续），需挖去小邻域再应用高斯公式
曲面分片光滑 允许曲面由多片光滑曲面拼接而成
方向一致性 补面时注意辅助曲面的方向与原曲面需构成封闭的外侧
常见陷阱： 使用高斯公式时最容易忽略的是曲面方向问题。一定要确认曲面取的是外侧还是内侧， 以及被积函数在区域内是否具有一阶连续偏导数。若遇到分母有 r 的形式（如 1/r2 场）， 原点往往是奇点，需要特殊处理。

七、高斯公式与格林公式的对比

对比项 格林公式（二维） 高斯公式（三维）
适用维度 二维平面 三维空间
边界 平面封闭曲线 空间封闭曲面
内部区域 平面区域 D 空间区域 Ω
边界积分 对坐标的曲线积分 对坐标的曲面积分
内部积分 二重积分 三重积分
核心算子 旋度（二维） 散度

八、典型例题分析

例 3： 含奇点的高斯公式应用
求 &iint;S (x dydz + y dzdx + z dxdy) / (x2 + y2 + z2)3/2， 其中 S 是球面 x2 + y2 + z2 = a2 的外侧。

解： 被积函数在原点处不连续（奇点）。
取 A = (x, y, z) / r3，其中 r = √(x2 + y2 + z2)。
计算散度：div A = 0（在 r ≠ 0 处）
但由于原点处有奇点，需挖去以原点为中心、 半径 ε → 0 的小球面 Sε（取内侧）。
在挖掉后的区域上使用高斯公式得：
&iint;S ... + &iint;Sε ... = 0
故 &iint;S ... = - &iint;Sε ...
在 Sε 上，r = ε 为常数，
&iint;Sε ... = (1/ε3) &iint;Sε x dydz + y dzdx + z dxdy
由高斯公式（在球体内）：
= (1/ε3) × 3 × (4πε3/3) = 4π
注意 Sε 取内侧，故最终结果为 -4π。
例 4： 利用高斯公式计算三重积分
计算 ∭Ω (x2 + y2 + z2) dv， 其中 Ω 是椭球面 x2/a2 + y2/b2 + z2/c2 = 1 所围区域。

解： 直接计算三重积分较复杂。
取 P = x3, Q = y3, R = z3，则 ∂P/∂x = 3x2 等。
反向使用格林公式的推广（高斯公式的逆用并不直接简单）， 更直接的做法是利用对称性和广义球坐标变换：
x = aρ sinφ cosθ, y = bρ sinφ sinθ, z = cρ cosφ
J = abc ρ2 sinφ
x2 + y2 + z2 = a2ρ2 sin2φ cos2θ + b2ρ2 sin2φ sin2θ + c2ρ2 cos2φ
积分：∫02π cos2θ dθ = π， ∫02π sin2θ dθ = π， ∫0π sin3 φ dφ = 4/3， ∫01 ρ4 dρ = 1/5
最终整理得：原式 = (4πabc/15)(a2 + b2 + c2)

九、应用场景总结

应用场景 方法 典型条件
封闭曲面上的曲面积分 直接应用高斯公式 曲面封闭、外侧、偏导连续
非封闭曲面的曲面积分 补面法：添加辅助面后减掉 辅助面易于计算
含奇点的曲面积分 挖洞法：挖去奇点邻域 奇点被挖掉后区域无奇点

利用对称性化简 取适当 P,Q,R 反向使用 被积函数有特殊形式
