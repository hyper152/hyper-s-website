对称式与参数式方程

空间解析几何 — 空间直线的方程表示与转换

📥 下载 PDF 原文

一、空间直线方程的三种基本形式

1. 一般式方程（交面式）

空间直线可以看作两个平面的交线。设平面 π1 和 π2 的方程分别为：

A1x + B1y + C1z + D1 = 0
A2x + B2y + C2z + D2 = 0

则直线的一般式方程为联立形式：

⎮ A1x + B1y + C1z + D1 = 0
⎮ A2x + B2y + C2z + D2 = 0

其中 (A1, B1, C1) 与 (A2, B2, C2) 不共线（即两平面不平行）。直线的方向向量 s 可由两平面法向量的向量积得到：

s = n1 × n2 = (A1, B1, C1) × (A2, B2, C2)

2. 对称式方程（点向式）

若直线过已知点 M0(x0, y0, z0)，方向向量为 s = (m, n, p)（m, n, p 不全为零），则直线上任意一点 M(x, y, z) 满足 M0M 与 s 平行，即对应坐标成比例：

⎮ x - x0 / m = y - y0 / n = z - z0 / p

这就是直线的对称式方程（也称为点向式方程）。

注意：若方向向量的某个分量为零，如 m = 0，则对称式应理解为 x - x0 = 0 且 (y - y0) / n = (z - z0) / p。

3. 参数式方程

令对称式方程中的比值为参数 t，即：

x - x0 / m = y - y0 / n = z - z0 / p = t

得到参数式方程：

⎮ x = x0 + m t
⎮ y = y0 + n t
⎮ z = z0 + p t
t 为参数，t ∈ R

参数 t 的几何意义：当 |s| = 1 时（即方向向量为单位向量），|t| 表示点 M 到点 M0 的距离。

二、三种形式之间的相互转换

转换方向 方法
一般式 → 对称式 1. 求方向向量 s = n1 × n2
2. 求直线上一点：令 x = 0（或其他方便的值），解方程组得到 y, z
3. 代入对称式公式
一般式 → 参数式 先化为对称式，再令比值等于 t
对称式 → 参数式 令 (x - x0) / m = (y - y0) / n = (z - z0) / p = t，解出 x, y, z
对称式 → 一般式 将对称式拆分为两个等式：(x - x0) / m = (y - y0) / n 和 (y - y0) / n = (z - z0) / p，交叉相乘化为平面方程
参数式 → 对称式 从参数式中解出 t = (x - x0) / m = (y - y0) / n = (z - z0) / p
例题 1：将直线的一般式方程 x + y + z + 1 = 0 和 2x - y + 3z + 4 = 0 化为对称式和参数式。

解：
① 求方向向量：s = n1 × n2 = (1,1,1) × (2,-1,3)
 = (1·3 - 1·(-1), 1·2 - 1·3, 1·(-1) - 1·2)
 = (3 + 1, 2 - 3, -1 - 2) = (4, -1, -3)

② 求直线上一点：令 z = 0，解 x + y + 1 = 0, 2x - y + 4 = 0，得 x = -5/3, y = 2/3，即点 M0(-5/3, 2/3, 0)。

③ 对称式：(x + 5/3) / 4 = (y - 2/3) / (-1) = z / (-3)

④ 参数式：令比值 = t，得
 x = -5/3 + 4t, y = 2/3 - t, z = -3t

三、方向向量与方向余弦

直线的方向向量 s = (m, n, p) 决定了直线的方向。方向向量乘以任意非零常数仍表示同一条直线。

若将方向向量单位化，记 s0 = (cos α, cos β, cos γ)，其中：

cos α = m / √(m2 + n2 + p2)
cos β = n / √(m2 + n2 + p2)
cos γ = p / √(m2 + n2 + p2)

称为直线的方向余弦，满足 cos2α + cos2β + cos2γ = 1。

此时直线的参数式可以写为：

x = x0 + t cos α
y = y0 + t cos β
z = z0 + t cos γ

其中参数 t 的绝对值即为点到 M0 的有向距离。

四、两直线的位置关系

设两直线 L1 和 L2 的方向向量分别为 s1 = (m1, n1, p1) 和 s2 = (m2, n2, p2)，过点 M1 和 M2。

位置关系 判定条件
平行 s1 × s2 = 0（即方向向量共线）且 M1M2 不与 s1 平行
重合 s1 ∥ s2 且 M1M2 ∥ s1
相交 s1 与 s2 不共线，且三向量 s1, s2, M1M2 共面（混合积为零）
异面 s1, s2, M1M2 的混合积不为零，即 (s1 × s2) · M1M2 ≠ 0
垂直 s1 · s2 = 0

两直线的夹角

两直线方向向量的夹角（取锐角）即为两直线的夹角：

cos θ = |s1 · s2| / |s1| |s2| = |m1m2 + n1n2 + p1p2| / √(m12 + n12 + p12) √(m22 + n22 + p22)

其中 0 ≤ θ ≤ π/2。

例题 2：判断直线 L1: (x-1)/2 = (y+2)/(-1) = (z-3)/4 和 L2: x = 2t, y = 3 - t, z = 1 + 2t 的位置关系。

解：
L1 的方向向量 s1 = (2, -1, 4)，过点 M1(1, -2, 3)
L2 的方向向量 s2 = (2, -1, 2)，过点 M2(0, 3, 1)
由于 s1 与 s2 不共线，计算混合积：
M1M2 = (-1, 5, -2)
(s1 × s2) · M1M2 = ...
计算得混合积 = 0，故两直线相交。

五、直线与平面的位置关系

设直线 L 的方向向量为 s = (m, n, p)，平面 π 的法向量为 n = (A, B, C)。

位置关系 判定条件
直线在平面上 s · n = 0 且直线上一点满足平面方程
直线与平面平行 s · n = 0 但直线上点不满足平面方程
直线与平面相交 s · n ≠ 0（有唯一交点）
直线与平面垂直 s ∥ n，即 m/A = n/B = p/C

直线与平面的夹角

直线与它在平面上的投影直线之间的夹角 φ（0 ≤ φ ≤ π/2）：

sin φ = |s · n| / |s| |n| = |Am + Bn + Cp| / √(A2 + B2 + C2) √(m2 + n2 + p2)

直线与平面的交点

将直线的参数式代入平面方程，解出参数 t，再代回参数方程即得交点坐标。

例题 3：求直线 (x-1)/2 = y/3 = (z+2)/(-1) 与平面 x - 2y + 3z - 1 = 0 的交点。

解：将直线化为参数式：
x = 1 + 2t, y = 3t, z = -2 - t
代入平面方程：(1 + 2t) - 2(3t) + 3(-2 - t) - 1 = 0
1 + 2t - 6t - 6 - 3t - 1 = 0
-7t - 6 = 0，解得 t = -6/7
代入得交点 (1 - 12/7, -18/7, -2 + 6/7) = (-5/7, -18/7, -8/7)

六、点到直线的距离

设直线 L 过点 M0，方向向量为 s，点 M1 为直线外一点，则点 M1 到直线 L 的距离为：

d = |M0M1 × s| / |s|

即向量 M0M1 与方向向量 s 所张平行四边形的面积除以底边长 |s|。

两异面直线的距离

设两异面直线 L1（过点 M1，方向 s1）和 L2（过点 M2，方向 s2）的公垂线距离为：

d = |(s1 × s2) · M1M2| / |s1 × s2|

即混合积的绝对值除以方向向量叉积的模。

七、常见题型与方法总结

题型 解题思路
求过一点且与已知直线平行的直线方程 使用相同的方向向量，代入点的坐标到对称式或参数式
求过一点且与已知平面垂直的直线方程 以平面的法向量作为直线的方向向量
求过一点且与两直线都垂直的直线方程 方向向量 s = s1 × s2
求过一点且与已知直线垂直相交的直线 先求过该点且与已知直线垂直的平面，再求该平面与已知直线的交点
求直线在平面上的投影直线方程 先求过直线且与已知平面垂直的平面（法向量 = s × n），再联立两平面
常见错误提醒：
1. 方向向量不是唯一的——任何非零倍数都是同一个方向向量。
2. 对称式中分母为零时，表示对应坐标恒等于点的坐标。
3. 两直线的夹角取锐角，用方向向量点积的绝对值除以模长之积。
4. 参数 t 的取值约定不同会导致参数方程形式不同，但表示同一直线。
