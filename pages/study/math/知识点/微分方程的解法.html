微分方程的解法

微分方程 — 一阶、二阶、高阶微分方程的各类解法全梳理

📥 下载 PDF 原文

一、概述

微分方程是描述未知函数及其导数之间关系的方程，是高等数学的核心内容之一。根据阶数、线性性、齐次性等特征，微分方程可分为多种类型，各自有特定的求解方法。本文系统梳理从一阶到高阶微分方程的主要解法，涵盖可分离变量、齐次方程、一阶线性微分方程、可降阶方程、常系数线性微分方程及 Euler 方程等核心类型。

微分方程在物理（运动方程、热传导）、工程（电路分析、控制理论）、生物（种群模型）等领域有极其广泛的应用。

二、一阶微分方程的解法

一阶微分方程的一般形式为 F(x, y, y') = 0 或 y' = f(x, y)。以下是几种主要类型及其解法。

2.1 可分离变量方程

形式：y' = g(x)h(y) 或 M(x)N(y)dx + P(x)Q(y)dy = 0

解法：分离变量后两边积分。

dy/dx = g(x)h(y) ⇒ ∫ dy/h(y) = ∫ g(x) dx + C
例：求 y' = 2xy 的通解。
解：分离变量 dy/y = 2x dx，积分 ∫ dy/y = ∫ 2x dx，得 ln|y| = x2 + C，即 y = Cex2。

2.2 一阶齐次方程

形式：y' = f(y/x)

解法：令 u = y/x，则 y = ux，y' = u + x·du/dx，代入后化为可分离变量方程。

u + x·du/dx = f(u) ⇒ ∫ du/(f(u) - u) = ∫ dx/x + C

2.3 一阶线性微分方程

形式：y' + P(x)y = Q(x)

解法：使用 积分因子法（常数变易法）。

积分因子 μ(x) = e∫ P(x) dx

通解：y = (1/μ(x)) ∫ μ(x)Q(x) dx + C/μ(x)

步骤：

  1. 计算积分因子 μ = e∫ P(x) dx
  2. 方程两边同乘 μ，化为 (μy)' = μQ
  3. 两边积分即得通解
例：求 y' + 2xy = x 的通解。
解：P(x) = 2x，μ = e∫ 2x dx = ex2
方程变为 (ex2y)' = xex2
积分得 ex2y = ½ex2 + C
即 y = ½ + Ce-x2

2.4 伯努利方程

形式：y' + P(x)y = Q(x)yn（n ≠ 0, 1）

解法：令 z = y1-n，化为关于 z 的一阶线性方程。

z = y1-n ⇒ z'/(1-n) + P(x)z = Q(x)
即 z' + (1-n)P(x)z = (1-n)Q(x)

2.5 一阶微分方程解法速查表

方程类型标准形式解法要点
可分离变量y' = g(x)h(y)分离 → 积分
齐次方程y' = f(y/x)令 u = y/x → 可分离
一阶线性y' + P(x)y = Q(x)积分因子 μ = e∫ Pdx
伯努利方程y' + P(x)y = Q(x)yn令 z = y1-n → 线性
全微分方程Mdx + Ndy = 0
∂M/∂y = ∂N/∂x		求势函数 F 使 dF = Mdx + Ndy

三、可降阶的高阶微分方程

某些高阶方程可通过变量代换降为一阶方程求解。

3.1 y(n) = f(x) 型

直接逐次积分 n 次即得通解。

y = ∫ ⋯ ∫ f(x) dx ⋯ dx（n 次积分）+ C1xn-1 + C2xn-2 + ... + Cn

3.2 不显含 y 的方程

形式：F(x, y', y'') = 0

解法：令 p = y'，则 y'' = p'，化为关于 p 的一阶方程。

3.3 不显含 x 的方程

形式：F(y, y', y'') = 0

解法：令 p = y'，利用 y'' = p·dp/dy 化为关于 p 的一阶方程。

y'' = d(y')/dx = (dp/dy)·(dy/dx) = p·dp/dy
例：求 yy'' = (y')2 的通解。
解：不显含 x，令 p = y'，y'' = p·dp/dy
代入得 y·p·dp/dy = p2，若 p ≠ 0，消去 p：
y·dp/dy = p ⇒ dp/p = dy/y
积分得 ln|p| = ln|y| + C1，即 p = C1y
dy/dx = C1y ⇒ y = C2eC1x

四、高阶线性微分方程

4.1 解的结构

n 阶线性微分方程的一般形式：

y(n) + a1(x)y(n-1) + ... + an-1(x)y' + an(x)y = f(x)

解的结构定理：

  • 齐次解（通解）：yh = C1y1 + C2y2 + ... + Cnyn（y1, ..., yn 为 n 个线性无关的特解）
  • 非齐次通解：y = yh + yp（齐次通解 + 一个特解）

4.2 常系数齐次线性微分方程

形式：y'' + py' + qy = 0（二阶）或更高阶

解法：列 特征方程，解特征根。

二阶：r2 + pr + q = 0
特征根情况通解形式
两个不等实根 r1 ≠ r2y = C1er1x + C2er2x
两个相等实根 r1 = r2 = ry = (C1 + C2x)erx
共轭复根 r = α ± iβy = eαx(C1cosβx + C2sinβx)
例：求 y'' + 4y = 0 的通解。
解：特征方程 r2 + 4 = 0，r = ±2i
α = 0，β = 2
通解：y = C1cos2x + C2sin2x

4.3 常系数非齐次线性微分方程

形式：y'' + py' + qy = f(x)

解法：先用前一方法求齐次通解 yh，再用以下方法求特解 yp。

方法一：待定系数法（常用）

根据 f(x) 的形式，设特解形式，代入方程确定系数。

f(x) 的形式特解形式
Pm(x)eλxyp = xkQm(x)eλx
eαx[Pl(x)cosβx + Qn(x)sinβx]yp = xkeαx[Rm(x)cosβx + Sm(x)sinβx]

其中 k 为 λ（或 α + iβ）作为特征根的重数，m = max(l, n)。

方法二：常数变易法

设 yp = u1(x)y1 + u2(x)y2，其中 y1, y2 为齐次方程的两个线性无关解。列出方程组求解 u1', u2'。

u1'y1 + u2'y2 = 0
u1'y1' + u2'y2' = f(x)
例：求 y'' + 4y = 8sin2x 的通解。
解：齐次通解 yh = C1cos2x + C2sin2x
f(x) = 8sin2x，α = 0，β = 2 是特征根（单根），k = 1
设 yp = x(Acos2x + Bsin2x)，代入得 A = -2，B = 0
通解：y = C1cos2x + C2sin2x - 2xcos2x

五、Euler 方程（变系数可化常系数）

形式：

x2y'' + pxy' + qy = f(x)

解法：令 x = et（或 t = ln|x|），化为关于 t 的常系数方程。

记 D = d/dt，则：
xy' = Dy，x2y'' = D(D-1)y
原方程化为 D(D-1)y + pDy + qy = f(et)
例：求 x2y'' - 2xy' + 2y = 0 的通解。
解：令 x = et，xy' = Dy，x2y'' = D(D-1)y
代入得 D(D-1)y - 2Dy + 2y = 0
即 (D2 - 3D + 2)y = 0，特征方程 r2 - 3r + 2 = 0
r1 = 1，r2 = 2
y = C1et + C2e2t = C1x + C2x2

六、特殊类型与解题技巧

6.1 恰当方程与积分因子

对于 M(x,y)dx + N(x,y)dy = 0，若 ∂M/∂y ≠ ∂N/∂x，可寻找积分因子 μ(x,y)，使 μMdx + μNdy = 0 成为恰当方程。

6.2 一阶隐式方程

形式 F(x, y, y') = 0，可尝试：

  • 解出 y' → 化为显式方程
  • 引入参数法（如设 y' = p，将 x 或 y 表示为 p 的函数）
  • Clairaut 方程：y = xy' + φ(y')，通解为 y = Cx + φ(C)

6.3 解的结构图示

微分方程类型解法路径
一阶判别类型 → 分离变量/齐次/线性/伯努利 → 求解
可降阶判断缺 x 或缺 y → 令 p = y' 降阶 → 一阶方程
高阶常系数线性特征方程 → 齐次通解 + 特解（待定系数/常数变易）
Euler 方程令 x = et → 常系数方程 → 求解 → 代回

七、应用举例

应用 1：弹簧振子（简谐振动）
由 Newton 第二定律 F = ma 和 Hooke 定律 F = -kx：
m·d2x/dt2 + kx = 0 （二阶常系数齐次方程）
特征方程 mr2 + k = 0，r = ±i√(k/m)
通解：x(t) = A cos(ωt) + B sin(ωt)，其中 ω = √(k/m)
应用 2：RC 电路
电阻 R 与电容 C 串联，输入电压 E(t)：
R·dq/dt + q/C = E(t) （一阶线性方程）
积分因子 μ = et/(RC)，
q(t) = e-t/(RC)[∫ et/(RC) E(t)/R dt + C0]
应用 3：Logistic 增长模型（种群生态学）
dP/dt = rP(1 - P/K) （可分离变量的一阶方程）
分离变量 dP/[P(1 - P/K)] = r dt，部分分式展开求积分：
P(t) = K / [1 + (K/P0 - 1)e-rt]

八、微分方程解题总体流程

  1. 确定阶数：最高阶导数的阶数即为方程阶数
  2. 判断线性性：是否为 y 及其导数的线性组合
  3. 一阶方程：判别是否为可分离/齐次/线性/伯努利/恰当等类型，适用对应解法
  4. 高阶方程：
    • 若能降阶（不显含 x 或 y），降为低阶求解
    • 常系数 → 特征方程法 + 待定系数法
    • Euler 型 → 变量代换为常系数
    • 一般变系数 → 常数变易法或级数解法
  5. 验证：将解代入原方程，检查是否满足初始/边界条件
💡 常用技巧：
• 观察方程是否能写成某种"凑微分"形式
• 对于非齐次项，先判断是否与齐次解中的项"共振"，决定特解形式中的 xk 因子
• 二阶方程记住两类特殊情况：f(x) 为多项式/指数/三角函数的组合
• 遇到复杂的方程先化简（变量代换、同除公因子），再判断类型
