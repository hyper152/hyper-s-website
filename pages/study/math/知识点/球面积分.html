球面积分

重积分与线面积分

📥 下载 PDF 原文

一、球面坐标系

球面坐标系是三维空间中处理球对称问题的重要坐标系。空间中任意一点 P(x, y, z) 可用三个坐标表示：

  • 径向距离 r：原点到点 P 的距离，r = √(x² + y² + z²) ≥ 0
  • 极角（余纬度） φ：z 轴正方向与位置向量的夹角，0 ≤ φ ≤ π
  • 方位角 θ：x 轴正方向到 OP 在 xOy 平面投影的夹角，0 ≤ θ ≤ 2π

直角坐标与球面坐标的转换关系

x = r sinφ cosθ ,   y = r sinφ sinθ ,   z = r cosφ

球面坐标下的体积元

dV = dx dy dz = r² sinφ dr dφ dθ

其中 r² sinφ 为球面坐标系的雅可比行列式的绝对值。

二、三重积分的球面坐标计算

将三重积分从直角坐标转换到球面坐标：

∭Ω f(x, y, z) dV = ∫θ ∫φ ∫r f(r sinφ cosθ, r sinφ sinθ, r cosφ) · r² sinφ dr dφ dθ

一般积分次序

∭Ω f · dV = ∫02π dθ ∫0π dφ ∫0R f(r, φ, θ) r² sinφ dr

（对于半径为 R 的完整球体区域）。

常用积分区域对应的参数范围

区域形状r 范围φ 范围θ 范围
球心在原点的球体（半径 R）0 ≤ r ≤ R0 ≤ φ ≤ π0 ≤ θ ≤ 2π

三、球面上的面积分（第一类曲面积分）

对于定义在球面 S 上的函数 f(x, y, z)，曲面积分在球面坐标系下的表达式为：

&iint;S f(x, y, z) dS = ∫02π ∫0π f(R sinφ cosθ, R sinφ sinθ, R cosφ) · R² sinφ dφ dθ

其中 dS = R² sinφ dφ dθ 为球面上的面积元。

球面面积元推导

球面参数方程 r(φ, θ) = (R sinφ cosθ, R sinφ sinθ, R cosφ)：

  • 经线方向切向量：rφ = (R cosφ cosθ, R cosφ sinθ, -R sinφ)
  • 纬线方向切向量：rθ = (-R sinφ sinθ, R sinφ cosθ, 0)
  • 法向量模长：|rφ × rθ| = R² sinφ

因此 dS = |rφ × rθ| dφ dθ = R² sinφ dφ dθ。

四、常用球面积分公式

球的表面积

S = &iint;S dS = ∫02π dθ ∫0π R² sinφ dφ = 4πR²

球的体积

V = ∭Ω dV = ∫02π dθ ∫0π dφ ∫0R r² sinφ dr = &frac43;πR³

重要积分恒等式

&iint;S x² dS = &iint;S y² dS = &iint;S z² dS = ⅓ &iint;S (x² + y² + z²) dS = ⅓R² · 4πR² = &frac43;πR⁴
∭Ω x² dV = ∭Ω y² dV = ∭Ω z² dV = ⅓ ∭Ω r² dV = ⅓ ∫02π dθ ∫0π dφ ∫0R r⁴ sinφ dr = &frac415;πR⁵

五、典型例题

例 1：计算曲面积分 I = &iint;S (x² + y²) dS，其中 S 为球面 x² + y² + z² = a²。

解：由于对称性，x² + y² = a² - z²。
在球面坐标下，x² + y² = a² sin²φ，dS = a² sinφ dφ dθ。
I = ∫02π dθ ∫0π a² sin²φ · a² sinφ dφ = 2πa⁴ ∫0π sin³φ dφ = 2πa⁴ · &frac43; = &frac83;πa⁴
例 2：计算三重积分 I = ∭Ω (x² + y² + z²) dV，其中 Ω 是球体 x² + y² + z² ≤ R²。

解：在球面坐标下，x² + y² + z² = r²，dV = r² sinφ dr dφ dθ。
I = ∫02π dθ ∫0π dφ ∫0R r² · r² sinφ dr
= 2π · 2 · ∫0R r⁴ dr = 4π · ⅕R⁵ = ⅘πR⁵
例 3：计算由球面 x² + y² + z² = 2az 围成的球体体积。

解：将方程配方为 x² + y² + (z - a)² = a²，球心 (0, 0, a)，半径 R = a。
在球面坐标下，球面的极坐标方程为 r = 2a cosφ，0 ≤ φ ≤ π/2。
V = ∫02π dθ ∫0π/2 dφ ∫02a cosφ r² sinφ dr
= 2π ∫0π/2 ⅓(2a cosφ)³ sinφ dφ = &frac{16πa³}{3} ∫0π/2 cos³φ sinφ dφ
= &frac{16πa³}{3} · ¼ = &frac43;πa³

六、柱面坐标与球面坐标的选择对比

被积区域特征推荐坐标系说明
球体、半球体、球壳球面坐标被积函数含 x² + y² + z² 时尤佳
圆柱体、圆锥体、旋转抛物面柱面坐标被积函数含 x² + y² 时适用
长方体、四面体等直角边区域直角坐标区域边界为坐标平面时优先考虑
旋转体（绕 z 轴）柱面坐标用 r, θ, z 表示边界简单

七、常见注意事项与易错点

⚠ 注意事项：
  1. 体积元不能遗漏因子：球面坐标的体积元是 r² sinφ，初学者常遗漏 r² 或 sinφ。
  2. 角度范围：φ 的范围是 0 到 π（不是到 2π），θ 的范围是 0 到 2π。
  3. 被积函数代换：直角坐标下的被积函数 f(x, y, z) 必须全部代换为 r, φ, θ 的表达式。
  4. 区域对称性利用：当被积函数具有奇偶性且区域对称时，可先判断是否为零以简化计算。
  5. 球面面积分 vs 三重积分：球面面积分只有两个积分变量 (φ, θ)，面积元为 R² sinφ；三重积分有三层积分，体积元为 r² sinφ。
  6. 球心不在原点时：可以先平移坐标系，使球心在坐标轴上，再利用球面坐标的平移形式。

八、球面坐标下的梯度、散度与旋度

在球面坐标系 (r, φ, θ) 中，向量微分算子的表达式为：

梯度（标量场 f）

∇f = ∂f/∂r · er + (1/r) · ∂f/∂φ · eφ + (1/(r sinφ)) · ∂f/∂θ · eθ

散度（向量场 A = Ar er + Aφ eφ + Aθ eθ）

∇·A = (1/r²) ∂(r² Ar)/∂r + (1/(r sinφ)) ∂(sinφ Aφ)/∂φ + (1/(r sinφ)) ∂Aθ/∂θ

拉普拉斯算子

∇²f = (1/r²) ∂(r² ∂f/∂r)/∂r + (1/(r² sinφ)) ∂(sinφ ∂f/∂φ)/∂φ + (1/(r² sin²φ)) ∂²f/∂θ²

这些公式在求解具有球对称性的偏微分方程（如拉普拉斯方程、热传导方程）中具有重要应用。
