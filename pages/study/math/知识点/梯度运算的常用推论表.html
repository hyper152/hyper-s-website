梯度运算的常用推论表

多元函数微分学 — 梯度运算的各种恒等式与推论汇总

📥 下载 PDF 原文

一、梯度定义与基本概念

梯度（Gradient）是多元函数微分学中的核心概念。设 u = f(x, y, z) 在区域 D 内具有一阶连续偏导数，则函数 f 在点 P(x, y, z) 处的梯度定义为：

grad f = ∇f = (∂f/∂x, ∂f/∂y, ∂f/∂z)

其中 ∇ = (∂/∂x, ∂/∂y, ∂/∂z) 称为 Hamilton 算子（Nabla 算子）。梯度方向是函数在该点处方向导数最大的方向，其模等于该方向导数的最大值。

几何意义：梯度方向是等值面（等值线）的法线方向，指向函数值增加最快的方向。梯度向量与等高线（等值面）正交。

二、梯度运算的基本法则

设 u = f(x), v = g(x) 为可微函数，C 为常数。以下为梯度运算的基本法则表：

性质 公式 名称
线性性 ∇(C · u) = C · ∇u 常数倍法则
线性性 ∇(u ± v) = ∇u ± ∇v 加法/减法法则
乘积法则 ∇(uv) = v · ∇u + u · ∇v Leibniz 法则
商法则 ∇(u/v) = (v∇u − u∇v) / v2 (v ≠ 0) 分式法则
幂法则 ∇(un) = n un−1 · ∇u 复合函数求导

这些法则与一元函数求导法则在形式上高度一致，但梯度算子作用于多元函数时，结果是一个向量而非标量。

三、链式法则与复合函数梯度

设 y = f(u1, u2, ..., um)，其中 ui = gi(x1, x2, ..., xn)，则复合函数的梯度满足以下链式法则：

∇y = ∑i=1m (∂f/∂ui) · ∇gi

特别地，对于一元外函数与多元内函数的复合 y = f(u), u = g(x, y, z)，有：

∇f(u) = f'(u) · ∇u
示例：求 f(x, y) = sin(x2 + y2) 的梯度。
解：令 u = x2 + y2，则 f = sin u，∇f = cos u · ∇u = cos(x2 + y2) · (2x, 2y) = (2x cos(x2 + y2), 2y cos(x2 + y2))。

四、梯度运算的常用恒等式

以下为梯度运算中重要的恒等式汇总，涉及标量函数与向量函数的交互：

4.1 向量点积的梯度恒等式

设 F = (F1, F2, F3) 和 G = (G1, G2, G3) 为向量值函数，f, g 为标量函数：

∇(F · G) = (G · ∇)F + (F · ∇)G + G × (∇ × F) + F × (∇ × G)

其中 (F · ∇)G 表示方向导数算子 (F1∂/∂x + F2∂/∂y + F3∂/∂z) 作用于 G 的每个分量。

4.2 数量积的梯度

∇(f g) = f · ∇g + g · ∇f

这是乘积法则的直接推广，与一元情形一致。

4.3 复合函数的梯度恒等式

∇(f ∘ φ) = f'(φ) · ∇φ

其中 φ: ℝn → ℝ 为可微函数，f: ℝ → ℝ 为可微函数。

4.4 线性函数的梯度

对线性函数 f(x) = a · x = a1x1 + a2x2 + ... + anxn：

∇(a · x) = a

特别地，∇xi = ei（第 i 个标准基向量），∇||x||2 = 2x。

4.5 二次型的梯度

设 A 为 n × n 对称矩阵，f(x) = xT A x：

∇(xT A x) = 2 A x

4.6 距离函数的梯度

∇(||x − a||) = (x − a) / ||x − a||
∇(||x − a||2) = 2(x − a)

五、梯度与方向导数的关系推论

方向导数是梯度概念的核心应用之一。设 u = f(x, y, z) 在点 P 处可微，l 为单位向量，则：

∂f/∂l = ∇f · l = |∇f| · cos(θ)

其中 θ 为梯度方向与 l 方向的夹角。

方向 夹角 θ 方向导数值 意义
沿梯度方向 θ = 0 |∇f| 函数增长最快
逆梯度方向 θ = π −|∇f| 函数下降最快
沿等值面切向 θ = π/2 0 函数值不变
推论：梯度方向是函数变化率最大的方向，且梯度的模即为该最大方向导数值。这一推论在优化算法（如梯度下降法）中有着核心应用。

六、梯度与等值面的关系推论

设曲面方程为 F(x, y, z) = C，则曲面上点 P0(x0, y0, z0) 处的切平面法向量为：

n = ∇F(P0) = (Fx(P0), Fy(P0), Fz(P0))

从而切平面方程为：

Fx(P0)(x − x0) + Fy(P0)(y − y0) + Fz(P0)(z − z0) = 0

法线方程为：

(x − x0) / Fx(P0) = (y − y0) / Fy(P0) = (z − z0) / Fz(P0)
示例：求椭球面 x2 + 2y2 + 3z2 = 6 在点 (1, 1, 1) 处的切平面方程。
解：设 F(x, y, z) = x2 + 2y2 + 3z2，则 ∇F = (2x, 4y, 6z)，在点 (1, 1, 1) 处 ∇F = (2, 4, 6)。切平面方程为：2(x − 1) + 4(y − 1) + 6(z − 1) = 0，即 x + 2y + 3z = 6。

七、梯度运算的进阶推论

7.1 梯度场与保守场

若向量场 F 是某个标量函数 f 的梯度场，即 F = ∇f，则 F 为保守场（无旋场），满足：

∇ × F = 0

且对任意闭合曲线 C，有：

∮C F · dr = 0

这构成了梯度场是否为保守场的判定依据。

7.2 梯度的散度与拉普拉斯算子

∇ · (∇f) = ∇2f = ∂2f/∂x2 + ∂2f/∂y2 + ∂2f/∂z2

梯度的散度即为 Laplace 算子，在偏微分方程（热传导方程、波动方程等）中具有重要地位。

7.3 梯度的旋度恒为零

∇ × (∇f) = 0

该恒等式表明任意标量场的梯度场均为无旋场，在向量分析中属于基本恒等式之一。

7.4 乘积的拉普拉斯算子

∇2(fg) = f · ∇2g + g · ∇2f + 2∇f · ∇g

九、常见误区与注意事项

  • 梯度与方向导数的区别：梯度是向量，方向导数是标量。梯度给出方向导数的最大变化率方向，而非方向导数本身。
  • 梯度的存在条件：函数必须在某点的邻域内可微（偏导数连续），梯度才存在。
  • 梯度与偏导的维度关系：对于 n 元函数，梯度是 n 维向量，其每个分量即为对应的偏导数。
  • 零梯度条件：∇f = 0 表示该点为驻点（临界点），是极值点的必要条件。
  • 梯度场积分与路径无关：当向量场为梯度场时，曲线积分与路径无关，仅为起点和终点的函数值之差。

十、梯度在机器学习中的应用

梯度运算是机器学习优化的数学基础。以下简要列举几个核心应用场景：

  • 梯度下降法（Gradient Descent）：xk+1 = xk − η · ∇f(xk)，沿负梯度方向迭代更新，寻找函数极小值。
  • 反向传播（Backpropagation）：利用链式法则逐层计算神经网络中损失函数对权重的梯度。
  • 随机梯度下降（SGD）：在大规模数据中采用随机近似梯度，高效优化目标函数。
  • 梯度裁剪（Gradient Clipping）：防止梯度爆炸，将梯度的模限制在一定范围内。
注：以上应用属于梯度概念的推广部分，考试中主要考察上述恒等式的推导与应用，建议熟练掌握速查表内容。
