点火公式详解

无穷级数 — Wallis公式（点火公式）及其在积分中的应用

📥 下载 PDF 原文

一、概述

点火公式（亦称 Wallis 公式）是处理形如 sinnx 和 cosnx 在区间 [0, π/2] 上定积分的重要工具。其名称来源于"点火"递推过程——每当指数 n 减小 2，就"引燃"一个系数，最终抵达 n = 0 或 n = 1 的基值。

Wallis 公式不仅仅是一个积分递推式，它还给出了 π 的一个无穷乘积表达式，在概率论（计算 Gauss 积分）、组合数学（Stirling 公式推导）中均有重要应用。

二、点火公式（Wallis 积分递推公式）

2.1 基本形式

设正整数 n ≥ 0，定义：

In = ∫0π/2 sinnx dx = ∫0π/2 cosnx dx

则满足以下递推关系：

In = (n-1)/n · In-2 ， n ≥ 2

其中初始值：

I0 = π/2 ， I1 = 1

2.2 点火展开（具体结果）

反复应用递推公式，可得分段闭合表达式：

n 的奇偶性 公式
n 为偶数（n = 2k） I2k = ( (2k-1)!! / (2k)!! ) · π/2
n 为奇数（n = 2k+1） I2k+1 = ( (2k)!! / (2k+1)!! )

其中双阶乘定义：

  • (2k)!! = 2 · 4 · 6 · ... · (2k) = 2k · k!
  • (2k-1)!! = 1 · 3 · 5 · ... · (2k-1)
💡 记忆口诀："偶次乘 π/2，奇次乘 1；分子分母交替降，点火到 0 或 1。"
即从 n 开始，每隔 2 乘一个分数 (k-1)/k，直到遇 0 或 1。

三、Wallis 乘积（π 的无穷乘积表示）

由点火公式可导出著名的 Wallis 乘积：

π/2 = limk→∞ [ (2·2·4·4·6·6·...·(2k)·(2k)) / (1·3·3·5·5·7·...·(2k-1)·(2k+1)) ]

等价写作：

π/2 = ∏k=1∞ ( (2k)2 / ((2k-1)(2k+1)) )

推导思路：考虑比值 I2k+1 / I2k，利用夹逼定理令 k → ∞ 即得。Wallis 乘积是历史上第一个将常数 π 表示为无穷乘积的公式，也是 Stirling 公式推导的关键工具。

四、推广形式

4.1 任意区间上的推广

∫0π sinnx dx = ∫0π cosnx dx = 2In
∫02π sinnx dx = ∫02π cosnx dx =
 n 为奇数 → 0
 n 为偶数 → 4In

4.2 带幂次修正的积分

∫0π/2 sinmx cosnx dx = ( (m-1)!! (n-1)!! / (m+n)!! ) · T

其中常数 T 取值规则：

  • 若 m 和 n 均为偶数 → T = π/2
  • 其他情况（至少一个奇数）→ T = 1

4.3 Beta 函数形式

点火公式本质上是 Beta 函数的特例：

In = ½ B( (n+1)/2, ½ ) = ½ · Γ((n+1)/2) Γ(½) / Γ((n+2)/2)

其中 Γ(½) = √π。这一观点将递推整数指数推广到了任意实数指数。

五、典型例题

例 1 计算 ∫0π/2 sin8x dx

解：n = 8 为偶数，使用点火公式：
I8 = (7/8)(5/6)(3/4)(1/2) · π/2
= (7·5·3·1)/(8·6·4·2) · π/2
= (105)/(384) · π/2 = 105π/768 = 35π/256
例 2 计算 ∫0π sin5x dx

解：先利用对称性 ∫0π sin5x dx = 2I5
I5 = (4/5)(2/3) · 1 = 8/15
原积分 = 2 × 8/15 = 16/15
例 3 计算 ∫02π cos4x dx

解：n = 4 为偶数，在 [0, 2π] 上：
原积分 = 4I4 = 4 · (3/4)(1/2) · π/2
= 4 · 3/8 · π/2 = 12π/16 = 3π/4
例 4 计算 ∫0π/2 sin3x cos2x dx

解：利用推广公式，m = 3（奇数），n = 2（偶数）：
原积分 = (2!! · 1!!) / (5!!) · 1
= (2·1) / (5·3·1) = 2/15

也可直接利用三角函数恒等式 + 点火公式验算。

六、常见应用场景

应用领域 具体使用方式
定积分计算 快速求 ∫ sinnx dx、∫ cosnx dx 等三角幂积分
概率论与数理统计 推导 ∫-∞+∞ e-x2 dx = √π（Gauss 积分）
Stirling 公式推导 Wallis 乘积 ⇒ n! ~ √(2πn) (n/e)n
Gamma 函数计算 通过 Beta 函数连接，计算 Γ(k+½) 的值
傅里叶级数 计算三角级数展开中的系数积分

七、常见误区与注意事项

⚠ 误区 1：混淆双阶乘计算。注意 (2k)!! ≠ 2·(k!)，正确为 (2k)!! = 2k·k!。

⚠ 误区 2：忽略积分区间。点火公式仅适用于 [0, π/2]，扩展到 [0, π] 或 [0, 2π] 需乘相应倍数。

⚠ 误区 3：误认为 n 为任意实数。最简递推形式仅对正整数 n 成立，实数推广需借助 Gamma 函数。

⚠ 误区 4：点火顺序错误。递推是从 n 开始每隔 2 乘以 (n-1)/n，不是从 1 开始的连乘。
