高等数学II-2 考点大纲

基于手写复习笔记整理

一、空间解析几何

  • 1. 向量代数
    • 数量积 (a·b)
    • 向量积 (a×b)
    • 混合积 (a·(b×c))
    • 向量平行 (a∥b)、垂直 (a⊥b) 的判定
  • 2. 直线与平面
    • 直线方程：点法式、一般式
    • 空间曲线的方程、空间曲面的方程
    • 空间曲面的切平面、法平面方程
    • 直线的位置关系、空间曲线在平面的投影

二、多元函数微分学

  • 1. 抽象函数的二阶偏导数
  • 2. 隐函数求导（在可微条件下求方向导数）
  • 3. 方向导数的求解
  • 4. 微分方程（注：可参考二元函数相关题，2022年曾考过）

三、重积分

  • 1. 利用积分区域的 对称性、轮换性 进行积分化简。
    • 格林公式（Gauss公式）：用于 二重积分
    • 高斯公式（Gauss公式）：用于 三重积分
  • 2. 二重积分、三重积分的计算。

四、线面积分 (2024年考研)

  • 1. 第一型曲线/曲面积分
    • 重点技巧：利用对称性、轮换性
  • 2. 第二型曲线/曲面积分（环流量、通量）
    • 环流量：单位时间内通过闭曲线的环流量（对应第二型曲线积分）
    • 通量：单位时间内通过有向曲面的通量（对应第二型曲面积分）
  • 3. 格林公式（Green公式）：平面中封闭曲线与面积的关系
  • 4. 高斯公式（Gauss公式）
  • 5. 曲线积分的计算（计算示例）
    设曲面 Σ: x² + y² + z² = 2, z ≥ 0，
    计算曲面积分 ∬Σ x²√(2-x²-y²) dS
    （注：利用曲面方程将 z 和面积微元 dS 投影到 xoy 平面进行计算）

五、无穷级数

  • 1. 正向级数收敛性判定（多种判别法）
  • 2. 级数求和（幂级数展开法）
    例如：求 ∑n=0∞ (n / 2n) 的和。
    方法：利用已知展开式 ∑ xn = 1 / (1-x)，两边求导得 ∑ n xn-1 = 1 / (1-x)2，再乘 x 并代入 x=1/2 得出结果。
  • 3. 幂级数收敛半径、收敛域的求解
    • 常用方法：比值法、根值法
    • 注意事项：讨论端点处的收敛性（数项级数判定）
  • 4. 交错级数，绝对收敛与条件收敛
    • 判断 ∑ (sin n / n²) 为 绝对收敛（因为 |sin n / n²| ≤ 1/n² 收敛）
    • 判断 ∑ (sin n / n) 为 条件收敛

六、微分方程 (重点：一阶、二阶、可降阶、非齐次、常系数)

  • 1. 一阶微分方程
    • 可分离变量方程
    • 齐次方程
    • 一阶线性非齐次方程
    • 换元法
  • 2. 可降阶的高阶微分方程
  • 3. 常系数线性齐次/非齐次微分方程
    • 特征方程的求法（齐次）
    • 待定系数法（非齐次特解的设法）
